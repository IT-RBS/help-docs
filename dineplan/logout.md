# Logout

### Overview

The Log Out option allows the current user to safely sign out of the DinePlan application. When the user selects “Log Out”, the current session is closed, and the application returns to the Login screen.

Logging out does not close the DinePlan application. It only ends the current user's session and allows another authorized user to log in.

<figure><img src=".gitbook/assets/image (128).png" alt=""><figcaption></figcaption></figure>

### Working

1. From the main DinePlan screen, select “Log Out”.
2. The current user is logged out of the application.
3. DinePlan returns to the Login screen.
4. Another user can enter their PIN and log in to the application.

**Note:** To completely close the DinePlan application, select **“Exit”** from the Login screen. **“Log Out”** only ends the current user session.

### Use Case

* Log Out – Use this option when you want to end the current user's session and return to the Login screen.

<figure><img src=".gitbook/assets/image (129).png" alt=""><figcaption></figcaption></figure>

* Exit – Use this option when you want to completely close the DinePlan application.
