# FAQ's

## 1. How do I open the Till Transactions feature in DinePlan at the start of my shift?

To access the **Till Transactions** management screen from the DinePlan dashboard:

1. Log in to **"DinePlan"**.
2. From the main **"Dashboard"**, select **"Front Desk"**.
3. Select **"Till Transactions"**.

<figure><img src="../../.gitbook/assets/image (407).png" alt=""><figcaption></figcaption></figure>

**Result:** The **Till Transactions** screen opens, allowing administrators and cashiers to create till entries, record remarks, print summaries, and review transaction records for auditing.

## 2. How do I initialize an opening cash balance for a cashier's till using Add Details?

To set up a new till transaction and record the opening cash float:

1. Navigate to **"Front Desk"** _**→**_ **"Till Transactions"**.
2. Select **"Add Details"**.
3. On the **Add Details** screen, select the required **"Account"** from the drop-down list.
4. Enter the opening float amount into the **"Total"** field.
5. Enter any notes or comments in the **"Remarks"** field, if required.
6. Select **"Open Till"** to initialize the till for the selected account.
7. Select **"Save"**.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-14 171025.png" alt=""><figcaption></figcaption></figure>

**Result:** The new till transaction is created and immediately displayed in the **Till Transactions** list.

## 3. How do I print a till summary report for daily cash reconciliation?

To generate a physical or printed report of a till transaction:

1. Open **"Front Desk"** _**→**_ **"Till Transactions"**.
2. From the **Till Transaction List**, select the required till transaction row.
3. Select **"Print Summary"**.

<figure><img src="../../.gitbook/assets/image (400).png" alt=""><figcaption></figcaption></figure>

**Result:** The system generates and prints the summary report of the selected till transaction for auditing and physical verification.

## 4. How do I remove or delete an incorrect till transaction record from the list?

To remove an unneeded or invalid till transaction entry:

1. Open **"Front Desk"** _**→**_ **"Till Transactions"**.
2. Select the target till transaction from the list.
3. Select **"Delete"**.
4. When prompted by the system, confirm the deletion action.

<figure><img src="../../.gitbook/assets/image (409).png" alt=""><figcaption></figcaption></figure>

**Result:** The selected till transaction is permanently removed from the **Till Transaction List**.

## 5. How do I search for a specific till transaction record using keywords?

To quickly find a till record in a long list:

1. Open **"Front Desk"** _**→**_ **"Till Transactions"**.
2. Locate the **"Search"** input bar above the **Till Transaction List**.
3. Type a keyword into the **"Search"** bar, such as the **Till Account** name or text from the **Remarks** field.
4. The list filters automatically to display matching transaction records.

## 6. Where do I select the specific Account when creating a new till entry?

When initializing a till on the **Add Details** screen:

1. Open **"Front Desk"** _**→**_ **"Till Transactions"** _**→**_ **"Add Details"**.
2. Click the **"Account"** drop-down menu.
3. Select the required till account assigned to the cashier or station.
4. Proceed to enter the **Total** opening float.

## 7. In which field do I enter the opening cash amount when initializing a till?

When configuring a new till transaction:

1. Open the **Add Details** configuration form.
2. Locate the **"Total"** field.
3. Enter the exact opening cash amount for the till into the **"Total"** text box.
4. Select **"Open Till"** and click **"Save"**.

## 8. How do I attach custom notes or comments to a till transaction entry?

To record audit notes (such as shift details or float explanations):

1. On the **Add Details** screen, locate the **"Remarks"** input box.
2. Type your comments or notes into the **"Remarks"** field.
3. Select **"Save"**.

<figure><img src="../../.gitbook/assets/image (411).png" alt=""><figcaption></figcaption></figure>

**Note:** Entered remarks are stored with the record and displayed under the **Remarks** column in the **Till Transaction List**.

#### 9. What is the purpose of the "Open Till" button on the Add Details screen?

The **"Open Till"** button is used during till creation to initialize the drawer float for the chosen account.

* **Location:** On the **Add Details** screen below the entry fields.
* **Action:** Click **"Open Till"** to initialize the till for the selected account before clicking **"Save"**.

<figure><img src="../../.gitbook/assets/image (412).png" alt=""><figcaption></figcaption></figure>

## 10. What information is displayed in the main Till Transaction List table?

The **Till Transaction List** provides a comprehensive summary of all cashier till records. The table displays the following columns:

* **S.No.:** Displays the serial number of each till transaction entry.
* **Till Account:** Displays the specific till account linked to the transaction.
* **Date:** Displays the exact creation date of the till record.
* **Remarks:** Displays notes or comments entered during creation.
* **Total:** Displays the total opening float or transaction amount.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-14 170230.png" alt=""><figcaption></figcaption></figure>

## 11. How do I check active operational details like business date, shift number, and active user on the Till Transactions screen?

Operational system information is displayed continuously along the bottom of the screen:

1. Navigate to **"Front Desk"** _**→**_ **"Till Transactions"**.

3. Review the displayed operational fields:
   * **Active Business Type** (e.g., _Restaurant_, _Take Away_, or _Zomato_)
   * **Business Date**
   * **Shift Number**

   * **Navigation Controls**

## 12. How do store managers and administrators use Till Transactions for daily cash auditing?

The **Till Transactions** module supports end-of-shift reconciliation and financial auditing through the following workflow:

1. **Record Opening Float:** Cashiers or managers log opening float amounts using **"Add Details"**.
2. **Review Ledger:** Administrators review the **Till Transaction List** to verify account names, creation dates, and recorded totals.
3. **Print Audit Copy:** Managers select individual records and click **"Print Summary"** to generate physical paper slips for physical register counting.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-14 170230 (3).png" alt=""><figcaption></figcaption></figure>

## 13. What happens immediately after I click "Save" on the Add Details screen?

When you select **"Save"** after entering till details:

1. The system commits the opening float record.
2. The newly created till transaction is added directly to the **Till Transaction List**.
3. The table updates to show its **S.No.**, **Till Account**, **Date**, **Remarks**, and **Total** amount.

## 14. How do I search for a till transaction if I only remember the cashier's remark or note?

If you do not know the exact account name or serial number:

2. Click the **"Search"** bar.
3. Type the remark keyword (e.g., _"Morning shift"_ or _"Main Register"_).
4. The list filters dynamically to match text stored in the **Remarks** column.

* **Restaurant**
* **Take Away**
* **Zomato**

## 16. What step-by-step process must I follow to initialize a till and immediately print a paper copy for the register?

To complete a full opening workflow with physical paper verification:

1. Open **"Front Desk"** _**→**_ **"Till Transactions"**.
2. Select **"Add Details"**.
3. Select the cashier **"Account"**.
4. Enter the opening cash float in **"Total"**.
5. Enter any operational notes in **"Remarks"**.
6. Click **"Open Till"**.
7. Click **"Save"**.
8. Select the newly generated transaction row from the **Till Transaction List**.
9. Click **"Print Summary"** to print the physical summary slip for the cashier register.

<figure><img src="../../.gitbook/assets/image (400).png" alt=""><figcaption></figcaption></figure>

## 17. What information is shown in the S.No., Till Account, and Date columns?

The first three table columns provide primary tracking identifiers:

* **S.No.:** Displays the sequential system serial number for the record.
* **Till Account:** Identifies the specific cashier or till account associated with the entry.
* **Date:** Displays the exact calendar date on which the till transaction was created.

<figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

## 18. How do I safely delete a duplicate or accidental opening till entry?

If a till float was recorded twice or entered with the wrong account:

1. Open **"Front Desk"** _**→**_ **"Till Transactions"**.
2. Locate and click on the incorrect transaction row in the **Till Transaction List**.
3. Click **"Delete"**.
4. When the confirmation prompt appears on screen, confirm the deletion.
5. Verify that the incorrect row disappears from the table, then use **"Add Details"** to re-enter the record if needed.
