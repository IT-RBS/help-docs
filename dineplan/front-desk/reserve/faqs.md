# FAQ's

## 1. How do I create a new customer reservation in DinePlan?

To schedule a new reservation for a guest:

1. Log in to **"DinePlan"** and select **"Front Desk"** from the **"Dashboard"**.
2. Select **"Reserve"** to open the Reserve screen.
3. Select **"Add"** to open the **Add Reservation** screen.
4. Enter the required reservation details:
   * **Reservation Date:** Select the date scheduled for the visit.
   * **Reservation Time:** Select the reserved time slot.
   * **Phone Number:** Enter the customer's contact number.
   * **Customer Name:** Enter the name of the customer.
   * **Email Address:** Enter the customer's email address (optional).
   * **PAX (Total Guests):** Enter the total number of guests included in the booking.
   * **Adult PAX / Adults:** Enter the number of adults.
   * **Child PAX:** Enter the number of children.
   * **Deposit Paid / Deposit & Deposit Type:** Enter deposit details and payment method, if applicable.
   * **Deposit Reference Number:** Enter the reference number, if applicable.
   * **Remarks / Remark:** Enter any special requests or operational notes.
5. Select **"Save"**.

**Note:** The newly created reservation appears directly in the **Reservation List** upon saving.

## 2. How do I assign an unassigned reservation to an available dining table?

To allocate a physical table to a scheduled guest booking:

1. Open **"Front Desk"** → **"Reserve"**.
2. From the **Reservation List**, highlight or select the target reservation.
3. Select **"Assign"**.
4. Select the appropriate available table from the list.
5. Confirm the table assignment.

<figure><img src="../../.gitbook/assets/image (429).png" alt=""><figcaption></figcaption></figure>

**Note:** Once confirmed, the reservation status automatically changes to **Assigned**.

## 3. How do I update or edit the details of an existing reservation?

To modify booking times, guest counts, or contact information for an existing reservation:

1. Open **"Front Desk"** → **"Reserve"**.
2. From the **Reservation List**, select the reservation you need to modify.
3. Select **"Edit"**.
4. Update the required information (such as **Reservation Date**, **Reservation Time**, **Phone Number**, **Customer Name**, **Email Address**, **PAX**, **Adult PAX**, **Child PAX**, **Deposit**, or **Remarks**).
5. Select **"Save"**.

## 4. How do I cancel a customer reservation when a guest cancels their visit?

To process a cancellation for a booking:

1. Open **"Front Desk"** → **"Reserve"**.
2. Select the target reservation from the **Reservation List**.
3. Select **"Cancel"**.
4. Confirm the cancellation when prompted by the system.

<figure><img src="../../.gitbook/assets/image (426).png" alt=""><figcaption></figcaption></figure>

**Note:** Upon confirmation, the reservation status automatically changes to **Cancelled**.

## 5. How do I search and filter reservations by date range and status?

To locate specific bookings or view reservations by status:

1. Open **"Front Desk"** → **"Reserve"**.
2. Select the start date in the **"From"** field.
3. Select the end date in the **"To"** field.
4. Click the **"Status"** filter dropdown menu and select the required option:
   * **Not Assigned:** Displays unallocated reservations.
   * **Assigned:** Displays reservations already allocated to a table.
   * **Cancelled:** Displays cancelled bookings.
5. Select **"Refresh"**.

<figure><img src="../../.gitbook/assets/image (425).png" alt=""><figcaption></figcaption></figure>

**Note:** You must select **"Refresh"** to reload the list with your newly selected filter criteria.

## 6. How do I clear applied search filters and return to the default reservation list?

To reset all active search parameters and reload the full reservation view:

1. Open **"Front Desk"** → **"Reserve"**.
2. Locate the toolbar controls above the **Reservation List**.
3. Select **"Reset"**.

<figure><img src="../../.gitbook/assets/image (424).png" alt=""><figcaption></figcaption></figure>

**Note:** Selecting **"Reset"** clears all applied date range and status filters and immediately reloads the default reservation list.

## 7. How do I export reservation records for daily floor planning or reporting?

To generate an external file of reservation records for administrative use:

1. Open **"Front Desk"** → **"Reserve"**.
2. Apply the required **"From"** and **"To"** date range and **"Status"** filters if exporting a specific subset.
3. Select **"Refresh"** to display the matching records.
4. Select **"Export"**.

<figure><img src="../../.gitbook/assets/image (423).png" alt=""><figcaption></figcaption></figure>

**Note:** The system exports the displayed reservation records for reporting or record keeping.

## 8. How do I enter and track separate adult and child guest counts (Adult PAX and Child PAX) for a reservation?

To record distinct counts for adult and child guests when booking a party:

1. Navigate to **"Front Desk"** → **"Reserve"**.
2. Select **"Add"** (or select an existing reservation and click **"Edit"**).
3. In the **"PAX (Total Guests)"** field, enter the overall total number of guests.
4. In the **"Adult PAX"** (or **"Adults"**) field, enter the specific number of adult guests.
5. In the **"Child PAX"** field, enter the specific number of child guests.
6. Complete any remaining booking fields and select **"Save"**.

<figure><img src="../../.gitbook/assets/image (433).png" alt=""><figcaption></figcaption></figure>

**Note:** The **PAX**, **Adults**, and **Child PAX** numbers display in dedicated columns within the **Reservation List** for quick staff reference.

## 9. How do I log customer deposit details and a deposit reference number for a booking?

To record an advance deposit collected for a reservation:

1. Open **"Front Desk"** → **"Reserve"** and select **"Add"** (or **"Edit"**).
2. Locate the **"Deposit Paid"** (or **"Deposit"**) field and enter the monetary amount collected.
3. Select the payment method in the **"Deposit Type"** field, if applicable.
4. Enter the transaction reference in the **"Deposit Reference Number"** field.
5. Select **"Save"**.

<figure><img src="../../.gitbook/assets/image (432).png" alt=""><figcaption></figcaption></figure>

**Note:** Recorded deposit amounts and payment methods are displayed under the **Deposit** and **Deposit Type** columns in the **Reservation List**.

## 10. How do I filter the Reserve screen to see only unassigned reservations that need table allocation?

To isolate pending bookings that still require physical table assignments:

1. Open **"Front Desk"** → **"Reserve"**.
2. Select the starting date in the **"From"** field and ending date in the **"To"** field.
3. Click the **"Status"** dropdown menu and select **"Not Assigned"**.
4. Select **"Refresh"**.

<figure><img src="../../.gitbook/assets/image (431).png" alt=""><figcaption></figcaption></figure>

**Result:** The **Reservation List** reloads to display only reservations that have not yet been assigned to a table.

## 11. How do I navigate through multiple pages of reservation records using Previous and Next?

When a date range contains more reservation records than can fit on a single screen:

1. Open **"Front Desk"** → **"Reserve"** and view your filtered **Reservation List**.
2. Select **"Next"** to move forward to the next page of reservation entries.
3. Select **"Previous"** to navigate back to the preceding page of entries.

## 12. How do I find out when a reservation was originally created versus its scheduled visit date?

To track when a booking was entered into DinePlan compared to when the guest actually intends to visit:

1. Navigate to **"Front Desk"** → **"Reserve"**.
2. Locate the target booking in the **Reservation List**.
3. Check the **"Reservation Date"** column to view the date scheduled for the guest's visit.
4. Check the **"Created Date"** column to view the exact date on which the reservation entry was originally created in the system.

## 13. Where can I check active shift details, business date, and logged-in user on the Reserve screen?

System operational information is continuously displayed along the bottom of the screen:

1. Open **"Front Desk"** → **"Reserve"**.
2. Look at the **Status Bar** along the bottom edge of the window.
3. Read the **Status Bar** to check:
   * **Active Business Type** (such as **Restaurant**, **Take Away**, or **Zomato**)
   * **Business Date**
   * **Shift Number**
   * **Logged-in User**
   * **Navigation Controls**

## 17. How do I view guest contact information directly from the Reservation List grid?

To check customer contact details without opening the edit screen:

1. Open **"Front Desk"** → **"Reserve"**.
2. Locate the guest row in the **Reservation List**.
3. Read the **"Phone Number"** column to view the customer's contact phone number.
4. Read the **"Email"** column to view the customer's email address.
