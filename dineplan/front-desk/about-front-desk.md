# About Front Desk

## Overview

The **Front Desk** section provides access to important operational functions used to monitor and manage day-to-day restaurant activities. It brings together features that help users review restaurant information, manage item availability, track till transactions, perform audits, handle reservations, and manage messages.

## Screen Elements

The available options in the Front Desk section are:

| Option                | Description                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Report**            | Provides access to reports that help users review and monitor restaurant activities and transaction-related information. |
| **Sold Out**          | Allows users to manage items that are unavailable for ordering by marking them as sold out.                              |
| **Till Transactions** | Allows users to view and manage transactions associated with the till, helping track cashier-related activities.         |
| **Audit**             | Provides access to audit-related information for reviewing activities and changes performed in the system.               |
| **Reserve**           | Allows users to manage restaurant reservations and related booking activities.                                           |
| **Message**           | Provides access to messages and communication related to restaurant operations.                                          |

## Accessing the Front Desk

To access the **Front Desk** section:

1. Log in to DinePlan.
2. From the Dashboard, select “Front Desk”.

<figure><img src="../.gitbook/assets/image (163).png" alt=""><figcaption></figcaption></figure>

3. The Front Desk screen opens with the available options.
4. Select the required option to access its respective functionality.

## Front Desk Functions

The Front Desk features support different aspects of restaurant operations:

* [**Report** ](report/)– Review operational and transaction information.
* [**Sold Out**](sold-out/#about-sold-out) – Manage the availability of menu items.
* [**Till Transactions**](till-transaction/) – Track till and cashier transactions.
* **Audit** – Review system activities for monitoring and verification.
* [**Reserve**](reserve/) – Manage customer reservations.
* [**Message**](message/) – Access and manage operational messages.

These options provide users with a centralized location to access frequently required operational, transaction, reservation, and monitoring functions without navigating through the main POS workflow.
