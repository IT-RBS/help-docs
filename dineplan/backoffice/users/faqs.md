# FAQ's

## 1. How do I create a new user profile for a restaurant staff member?

To set up a new user profile in DinePlan BackOffice:

1. Open **BackOffice** and navigate to the **Users** setting screen.
2. Select **"Add User"**.
3. Enter the employee's name in the **"User Name"** field.
4. Enter the security login PIN in the **"Pin"** field.
5. Enter a security code in the **"Security Code"** field.
6. Click **"User Role"** and select the required role for the user from the dropdown menu.
7. Click **"UI Language"** and select the primary interface language.
8. Select an **"Alternate Language"** if a secondary interface language is required.
9. Select **"Save"** to create the user account.

**Note:** **User Name**, **Pin**, **User Role**, and **UI Language** are required when creating a user.

## 2. Which fields are strictly mandatory when creating a new user profile?

When creating a new user profile in DinePlan BackOffice, you must complete four mandatory fields before the system allows you to save the record:

* **User Name:** Specifies the name of the user.
* **Pin:** Specifies the PIN used by the user for authentication.
* **User Role:** Specifies the role assigned to govern user access.
* **UI Language:** Specifies the primary language used in the DinePlan interface.

## 3. What are the PIN length requirements when setting up a user PIN?

When entering a user PIN in the **Pin** field, the PIN must contain **between 4 and 20 characters**.

<figure><img src="../../.gitbook/assets/image (355).png" alt=""><figcaption></figcaption></figure>

## 4. How do I assign a specific User Role to a staff member?

To assign operational access privileges to a user:

1. Open the user creation or edit screen (**Add User** or **Edit User**).
2. Locate the **"User Role"** field.
3. Click the **"User Role"** dropdown menu and select the required role for the user.
4. Select **"Save"** to store the user details.

<figure><img src="../../.gitbook/assets/image (354).png" alt=""><figcaption></figcaption></figure>

## 5. How do I set the primary UI Language and Alternate Language for a user?

To configure language preferences for a user profile:

1. Open **Add User** or **Edit User** on the **Users** settings screen.
2. Click the **"UI Language"** dropdown menu and select the primary language used in the DinePlan interface.
3. Click the **"Alternate Language"** dropdown menu and select a secondary language if required.
4. Select **"Save"**.

<figure><img src="../../.gitbook/assets/image (353).png" alt=""><figcaption></figcaption></figure>

## 6. Where do I enter a security code for a user account?

In the user setup window (**Add User** or **Edit User**), locate the **"Security Code"** field. Enter the required security code assigned to the user, then select **"Save"** to store the entry.

<figure><img src="../../.gitbook/assets/image (352).png" alt=""><figcaption></figcaption></figure>

## 7. How do I update an existing user's login details or assigned role?

To edit an existing user account:

1. Open the **Users** setting screen in BackOffice.
2. From the **User List**, select the user profile you want to modify.
3. Select **"Edit User"**.
4. Update the required user details (such as **User Name**, **Pin**, **Security Code**, **User Role**, **UI Language**, or **Alternate Language**).
5. Select **"Save"** to save your changes.

<figure><img src="../../.gitbook/assets/image (351).png" alt=""><figcaption></figcaption></figure>

## 8. How do I delete a user account from DinePlan when an employee leaves?

To permanently remove a user profile from the system:

1. Open the **Users** screen in BackOffice.
2. Highlight or select the target user from the **User List**.
3. Select **"Delete User"**.
4. A confirmation message will be displayed on screen.
5. Select **"Yes"** to delete the user.

<figure><img src="../../.gitbook/assets/image (350).png" alt=""><figcaption></figcaption></figure>

**Note:** A confirmation is strictly required before deleting a user.

## 9. What happens if I click "No" on the user deletion confirmation window?

If you select **"No"** when the deletion confirmation message appears, the deletion operation is cancelled and the user account remains unchanged in the **User List**.

<figure><img src="../../.gitbook/assets/image (349).png" alt=""><figcaption></figcaption></figure>

## 10. How do I change the display order of users in the User List?

To customize the order in which users are displayed on screen:

1. Open the **Users** setting screen.
2. Select **"Change Sort Order"**.
3. Arrange the users in the required display order.
4. Save the updated order.

<figure><img src="../../.gitbook/assets/image (348).png" alt=""><figcaption></figcaption></figure>

## 11. How do I search for a specific user profile in BackOffice?

To quickly locate a user in BackOffice:

1. Open the **Users** settings screen.
2. Click inside the **"Search"** input box located above the **User List**.
3. Type the user's name or keyword.
4. The **User List** automatically filters to display matching user records.

<figure><img src="../../.gitbook/assets/image (347).png" alt=""><figcaption></figcaption></figure>

## 12. How do I create a new User Role in BackOffice?

To create a new role for categorizing users and governing permissions:

1. Open **BackOffice** and navigate to **User Roles**.
2. Select **"Add User Role"**.
3. Enter the role name in the **"Role Name"** field.
4. Click **"Department"** and select the department associated with the role.
5. Configure the **"Admin"** option if administrator access is required.
6. Expand the required permission sections and configure permissions.
7. Select **"Save"** to create the user role.

<figure><img src="../../.gitbook/assets/image (346).png" alt=""><figcaption></figcaption></figure>

**Note:** **Role Name** and **Department** are required when creating a user role.

## 13. Which fields are compulsory when creating a new User Role?

When creating a new user role in BackOffice, you must specify:

* **Role Name:** Specifies the descriptive label for the user role.
* **Department:** Specifies the department associated with the user role.

## 14. How do I configure administrator access for a User Role?

To enable or disable administrator access for a specific user role:

2. Locate the **"Admin"** option.
3. Configure the **"Admin"** option to enable or disable administrator access for the role.

To associate a user role with a specific operational department:

2. Locate the **"Department"** field.

## 16. How do I configure Reporting Permissions and Ticket Permissions for a User Role?

To grant or restrict reporting and ticket access for a role:

1. Open **Add User Role** or **Edit User Role**.
2. Locate **"Reporting Permissions"** and click to expand the section to configure reporting settings.
3. Locate **"Ticket Permissions"** and click to expand the section to configure ticket-related settings.
4. Select **"Save"** to store permission changes.

## 17. How do I set up WorkDay, Navigation, Department, and Kitchen Permissions for a role?

To manage WorkDay, system navigation, department, and kitchen operations access:

1. Open the user role configuration screen (**Add User Role** or **Edit User Role**).
2. Expand **"WorkDay Permissions"** to configure WorkDay settings.
3. Expand **"Navigation Permissions"** to configure navigation settings.
4. Expand **"Department Permissions"** to configure department settings.
5. Expand **"Kitchen Permission"** to configure kitchen operation permissions.
6. Select **"Save"**.

## 18. How do I edit an existing User Role's permissions or details?

To modify permissions or settings for an existing role:

1. Open **User Roles** in BackOffice.
2. Select the required user role from the **User Role List**.
3. Select **"Edit User Role"**.
4. Update the required role details (**Role Name**, **Department**, **Admin**) or expand permission sections to update access settings.
5. Select **"Save"** to save your changes.

<figure><img src="../../.gitbook/assets/image (339).png" alt=""><figcaption></figcaption></figure>

## 19. How do I delete an unneeded User Role, and what confirmation is required?

To remove a user role from the system:

1. Go to the **User Roles** screen in BackOffice.
2. Select the user role you want to delete from the **User Role List**.
3. Select **"Delete User Role"**.
4. A confirmation message is displayed on screen.
5. Select **"Yes"** to confirm deletion, or select **"No"** to cancel.

<figure><img src="../../.gitbook/assets/image (338).png" alt=""><figcaption></figcaption></figure>

**Note:** A confirmation is strictly required before deleting a user role.

## 20. How do I reorder User Roles in the User Role List?

To control how user roles are presented in selection lists:

2. Select **"Change Sort Order"**.
3. Arrange the user roles in the required order.
