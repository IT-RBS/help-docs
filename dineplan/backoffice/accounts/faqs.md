# FAQ's

## 1. How do I create a new Till Account in BackOffice to record till transactions?

To create a new till account for organizing till-related financial transactions in BackOffice:

1. Open the **Till Account** screen in BackOffice.
2. Select **"Add Till Account"** from the **Till Account List**.
3. Enter the required account name in the **"Till Account Name"** field.
4. Click the **"Account Type"** dropdown and select the required category option (**Income**, **Expense**, **Accrual Income**, or **Accrual Expense**).
5. Click the **"Account Mode"** dropdown and select how the account amount is handled (**Calculate In Shift** or **No Calculate In Shift**).
6. Enter the starting or designated value in the **"Amount"** field.
7. Select **"Save"** to create the till account.

<figure><img src="../../.gitbook/assets/image (538).png" alt=""><figcaption></figcaption></figure>

**Note:** Specifying a **Till Account Name** is required before saving.

## 2. What error appears if I try to save a Till Account without entering a Till Account Name?

When setting up a new till account, entering a name in the **"Till Account Name"** field is strictly required.

If you select **"Save"** while the **Till Account Name** field is empty, the system blocks the save action and displays the validation message: **"Name" should not be empty**.

To resolve this issue:

1. Enter a descriptive title in the **"Till Account Name"** text box.
2. Complete the **"Account Type"**, **"Account Mode"**, and **"Amount"** fields.
3. Select **"Save"**.

<figure><img src="../../.gitbook/assets/image (537).png" alt=""><figcaption></figcaption></figure>

## 3. How do I edit an existing Till Account when its configuration or amount needs updating?

To modify the details, account mode, or amount of a previously created till account:

1. Navigate to the **Till Account** screen in BackOffice.
2. Locate and select the required account from the **Till Account List**.
3. Select **"Edit Till Account"**.
4. Update the necessary account fields (**Till Account Name**, **Account Type**, **Account Mode**, or **Amount**).
5. Select **"Save"** to apply the updated details.

<figure><img src="../../.gitbook/assets/image (536).png" alt=""><figcaption></figcaption></figure>

## 4. How do I delete an obsolete Till Account from BackOffice?

To remove a till account that is no longer required for restaurant operations:

1. Open the **Till Account** screen.
2. From the **Till Account List**, highlight or select the till account you want to delete.
3. Select **"Delete Till Account"**.
4. Review the confirmation prompt message displayed on screen.
5. Select **"Yes"** to permanently delete the till account (or select **"No"** to cancel the deletion).

<figure><img src="../../.gitbook/assets/image (535).png" alt=""><figcaption></figcaption></figure>

**Note:** Always review the selected till account carefully before confirming deletion.

## 5. How do I change the display order of Till Accounts in the list?

To customize the visual sequence of accounts displayed in the **Till Account List**:

1. Open the **Till Account** screen.
2. Select **"Sort Till Accounts"**.
3. In the **Sort Till Accounts Window**, click and drag the accounts into your preferred order.
4. Select **"OK"** to apply the new display sequence.

<figure><img src="../../.gitbook/assets/image (534).png" alt=""><figcaption></figcaption></figure>

**Note:** If you want to discard your order changes without saving them, select **"Cancel"** in the sorting window.

## &#x20;6. How do I search for a specific Till Account in BackOffice?

To locate a particular account quickly when managing a long list of till accounts:

1. Open the **Till Account** screen in BackOffice.
2. Click inside the **"Search"** text box located above the **Till Account List**.
3. Type the name or keyword of the till account you are searching for.
4. The system automatically filters the **Till Account List** to display matching records.

## 7. How do I set up a new Account in BackOffice for general financial recording?

To create a new general ledger or operational account in BackOffice:

1. Open the **Accounts** screen from BackOffice.
2. Select **"Add Account"**.
3. In the **"Account Name"** field, enter the required name for the account.
4. Click the **"Account Type"** dropdown menu and select the required category (e.g., **Receivables**, **Sales**, **Payment**, **Discount**, **Expense**, **Income**, or **Member**).
5. Click the **"Currency"** dropdown menu and select the required currency associated with the account.
6. Select **"Save"** to create the account record.

<figure><img src="../../.gitbook/assets/image (532).png" alt=""><figcaption></figcaption></figure>

**Note:** Both **Account Name** and **Account Type** are strictly required before an account can be saved.

## 8. How do I create multiple accounts at the same time using Batch Create Accounts?

To generate several accounts simultaneously without filling in individual forms one by one:

1. Open the **Accounts** screen in BackOffice.
2. Select **"Batch Create Accounts"**.
3. In the provided text entry area, type the names of the accounts you want to create, placing **each account name on a separate line**.
4. Select **"OK"** to create all listed accounts simultaneously.

<figure><img src="../../.gitbook/assets/image (530).png" alt=""><figcaption></figcaption></figure>

**Note:** When using batch creation, ensure each account name is entered on its own separate line before clicking **"OK"**.

## 12. How do I create a new Account Type category to classify system accounts?

To create a custom account type classification (such as Receivables, Purchase, Payable, Sales, Payment, Discount, Member, Income, or Expense):

1. Open **"Account Types"** from the Back Office menu.
2. Select **"Add Account Type"**.
3. Enter the required title in the **"Name"** field.
4. Select the **"Filter type"** for the account category.
5. Select the required **"Rules"**.
6. Add relevant tags in the tags area, if applicable.
7. Select **"Save"** to add the new account type to the list.

<figure><img src="../../.gitbook/assets/image (525).png" alt=""><figcaption></figcaption></figure>

**Note:** Entering a **Name** is mandatory when creating a new account type.

## 16. How do I set up a new Account Transaction Type with debit and credit account rules?

To define a new financial transaction type and configure its accounting debit and credit pathways:

1. Open **"Account Transaction Type"** from Back Office.
2. Select **"Add Account Transaction Type"**.
3. Enter the required title in **"Account Transaction Type Name"**.
4. Select the required **"Currency"**.
5. Select the **"Source Account Type (Debit)"** and choose a **"Default Source Account"**.
6. Select the **"Target Account Type (Credit)"** and choose a **"Default Target Account"**.
7. Select **"Save"** to add the transaction type to the list.

<figure><img src="../../.gitbook/assets/image (519).png" alt=""><figcaption></figcaption></figure>

## 17. Which fields are mandatory when creating a new Account Transaction Type?

When configuring an Account Transaction Type, specific fields are required to establish valid transaction accounting pathways:

* **Account Transaction Type Name:** Required to identify the transaction type in the system.
* **Source Account Type (Debit):** Required to define the debit account classification.
* **Target Account Type (Credit):** Required to define the credit account classification.

If any of these mandatory fields are left incomplete, the system will not create the transaction type. Always verify that Currency, Default Source Account, and Default Target Account are configured accurately before selecting **"Save"**.
