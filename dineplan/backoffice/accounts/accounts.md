# Accounts

### **Overview** <a href="#overview" id="overview"></a>

The Accounts setting allows administrators to create and manage accounts used in the system. Accounts can be organized under different account types, such as Receivables, Sales, Payment, Discount, Expense, Income, and Member.

You can add, edit, delete, sort, and batch create accounts.

<figure><img src="../../.gitbook/assets/image (141).png" alt=""><figcaption></figcaption></figure>

### **Screen Elements** <a href="#screen-elements" id="screen-elements"></a>

| **Screen Element**    | **Description**                                          |
| --------------------- | -------------------------------------------------------- |
| Account List          | Displays the available accounts grouped by account type. |
| Search                | Allows users to search for a specific account.           |
| Add Account           | Creates a new account.                                   |
| Edit Account          | Opens the selected account for editing.                  |
| Delete Account        | Deletes the selected account after confirmation.         |
| Batch Create Accounts | Allows multiple accounts to be created at the same time. |
| Change Sort Order     | Allows users to change the display order of accounts.    |
| Account Name          | Specifies the name of the account.                       |
| Account Type          | Specifies the account category.                          |
| Currency              | Specifies the currency associated with the account.      |
| Save                  | Saves the new or updated account.                        |
| Close                 | Closes the Accounts screen.                              |

### **Working** <a href="#working" id="working"></a>

#### **Add an Account** <a href="#add-an-account" id="add-an-account"></a>

1. Select "Add Account".

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-05 120217.png" alt=""><figcaption></figcaption></figure>

2. Enter the required account name in "Account Name".
3. Select the required "Account Type".
4. Select the required "Currency".

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-05 120255.png" alt=""><figcaption></figcaption></figure>

5. Select "Save" to create the account.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-05 120312.png" alt=""><figcaption></figcaption></figure>

#### **Edit an Account** <a href="#edit-an-account" id="edit-an-account"></a>

1. Select the required account from the list.
2. Select "Edit Account".

<figure><img src="../../.gitbook/assets/image (98).png" alt=""><figcaption></figcaption></figure>

3. Update the required account details.
4. Select "Save" to save the changes.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-05 120312.png" alt=""><figcaption></figcaption></figure>

#### **Delete an Account** <a href="#delete-an-account" id="delete-an-account"></a>

1. Select the account you want to delete.
2. Select "Delete Account".

<figure><img src="../../.gitbook/assets/image (99).png" alt=""><figcaption></figcaption></figure>

3. Review the confirmation message.
4. Select "Yes" to confirm the deletion or "No" to cancel.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-05 120319.png" alt=""><figcaption></figcaption></figure>

#### **Batch Create Accounts** <a href="#batch-create-accounts" id="batch-create-accounts"></a>

1. Select "Batch Create Accounts".

<figure><img src="../../.gitbook/assets/image (100).png" alt=""><figcaption></figcaption></figure>

2. Enter the account names in the provided text area, with each account on a separate line.

<figure><img src="../../.gitbook/assets/image (97).png" alt=""><figcaption></figcaption></figure>

3. Select "OK" to create the accounts.

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-05 120327.png" alt=""><figcaption></figcaption></figure>

#### **Change Sort Order** <a href="#change-sort-order" id="change-sort-order"></a>

1. Select "Change Sort Order".

<figure><img src="../../.gitbook/assets/Screenshot 2026-10-05 120304.png" alt=""><figcaption></figcaption></figure>

2. Arrange the accounts in the required order.
3. Confirm the updated order.

### **Use Case** <a href="#use-case" id="use-case"></a>

1. Create accounts required for restaurant operations.
2. Organize accounts under the appropriate account types.
3. Configure the currency associated with an account.
4. Edit account details when configuration changes are required.
5. Delete accounts that are no longer required.
6. Create multiple accounts using "Batch Create Accounts".
7. Search for an account when working with a large account list.
8. Arrange accounts in the required display order for easier management.

### **Notes** <a href="#notes" id="notes"></a>

* Account Name is required when creating an account.
* Account Type must be selected before saving an account.
* Use "Batch Create Accounts" when multiple accounts need to be created at once.
* When using batch creation, enter each account on a separate line.
* Review the account details before selecting "Save".
* Deleting an account requires confirmation.
