# FAQ's

## 1. How do I add and configure a new hardware printer in BackOffice?

To add a new printer device to DinePlan for kitchen, bar, or receipt printing:

1. Open **BackOffice** and navigate to the **Printer** section.
2. Select **"Add Printer"** from the screen elements toolbar.
3. In the **"Printer Name"** field, enter a descriptive name for the printer.
4. Under **"Printer Share Name / Port Name"**, click the dropdown menu and select the required printer. (The default printer connected to the system is displayed automatically in this dropdown.)
5. Select the required **"Printer Type"**.
6. Configure the available printer settings according to your hardware setup.
7. Verify all printer details and select **"Save"** to create the printer record.

**Note:** Always verify the printer details before selecting **"Save"**.

## 2. How do I modify the details of an existing printer in the Printer List?

To update the name, port assignment, or printer type of an existing printer:

1. Navigate to the **Printer** section in BackOffice.
2. Highlight and select the required printer from the **Printer List**.
3. Select **"Edit Printer"**.
4. Update the required printer details on the configuration screen.
5. Select **"Save"** to apply and save your changes.

<figure><img src="../../.gitbook/assets/image (557).png" alt=""><figcaption></figcaption></figure>

**Note:** You must select the target printer from the **Printer List** before clicking **"Edit Printer"**.

## 3. How do I remove an unused printer from BackOffice?

To permanently delete an unnecessary or disconnected printer:

1. Navigate to the **Printer** section in BackOffice.
2. Select the printer you want to remove from the **Printer List**.
3. Select **"Delete Printer"**.
4. When the confirmation message appears on screen, select **"Yes"** to confirm deletion.

<figure><img src="../../.gitbook/assets/image (556).png" alt=""><figcaption></figcaption></figure>

**Note:** You must select the target printer before clicking **"Delete Printer"**. Deletion strictly requires user confirmation.

## 4. How do I change the display order of printers in the Printer List?

## 5. How do I create a new Print Job and set up its product-to-printer mappings?

To configure how specific menu items or product groups trigger printouts on designated printers:

1. Open BackOffice and navigate to the **Printer Job** section.
2. Select **"Add Print Job"**.
3. Enter the required **"Print Job Name"** and assign a **"Group"**.
4. Select the required option under **"Printing Content"**.
5. Configure **"Always Exclude Tax"** and **"Negative"** settings as required for the job.
6. Under **"Print Mapping"**, select **"Add"** to create a new mapping row.
7. Select the required **"Product Group"**, **"Product"**, **"Printer"**, **"Printer Template"**, and **"DepartmentID"**.
8. Add additional mapping rows if more product categories need to be linked.
9. Select **"Save"** to finalize and add the print job.

<figure><img src="../../.gitbook/assets/image (554).png" alt=""><figcaption></figcaption></figure>

**Note:** Entering a **Print Job Name** is strictly required before saving a new print job.

## 6. How do I add new product mappings or remove existing mappings from a Print Job?

To update which products, printers, or templates are linked to an existing Print Job:

1. Open the **Printer Job** section in BackOffice.
2. Select the target print job from the **Print Job List**.
3. Select **"Edit Print Job"**.
4. **To add a new mapping:** Under **"Print Mapping"**, select **"Add"** and choose the required **Product Group**, **Product**, **Printer**, **Printer Template**, and **DepartmentID**.
5. **To remove an existing mapping:** Under **"Print Mapping"**, highlight the unwanted mapping row and select **"Delete"**.
6. Select **"Save"** to save your updated print job mappings.

## 7. How do I configure tax exclusion and negative line rules on a Print Job?

To control whether tax details or negative values appear on kitchen/bar tickets generated by a print job:

3. Locate the **"Negative"** option and enable or disable it as needed.
4. Complete your mapping details under **"Print Mapping"**.
5. Select **"Save"**.

## 15. Why can't I delete the Second Display directly from DinePlan, and what is the exact removal procedure?

The Second Display has a specific system dependency constraint that prevents direct deletion inside the POS application.

**Operational Procedure to remove the Second Display:**

1. You **cannot** delete the Second Display directly from DinePlan initially.
2. To delete the Second Display, you must **first remove it from the Program Files** on the operating system.
3. Once it has been removed from the Program Files directory, return to DinePlan, open **Second Display**, select the display from the **Second Display View List**, and select **"Delete Second Display View"**.

## 16. How do I create a new Widget and choose its display type in BackOffice?

To create a new display widget for showing promotional images, videos, queue numbers, or tickets:

1. Open BackOffice and navigate to **Widget** settings.
2. Select **"Add Widget"**.
3. Enter a title in the **"Widget Name"** field.
4. Click the **"Type"** dropdown menu and select the required widget type.
5. Configure the available fields that appear for your selected type.
6. Enter the required content template in **"Item Content Template"**, where applicable.
7. Select **"Save"** to create the widget.

<figure><img src="../../.gitbook/assets/image (543).png" alt=""><figcaption></figcaption></figure>

**Note:** A **Widget Name** is strictly required to save a widget. The available configuration fields on screen vary depending on the selected **Type**.

## 17. What Widget Types are available in DinePlan, and how do they affect configuration options?

DinePlan supports five distinct **Widget Types** under Widget settings:

* **Image:** Displays image-based content.
* **Video:** Displays video-based media.
* **Slide:** Displays slideshow presentations.
* **Queue:** Displays order queue status information.
* **Ticket:** Displays ticket-related data.

<figure><img src="../../.gitbook/assets/image (542).png" alt=""><figcaption></figcaption></figure>

**Note:** Ensure that you select the appropriate widget **Type** before configuring additional options, as the configuration fields provided on screen change automatically based on the selected type.

## 19. How do I delete a Widget from BackOffice, and how do I cancel if clicked by mistake?
