# FAQ's

## 1. How do I create a new feedback question in BackOffice?

To create a new question for collecting customer feedback:

1. Open the **Feedback Question** screen in BackOffice.
2. Select **"Add Feedback Question"**.
3. Enter a descriptive label in the **"Name"** field.
4. Enter the question text to be displayed to users in the **"Question"** field.
5. Enter the **"Default Answer"**.
6. Enter the **"Negative Answer"** associated with the question.
7. Select the required **"Question Type"**.
8. Select **"Save"** to create the feedback question.

<figure><img src="../../.gitbook/assets/image (331).png" alt=""><figcaption></figcaption></figure>

**Note:** A **Name** is strictly required when creating a feedback question. The selected **Question Type** determines the type of response configured for the question.

## 2. Which field is compulsory when creating a new feedback question?

When setting up a new feedback question, specifying a **"Name"** is strictly required.

To set the question name during creation:

1. Select **"Add Feedback Question"**.
2. Enter the name in the **"Name"** input box.
3. Complete the remaining fields (**Question**, **Default Answer**, **Negative Answer**, and **Question Type**).
4. Select **"Save"**.

<figure><img src="../../.gitbook/assets/image (332).png" alt=""><figcaption></figcaption></figure>

## 3. How do I edit an existing feedback question when survey requirements change?

To update the question text, default answer, negative answer, or response type of an existing question:

1. Open the **Feedback Question** screen.
2. Select the required question from the **Feedback Question List**.
3. Select **"Edit Feedback Question"**.
4. Update the required details in the fields (**Name**, **Question**, **Default Answer**, **Negative Answer**, or **Question Type**).
5. Select **"Save"** to save your changes.

<figure><img src="../../.gitbook/assets/image (333).png" alt=""><figcaption></figcaption></figure>

## 4. How do I delete a feedback question from BackOffice?

To remove a feedback question that is no longer required:

1. Go to the **Feedback Question** screen.
2. Highlight or select the feedback question you want to delete from the **Feedback Question List**.
3. Select **"Delete Feedback Question"**.
4. Confirm the deletion when prompted.

<figure><img src="../../.gitbook/assets/image (334).png" alt=""><figcaption></figcaption></figure>

**Note:** The deletion procedure for feedback questions follows the same confirmation process used for User Roles.

## 5. How do I change the display order of questions in the Feedback Question List?

To customize the visual sequence of feedback questions:

1. Open the **Feedback Question** screen.
2. Select **"Change Sort Order"**.
3. Arrange the feedback questions in the required display order.
4. Confirm the updated order.

<figure><img src="../../.gitbook/assets/image (335).png" alt=""><figcaption></figcaption></figure>

**Note:** The sorting procedure for feedback questions uses the same arrangement workflow as User Roles.

## 6. What do the Default Answer, Negative Answer, and Question Type fields mean?

When configuring a feedback question, these three fields govern how responses are processed and captured:

* **Default Answer:** Specifies the default response pre-selected or suggested for the question.
* **Negative Answer:** Specifies the negative response value associated with the question for evaluation tracking.
* **Question Type:** Specifies the type of response required for the question (such as rating, text, or multiple choice).

## 7. How do I close the Feedback Question management screen?

To exit the Feedback Question screen and return to the main BackOffice interface:

1. Locate the **"Close"** button on the Feedback Question screen.
2. Select **"Close"**.

## 8. Which field is compulsory when creating a new Feedback Group?

When creating a new feedback group, specifying a **"Name"** is strictly required.

## 9. How do I add or remove questions from an existing Feedback Group?

To update the list of assigned questions in a feedback group:

1. Open the **Feedback Group** screen.
2. Select the required feedback group from the **Feedback Group List**.
3. Select **"Edit Feedback Group"**.
4. To update the group label, edit the **"Name"** field.
5. Select **"Save"** to save your updated configuration.

## 12. How do I search for a specific Feedback Group or filter questions while creating a group?

BackOffice provides two separate **Search** functions on the Feedback Group screen:

* **To search for an existing Feedback Group:** Type the group name into the **"Search"** bar located above the **Feedback Group List**.
* **To search for questions while adding or editing a group:** Type the question keyword into the **"Search"** bar located under **"Select Questions"**.
