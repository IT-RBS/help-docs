# Can I view venue availability reports for the whole month?

Yes, you can view venue availability for the entire month by using the Monthly Venue Position report.

To access this report:

&#x20;1\. Navigate to the Queries menu.

&#x20;2\. Click on the Monthly Venue Position menu option.

This specific report is designed to display all reservations and blocks for the month against each individual venue, giving you a comprehensive view of availability.

If you need different timeframes, you can also use:

• Venue Booking: Displays reservations and blocks for the current day.

• Weekly Forecast: Provides a outlook for the week.

• Banquet Status: Allows you to select a specific date and use Advance search filters to view the status of various bookings.
