# What is the process for cancelling a FP?



To cancel a Function Prospectus, you should follow these specific steps within the Transactions menu:

1\. Navigate to the Transactions menu and select Function Prospectus Cancel.

2\. Click the Display button and select the specific reservation for which you need to cancel the prospectus.

3\. Type in a cancel reason and then click the cancel button to finalize the process.
