# How do I define a custom session start time?

To define or set a custom start time for a session, you can do so through the Masters settings for overall session definitions or within a specific Reservation for individual events.

**Defining a Session in Masters**

If you want to create a session (like "Morning" or "Evening") with a specific default start time, follow these steps in the Master settings:

1\. Navigate to the Masters menu and click on Session.

2\. Click the New button to create a new session or select an existing one to edit.

3\. Enter the Session Id, Session Name, and Display seq no.

4\. Enter the specific start time and end time for this session in the provided fields.

5\. Click the Save button to finalize the session definition.

**Setting a Custom Event Start Time**

If you have already selected a session but need to specify a unique start time for a particular booking:

1\. During the Reservation process, navigate to the Venue tab.

2\. After selecting the Date and Session, locate the Event Start time field.

3\. Enter the specific custom time for that event.

4\. Enter the End time and other details like Serve time or Snacks pickup time if required.

5\. Save the reservation to apply these times to that specific booking.
