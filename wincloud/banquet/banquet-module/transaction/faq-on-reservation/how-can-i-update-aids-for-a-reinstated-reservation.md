# How can I update aids for a reinstated reservation?

Update Department Aids for a reinstated reservation, follow these steps within the Transactions menu:

1\. Navigate to Reinstatement: Go to the Transactions menu and click on Reservation - ReInstate.

2\. Open the Reservation: Click Open and type the guest name or select the specific reservation from the existing list.

3\. Access Venue Details: Once the reservation details are reinstated, you have the ability to change various fields. Navigate to the Venue tab.

4\. Update Aids: Locate the Department Aids field within the Venue tab and make the necessary updates or additions.

5\. Finalize: Click the Save button to complete the reinstatement process and store your updated aid requirements.

By using this specific menu, the system allows you to modify not only the aids but also other core details like the Venue, F\&B, Menu, and Amenities for that booking.
