# How to reprint and cancel the Function Prospectus ?

Steps to take reprint of Function Prospectus

1.Click on Function Prospectus under the transactions menu.

2\. Click Display and select the reservation which needs to reprint function prospectus as shown below.

3\. Click on Print as shown below.

&#x20;

**Function Prospectus Cancel**

Steps to cancel the Function prospectus.

1.Click on Function Prospectus Cancel under the Transactions menu.

2\. Click Display and select the reservation which needs to cancel function prospectus as shown below.

3\. Enter the cancel reason and click cancel
