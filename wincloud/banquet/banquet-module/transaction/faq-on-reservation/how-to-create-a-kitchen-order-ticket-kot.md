# How to create a kitchen order ticket (KOT)?

To create a Kitchen Order Ticket (KOT), follow these steps within the Transaction menu:

1\. Navigate to the Menu: Go to the Transaction menu and click on Kot/charges.

2\. Select the Category: Set the Category to KOT.

3\. Identify the Reservation: Click on Reserve No and select the specific reservation number for which you are generating the ticket.

4\. Choose Items: Click on the R symbol to select the items you wish to include in the order.

5\. Finalize: Click Save to complete the process and raise the KOT.

You can also view any Pending KOT/Charges by navigating to the Queries menu and selecting the Pending Bills option, where you can then click Display to see the current list
