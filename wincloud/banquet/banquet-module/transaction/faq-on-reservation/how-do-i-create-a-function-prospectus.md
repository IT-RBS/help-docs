# How do I create a Function Prospectus?

To create a Function Prospectus, follow these three steps within the system's Transactions menu:

1\. Navigate to the Transactions menu and select Function Prospectus.

2\. Click Display and choose the specific reservation for which you need to generate the prospectus.

3\. Click Save and then OK to print the document.

If you need to manage an existing prospectus, the sources also outline the following procedures:

· Reprinting: Go to Transactions > Function Prospectus, click Display to select the reservation, and then click Print.

· Canceling: Navigate to Transactions > Function Prospectus Cancel, click Display to find the reservation, enter a cancel reason, and click cancel.
