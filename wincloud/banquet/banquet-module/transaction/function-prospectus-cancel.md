# Function Prospectus Cancel

The **Function Prospectus Cancel** feature is used to cancel an already generated Function Prospectus for a reservation. This process helps users manage incorrect, unwanted, or cancelled function prospectus records efficiently.

## Steps to Cancel a Function Prospectus

Step 1: Navigate to the **Banquet** module and select **Transaction**.

1. Click on **Function Prospectus Cancel**.

* The Function Prospectus Cancel screen will open.

Step 2: Click the **Display** button.

1. The system will display the list of available reservations.
2. Select the reservation for which the Function Prospectus needs to be cancelled.

* Ensure the correct reservation is selected before proceeding.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 17-15-00.png" alt=""><figcaption></figcaption></figure>

Step 3: In the **Cancel Reason** field, enter the reason for cancelling the Function Prospectus.

1. Provide a clear and appropriate reason for future reference and record tracking.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 17-14-13.png" alt=""><figcaption></figcaption></figure>

Step 4: After entering the cancel reason, click the **Cancel** button.![](<../../../.gitbook/assets/Screenshot From 2026-05-25 17-12-04.png>)

1. The selected Function Prospectus will be cancelled successfully.
