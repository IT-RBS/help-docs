# How can I link a Function Type to a specific Market Segment?

To link a Function Type to a specific Market Segment, you must configure this association within the Master settings. Based on the sources, follow these steps:

&#x20;1\. Navigate to the Masters menu and click on Function Type.

&#x20;2\. Click the New button to create a new entry or select an existing one to edit.

&#x20;3\. Enter the Function Id and Function Name.

&#x20;4\. In the same window, you will find a field for Market Segment. Select the desired segment from this dropdown to create the link.

&#x20;5\. Click the Save button to finalize the association.

Important Note: Before you can link them, the Market Segment must already be created in its own Master setting **(Masters > Market Segment)** so that it appears as an option in the Function Type setup.

Once linked, whenever that specific Function Type is selected during a Venue Block or Reservation, the system can automatically associate it with the corresponding Market Segment for your Analysis reports.
