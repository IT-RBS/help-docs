# What is the purpose of the Bill Reprint Audit report?

The Bill Reprint Audit report serves as an auditing tool to track and display a log of all finalized bills that have been reprinted within a specific day range.

**Key features of this report include:**

• **User Tracking:** It allows you to filter the audit details by specific User, showing who performed each reprint.

• **Accountability:** Because the system requires a Reason to be entered whenever a bill is reprinted through the Cashier menu, this report helps management monitor those justifications and maintain financial oversight.

To access it, navigate to **Reports > Bill Reprint Audit**, select your date range and user (if needed), and click Display.
