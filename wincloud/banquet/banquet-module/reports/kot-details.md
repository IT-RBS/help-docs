# KOT Details

The **KOT Details Report** is used to view detailed information about all Kitchen Order Tickets (KOTs) generated within a selected date range. This report helps users monitor food and beverage orders, track order activity, and review transaction details.

## **Steps to View KOT Details Report**

Step 1: Log in to the system and navigate to the **Banquet Module**.

* Click on the **Reports** menu.
* Select **KOT Details** from the list of available reports.

Step 2: After selecting **KOT Details**, the system will open the report page.

* By default, the system displays the report based on a **predefined day/date range**.
* This view shows all KOT entries recorded during the selected period.

<figure><img src="../../../.gitbook/assets/image (1330).png" alt=""><figcaption></figcaption></figure>

Step 3: Select the required date range if needed.

* Click on the **Display** button.
* The system will generate and display the **KOT Details Report**.
