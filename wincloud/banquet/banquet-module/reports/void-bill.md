# Void Bill

The **Void Bill report** is used to view all bills that have been cancelled or voided within a selected date range. This report helps track voided transactions and ensures proper audit control within the system.

## **Steps to View Void Bill Report**

Step 1: Log in to the system and navigate to the **Banquet Module**.

1. Click on the **Reports** menu.
2. Select **Void Bill** from the list of available reports.

<figure><img src="../../../.gitbook/assets/m15 (1).png" alt=""><figcaption></figcaption></figure>

Step 2: After selecting **Void Bill**, the system will open the report page.

* By default, the system displays the **Void Bill list based on a selected day/date range**.
* This default view shows all voided bills within the predefined period.

Step 3: Click on the **Display** button.

* The system will generate and display **Void Bill report** based on the selected criteria.
