# Session Statistics

The **Session Statistics** report is used to view information related to user sessions in the system. It helps track active and completed sessions, allowing users to monitor system usage and login activity.

## Steps to View Session Statistics

Step 1: Navigate to the **Point of Sale** module and Select **Queries** menu.

Step 2: Click on **Session Statistics** from the available options.

1. The Session Statistics screen will be displayed.

This screen shows session-related details such as user activity and system usage information.
