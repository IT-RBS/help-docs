# How do I set up a Printer Location?

To set up a Printer Location, you must define it within the KOT Printer settings in the master configuration. This allows the system to forward order details like table numbers and item quantities to the correct area, such as the kitchen or billing division.Steps to Set Up a Printer Location

1. **Navigate to the Menu: Go to Master1 > kot > Kot printer.**
2. **Start a New Entry:** Click the New button.
3. **Define the Location:** Enter the Printer location (e.g., Kitchen, Bar, or Basement).
4. **Enter Share Name:** Input the printer share name as it is recognized on your network.
5. **Configure Backup (Optional):** You can set a second print option, which redirects the KOT to another printer if the primary location experiences a problem.
6. **Save:** Click the Save button to create the printer location.

**Allocating the Printer Location**

After creating the location, you must assign it to specific product groups so the system knows what items should print there:

* Go to **Master1 > Kot > Kot printer Allocation** and click Open.
* Click on printer location to see your newly created list.
* Select the product group to be assigned to that location and click Save
