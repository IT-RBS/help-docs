# How can I add item-specific instructions?

Yes, you can add item-specific instructions in the system by using the Item Instruction setup menu. This allows you to link specific directives directly to individual items within a product group.

**How to Set Up Item-Specific Instructions**

To configure these instructions, follow these steps within the Master3 module:

1. Navigate to **Master3 > Item Instruction.**
2. Click the Add button.
3. Select the relevant Product group, Sub group, and the specific Item you wish to add instructions for.
4. Click Search to load the item details.
5. Click the Add Button again to enter the specific Item Instruction.
6. Choose the Level for the instruction and click Save.

**Other Types of Instructions**

The system also provides broader instruction management tools:

* **Instruction Groups:** You can create general categories for instructions by going to **Master3 > Instruction Group**.
* **General Instructions:** You can define individual instructions and assign them to a group via **Master3 > Instruction.**
* **KOT Kitchen Instructions:** For general directives meant for the kitchen (rather than tied to a single item), use **Master1 > Kot > Kot Kitchen instruction** to enter an instruction and its corresponding group name.
* **Outlet Instruction Link:** You can link specific instruction types to an entire outlet through **Master3 > Outlet - Instruction Link**
