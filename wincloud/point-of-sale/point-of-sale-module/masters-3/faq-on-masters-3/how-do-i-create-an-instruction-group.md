# How do I create an instruction group?

To create an Instruction Group, which allows you to categorize various directives within the system, follow these steps:

1. **Navigate to the Menu:** **Go to Master3 > Instruction Group.**
2. S**tart a New Entry:** Click on the Add button.
3. **Enter Group Details:** Input the desired Instruction Group Name into the field provided.
4. **Save:** Click the Save button to finalize the creation of the new group.

Once you have created an instruction group, you can then define individual instructions and assign them to these groups via the Master3 > Instruction menu.
