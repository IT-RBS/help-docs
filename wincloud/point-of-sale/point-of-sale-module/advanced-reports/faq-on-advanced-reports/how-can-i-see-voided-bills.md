# How can I see voided bills?

To view voided bills, you should use the Void Bills Report found within the POS system. This report allows you to list all canceled bill details, including which specific items were canceled, the user who performed the action, and the reasons provided for the void.Steps to Access the Void Bills Report

1. Navigate to the Reports main menu.
2. **Select the Outlet:** If you need specific information for one location, select the desired outlet from the options.
3. **View Specific Details:** If you require the details of a particular bill rather than a summary, click the details check box.
4. **Generate the Report:** Once you have selected all necessary fields and filters, click display to load the data.

**Additional Features**

* **Excel Export:** If you need to save or analyze the data outside of the system, you can convert the report to an Excel format by clicking the corresponding icon.
* **Audit Tracking:** For broader oversight, you can also use the Bill Audit report (found under Advance > Reports > Bill Audit), which includes "settle cancellation details" along with bill amounts, times, and steward information
