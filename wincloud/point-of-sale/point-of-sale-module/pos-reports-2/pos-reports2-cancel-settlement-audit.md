# Cancel Settlement Audit

CANCEL SETTLEMENT AUDIT

Cancel settlement audit is a report, where the closed bills which are made active again by cancelling the settlements are shown. This report shows the bills for which the settlements are cancelled and not the bills which are voided.

1. To filter outlet click on ![](<../../../.gitbook/assets/1 (8).png>) next to the “**outlet**” option, to filter user same way select the ![](<../../../.gitbook/assets/1 (8).png>) icon next to the “**user**” option.
2. Select ‘from’ date and ‘to’ date to view list of bills with cancelled settlements.
3. Once filters all applied click on ![](<../../../.gitbook/assets/5 (29).png>)
4. To print directly click![](../../../.gitbook/assets/8.png), To convert and save in excel, click ![](../../../.gitbook/assets/5.png)
