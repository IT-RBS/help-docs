# How do I use Pending KOT?

The Pending KOT report is used to track Kitchen Order Tickets (KOT) that have been created but have not yet been processed for billing. Each entry in this report shows the specific food items punched for that KOT.To use the Pending KOT report, follow these steps:

1. **Navigate to the Report:** Go to the Reports menu and select Pending KOT.
2. **Apply Filters:** Select the required date, outlet, and session.
3. **Generate the View:** Click the display icon to load the report.

**Additional Features and Options**

* **Serve Instructions:** You can tick a specific checkbox to see if serve instructions were added to the KOT.
* **Printing:** The report can be printed directly by clicking the print icon.
* **Exporting:** You can convert and save the report into an Excel format by clicking the corresponding icon
