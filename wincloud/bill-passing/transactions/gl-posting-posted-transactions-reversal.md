# GL Posting Posted Transactions – Reversal

**GL Posting Posted Transactions – Reversal** is a transaction used to reverse General Ledger (GL) entries for transactions that have already been posted and finalised in the accounting system. This process is typically performed when corrections, adjustments, or modifications are required after posting.&#x20;

## Steps to Perform GL Posting Posted Transactions – Reversal

Step 1: Navigate to the **Transactions** menu in the **Bill Passing** module.

1. Click on **GL Posting Posted Transactions – Reversal**.

* The **GL Posting Posted Transactions – Reversal** screen will be displayed.

<figure><img src="../../.gitbook/assets/Screenshot from 2026-06-04 10-35-23.png" alt=""><figcaption></figcaption></figure>

Step 2: The system will display a list of transactions that have already been posted to the General Ledger.

Step 3: From the list of posted transactions, select the transaction that needs to be reversed.

Step 4: Click the **Reverse** button.

* The system will process the reversal and create the necessary reversing entries in the General Ledger.
