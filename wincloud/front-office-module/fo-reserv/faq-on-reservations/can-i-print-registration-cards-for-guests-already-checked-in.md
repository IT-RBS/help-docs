# Can I print registration cards for guests already checked in?

Yes, you can print registration cards for guests who are already checked in by using the dedicated printing tool in the system.

To print a registration card outside of the initial check-in flow, follow these steps:

1. Navigate to the **Reservation Main Menu**.
2. Select the **Registration Card Print** option.
3. From this screen, you can generate the card. For example, you can select **"Plain Reg. Card"** to generate a card for a walk-in guest.
4. Click the **Print icon** to generate the card in its designated format.

While the system automatically prompts you to print a registration card via a **pop-up window** during the actual check-in process, this standalone menu allows you to access and print the document at a later time if needed
