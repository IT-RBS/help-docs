# How do I perform an Auto-allocate for Group Check-ins?

To perform an Auto-allocate for group check-ins, you can use the dedicated Group Check-In tool, which is designed to process multiple rooms with a minimal number of clicks.

**Steps for Auto-allocation during Group Check-In**

1. **Identify the Group:** Navigate to the Group Check-In menu. Use the search icon in the Group field to select the referral group, or enter the reservation number directly if you have it.
2. **Locate Specific Guests** (Optional): If you need to find a specific individual within the group rather than checking in everyone, use the Funnel Filter to search by the guest's name.
3. **Execute Auto-allocation**: Click the Auto allocation button. This function automatically assigns available rooms to any guest in the group who hasn't already been assigned a room number.
4. &#x20;**Select Check-In Type**: Use the provided checkboxes to select whether you want to perform the check-in pax-wise (by person) or room-wise.
5. **Finalize**: Click the Save button to check in all selected rooms at once.

**Pre-allocation via Room Assignment**

If you prefer to allocate rooms before the group arrives, you can also use the Auto Allocation feature within the Room Assignment module (Reservation > Room Assignment). This tool allows you to pre-block rooms automatically based on specific criteria to ensure a smoother check-in process when the group reaches the hotel.
