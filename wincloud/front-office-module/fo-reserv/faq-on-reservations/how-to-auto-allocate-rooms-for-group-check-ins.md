# How to Auto-allocate rooms for Group Check-ins

**How do I perform an Auto-allocate for Group Check-ins?**

You can use the **Group Check-In** tool to automatically assign rooms and check in multiple guests with minimal effort.

#### **Steps for Auto-allocation during Group Check-In**

1. **Identify the Group:**\
   Navigate to the **Group Check-In** menu. Search for the group using the **search** icon in the **Group** field, or enter the **Reservation Number** directly.
2. **Locate Specific Guests (Optional):**\
   If you need to check in only certain guests, use the **Funnel Filter** to search by the guest's name.
3. **Execute Auto Allocation:**\
   Click the **Auto Allocation** button. The system automatically assigns available rooms to guests in the group who do not already have a room assigned.
4. **Select the Check-In Type:**\
   Choose the required check-in method using the available checkboxes:
   * **Pax-wise** (by guest)
   * **Room-wise**
5. **Finalize the Check-In:**\
   Click **Save** to complete the check-in for all selected guests or rooms.

#### **Pre-allocation Using Room Assignment**

If you prefer to assign rooms before the group arrives, use the **Auto Allocation** feature in **Reservation → Room Assignment**. This allows you to automatically pre-assign rooms based on defined criteria, helping ensure a smoother and faster group check-in process on arrival.
