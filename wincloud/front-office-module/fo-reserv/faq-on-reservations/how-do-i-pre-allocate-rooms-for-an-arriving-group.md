# How do I pre-allocate rooms for an arriving group?

To pre-allocate (or pre-block) rooms for an arriving group, you can use the Room Assignment tool or the Auto-allocate feature within the group-specific menus. Pre-blocking rooms in advance is recommended to facilitate a smooth and efficient check-in process.

**Method 1: Using Room Assignment**

This is the standard way to pre-allocate rooms for any guest scheduled to arrive on a given day.

1. Navigate to **Reservation > Room Assignment**.
2. Once the screen displays, you have two ways to assign rooms:

* **Manual Selection:** Select the required rooms manually through the Room Search option.
* **Auto Allocation:** Click the Auto Allocation button to have the system assign rooms automatically based on specified criteria.

**Method 2: Using Group-Specific Allocation**

If you are currently working within a group record, you can use built-in allocation buttons:

* **During Group Reservation:** Within the Group Reservation screen, select the reservation line and click the Auto-allocate button to assign specific rooms to the guests in that group.
* **During Group Check-In:** If rooms were not pre-allocated earlier, you can click the auto allocation button within the Group Check-In menu to automatically assign available rooms to the group members just before completing the check-in.

**Important Notes**

* **Room Search Details:** When manually selecting rooms, the Room Search screen will display floor numbers and color codes indicating room status (e.g., Vacant, Dirty, Blocked for Maintenance) to help you choose the best options.
* **Cancelling Assignments:** If a room has already been assigned and you need to change it, you can cancel the assignment by clicking the button located next to the respective room number in the Room Assignment screen.
