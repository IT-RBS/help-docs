# How do I create a new reservation?

To create a new reservation in the system, follow these standard steps within the **Front Office** module:

### **Standard Reservation Process**

1. **Access the Menu:** Navigate to **Reservation** from the Main Menu and select **Reservation** again from the submenu.
2. **Initiate New Entry:** Click the **Add new item** button to start a new booking.
3. **Define Stay Details:**
   1. Select the **Room type** from the drop-down list.
   2. Choose the **Arrival Date** using the calendar icon and enter the number of **Nights**.
   3. Input the number of **Adults** and **Children**.
4. **Select a Room:** Click the Room number field to open the **Room Search Screen**. Here you can select a room based on availability and color codes (e.g., Vacant, Dirty, Occupied, or Blocked).
5. **Identify the Guest:**
   1. **For Repeat Guests:** Click the **magnifier icon** to search for and select an existing guest profile.
   2. **For New Guests:** Type the name directly in the designated columns or double-click the row to enter details.
6. **Set Compulsory Analytics:** You must choose a **Business Source** (e.g., OTAs), as this field is compulsory for hotel analytical reports. You may also optionally select a **Segment** (Corporate/Individual) or **Guest Type** (VIP/Repeat).
7. **Finalize:** Ensure the rates are correctly displayed in the rate box based on the selected plan and room specifications, then **Save** the reservation.

### **Advanced Reservation Options**

* **Routing (Bill Splitting):** If the bill needs to be split among guests or a company, click the **Routing** button. You can specify the number of splits and assign specific revenues (like Room or F\&B) to different names or companies.
* **Packages:** Use the **Packages** button to add pre-created services such as city tours or taxi services to the reservation.
* **Auto Charge:** If there are additional recurring revenues to be added, use the **Auto Charge** section to select the relevant revenue rows.

### **Quick Reservation via Calendar**

You can also create a reservation visually using the **Room Chart**:

1. Go to **Front Office >> Reservations >> Reservations** and click the **calendar icon** on the menu bar.
2. **Click and drag** your cursor on the calendar from the desired arrival date to the departure date for a specific room.
3. Select **Quick Reservations** from the pop-up window; this will open the full Reservation Window with the dates already populated for you to finish the booking.
