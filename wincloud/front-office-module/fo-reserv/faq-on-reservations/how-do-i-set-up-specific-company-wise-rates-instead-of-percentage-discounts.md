# How do I set up specific company-wise rates instead of percentage discounts?

To set up specific fixed rates for a company rather than a percentage-based discount, you must use the **Company Rate** master tool. This allows you to link specific rate codes and currencies directly to a corporate account.

### **Steps to Set Up Company-Wise Rates**

1. **Navigate to the Menu:** Go to the **Front Office** module, select **Masters**, then **Rate**, and click on **Company Rate**.
2. **Initiate Setup:** Click **New** to create a new rate structure or **Open** to modify existing ones.
3. **Define Parameters:**
   1. Choose the appropriate **Currency**.
   2. Select the **Company Type** and the specific **Company** from your master list.
   3. Select the **Rate Code** that should be applied to this company.
4. **Assign Rate Type:** Click the **Add** button and use the **search icon** to choose the specific **Rate Type** from the search list.
5. **Save:** Click the **Save** button to successfully add the fixed company rate.

### **Difference from Company Discounts**

While the **Company Rate** master links a pre-defined rate code to a company, the **Company Discounts** master (found under **Masters >> Rate >> Company Discounts**) is used specifically for applying a **Discount %** or a discount amount to a base room rate for a specific company.

**Key Requirement**

As with all company-specific configurations, the company must first be created in the **Company Master** and its status must be set to **"Approved"**. If it remains in the default "unapproved" status, the system will not allow these rates to be utilized during settlements or reservations.
