# How do I cancel a pre-allocated room assignment?

To cancel a pre-allocated room assignment, you should navigate to the **Room Assignment** screen, which is used to pre-allocate or pre-block rooms for arriving guests.

Follow these steps:

1. Go to the **Reservation** menu and select **Room Assignment**.
2. Once the screen displays the list of scheduled arrivals, locate the specific guest or reservation.
3. If a room has already been assigned to that guest, you can cancel the assignment by **clicking the button located next to the respective room number**.

This process allows you to remove the existing allocation so that you can either leave the room unassigned or select a different room manually through the **Room Search** option.
