# Reservation Amendment

### Editing your existing Reservation

* To Edit an existing reservation, Go to Reservation.&#x20;
* Open folder <img src="../../../.gitbook/assets/{357CF8AE-7454-4AC0-B03D-FA6885E19EF6}.png" alt="" data-size="line">from the submenu bar to open the reservation list.
* Select the reservation to be amended from the reservation list.
*   Double click on the reservation to open it.

    <figure><img src="../../../.gitbook/assets/{B344241C-23AF-40F9-9D1A-42965393EA7C}.png" alt=""><figcaption></figcaption></figure>
* Make the necessary changes and save <img src="../../../.gitbook/assets/{96FD2EFE-DCF2-4F37-8A27-948B3D1EB7CF}.png" alt="" data-size="line">the reservation.
*   A pop up message confirming the amendment is displayed. Click Ok to confirm.

    <figure><img src="../../../.gitbook/assets/{EB6F5972-5EDC-40A5-97C6-1F4A5367756D}.png" alt=""><figcaption></figcaption></figure>
