# Reinstate Cancelled Reservation

### Reinstate a Cancelled Reservation for a Guest

**To create a reservation for a guest whose booking has been cancelled:**

When a reservation is cancelled in the system, a unique **cancellation number** is automatically generated. This number serves as a reference for the cancelled booking and can be used for tracking, guest communication, or audit purposes.

<figure><img src="../../../.gitbook/assets/image (894).png" alt=""><figcaption></figcaption></figure>

### Viewing the Cancelled Reservation

* Go to  Reservations>>Sub menu bar >> Reinstate cancel&#x20;
* Click on the Reinstate cancel button.&#x20;

<figure><img src="../../../.gitbook/assets/image (895).png" alt=""><figcaption></figcaption></figure>

* The system navigates to the Reservation Search screen.
* This screen displays only cancelled reservations.&#x20;
  * You can locate a cancelled reservation by searching with either:&#x20;
  * The Reservation Number, or&#x20;
  * The Guest Name.&#x20;

<figure><img src="../../../.gitbook/assets/image (896).png" alt=""><figcaption></figcaption></figure>

* **Double-click** the selected reservation.
* **Verify Guest Details**
  * **Review Information**
    * Confirm that all guest details (name, contact information, address, etc.) are accurate and up to date.
  * **Update if Needed**
    * Make any necessary adjustments or corrections to the guest information before proceeding.
* **Confirm Availability**
  * **Check Availability**
    * Verify that the desired **dates** and **room type** are available for the reservation.
  * **Adjust if Needed**
    * If availability is limited or unavailable, modify the **reservation dates** or **room type** to accommodate the guest’s request.
* Click Save
* Enter the reason to reinstate the reservation.

<figure><img src="../../../.gitbook/assets/image (897).png" alt=""><figcaption></figcaption></figure>

* Click OK to reinstate the reservation.
