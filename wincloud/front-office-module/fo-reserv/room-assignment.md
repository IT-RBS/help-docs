# Room Assignment

Room Assignment is used to pre-allocate rooms for guests scheduled to arrive on a given day. For group reservations, pre-blocking rooms in advance greatly facilitates a smooth and efficient check-in process. If a room has already been assigned, the assignment can be cancelled by clicking the button located next to the respective room number.

### **Steps to Room Assignment**

1. Go to **Front Office>>** **Reservation >> Room Assignment.**
2. Select a date for which the room needs to be assigned.

<figure><img src="../../.gitbook/assets/image (100).png" alt=""><figcaption></figcaption></figure>

* Apply additional filters from the funnel icon next to the date field.

<figure><img src="../../.gitbook/assets/image (101).png" alt=""><figcaption></figcaption></figure>

* The options buttons next to the funnel further customize the record. by adding columns to the chosen record.&#x20;

<figure><img src="../../.gitbook/assets/image (102).png" alt=""><figcaption></figcaption></figure>

3. The chosen options are added to the reservation as an additional column to hold information. This helps the user include instructions while selecting a room.

<figure><img src="../../.gitbook/assets/image (104).png" alt=""><figcaption></figcaption></figure>

4. A room can also be manually assigned using the Room Search option. Click on the magnifier icon next to the Room Number field to search and select a room.

<figure><img src="../../.gitbook/assets/image (106).png" alt=""><figcaption></figcaption></figure>

5. The room search screen appears, and the user can manually select the room from the displayed choices.

<figure><img src="../../.gitbook/assets/image (105).png" alt=""><figcaption></figcaption></figure>
