# Registration Card Print

1. Go to **Front Office>>Reservation >> Registration Card Print**
2. Select a reservation based on check in, check out, reservation arrival date or reservation booking date.
3. Select the arrival date.

<figure><img src="../../.gitbook/assets/image (89).png" alt=""><figcaption></figcaption></figure>

4. To print a plain registration card for a walk-in guest during the check-in process, select “Plain Reg. Card,” then click the “Print” icon to generate and print the registration card.
5. Select the reservation.

<figure><img src="../../.gitbook/assets/image (90).png" alt=""><figcaption></figcaption></figure>

6. Once the Print option is selected, the system will generate the Plain Registration Card.

<figure><img src="../../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure>
