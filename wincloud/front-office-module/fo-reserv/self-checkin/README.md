# Self-Checkin

* [Allow Pre Registration](allow-pre-registration.md)
* [Allow Self Checkin](allow-self-checkin.md)
* [Document Template](document-template.md)

Self-check-in enables a contactless guest onboarding process with pre-validated data, reducing front desk workload and improving efficiency.

* A reservation is created for the guest.
* A pre-registration link is sent to the guest.
* The guest enters personal details, uploads ID proof, photographs, and provides a digital signature.
* The submitted data is populated in the ‘Allow Self Check-in’ window.
* The system validates the data against existing records.
* If new or updated data is detected, the system prompts for confirmation before updating the guest profile.
