# Group Check In

<figure><img src="../../.gitbook/assets/gg1.png" alt=""><figcaption></figcaption></figure>

1.Click on the search icon in the Group field to select the referral group of the group reservation.

<figure><img src="../../.gitbook/assets/gg2.png" alt=""><figcaption></figcaption></figure>

2.If the reservation number is known, then enter the reservation number to select the reservation to be checked in.

3.Another way to select the reservation is by using the funnel. A Funnel Filter is provided to search by Guest Name. After a group is selected, if a single person has to be selected, use the funnel.

<figure><img src="../../.gitbook/assets/GG3.png" alt=""><figcaption></figcaption></figure>

Click on the Funnel Filter icon to refine your search.

5.A pop-up window will appear, prompting you to enter the guest's name to be checked in.

6.Enter the required details to filter and quickly locate the reservation.

<figure><img src="../../.gitbook/assets/GG4.png" alt=""><figcaption></figcaption></figure>

The Reserved and check-in button displays information about the selected Group Reservation, such as its Total Rooms booked and Total Pax.

· Example below says 4 rooms are reserved and each room will have 5 pax.

· It also says that one room has been checked in, and the number of persons in the checked-in room is 5.

<figure><img src="../../.gitbook/assets/GG6.png" alt=""><figcaption></figcaption></figure>

8.The auto allocation button can be applied to allocate the rooms if the rooms are not allocated. This functionality helps in allocating available rooms automatically.

9.It is possible to select or search by utilizing the search facility displayed next to **the Room No. column.**

<figure><img src="../../.gitbook/assets/GG7.png" alt=""><figcaption></figcaption></figure>

11.A new room search window will pop up and prompt Room Selection.

<figure><img src="../../.gitbook/assets/GG8.png" alt=""><figcaption></figcaption></figure>

11.Click on the required/ available room and click Select.

12.The check boxes can be used to select pax-wise or room-wise check-in of the selected rooms, after which the Save button is selected to check-in all rooms at one go.

<figure><img src="../../.gitbook/assets/GG9.png" alt=""><figcaption></figcaption></figure>

13.Click the save button to complete the group check-in.
