# How to configure overbooking parameters for room type

**How do I configure overbooking parameters for a room type?**

To configure **overbooking parameters** for a specific **room type**, use the **Room Type Master** in the **Front Office** module.

#### **Steps to Configure Overbooking**

1. **Navigate to the Menu:**\
   Go to **FRONT OFFICE → MASTERS → ROOMS → ROOM TYPE**.\
   Click **New** to create a new room type or select an existing room type to modify.
2. **Enable Overbooking:**\
   Select the **Overbooking** checkbox to allow the system to accept reservations beyond the available physical rooms for that room category.
3. **Set the Overbooking Percentage:**\
   Enter the **overbooking percentage** that will be permitted for the room type.
4. **Select the System Parameter:**\
   Choose the appropriate **system parameter** that determines how the overbooking logic is applied.
5. **Define Allotment Limits (Optional):**\
   If required, specify the **maximum allotted persons per room** to apply additional occupancy restrictions.
6. **Save the Configuration:**\
   Click the **Save** icon to apply the overbooking settings.

While configuring the room type, you can also define the **maximum occupancy** by setting separate limits for **adults** and **children**.
