# How do I specifically configure the Tab Sheet?

The Tab Sheet is a highly versatile tool that serves as a single source for viewing all room-based postings and billings. To specifically configure it to meet your needs, follow these steps:

1. **Configure Revenue Columns (Masters)**

Before running the report, you must define which financial data you want to track. The Tab Sheet is built based on the "Tab sheet report settings" in the Masters section.

* **Add Revenue Heads:** You can add an unlimited (‘n’) number of columns corresponding to different revenue heads (e.g., Room Tariff, F\&B, Laundry).
* **Customisation:** These settings determine exactly which revenue streams are displayed as individual columns when you generate the report.

2. **Select a View Mode**

Once your master settings are defined, you can filter the report based on the status of the guest:

**Guest Summary:** Selecting this provides a report for a specific, user-selected period.

**Current Guest:** This filter isolates and displays only the guests currently in-house on the account date.

**Checked Out:** Use this to view data for guests who have already departed within a chosen period.

3. **Add Detailed Information Columns**

After choosing a view mode, you can further tailor the report by adding specific detail columns:

* **Personal and Stay Details:** You can include columns for the Guest name, Pax details, Company name, and other personal information.
* **Accounting Data:** For checked-out guests, you can specifically enable a column for "Brought Fwd. Amt." (Brought Forward Amount).
* **Instructions:** You can also choose to display reservation instructions within the report to provide context for specific billings.

By using these master settings and report filters, the Tab Sheet allows you to create a consolidated view of all financial transactions tied to a room.
