# company-wise rates instead of percentage discounts

**How do I set up specific company-wise rates instead of percentage discounts?**

To configure **fixed company-wise rates** instead of applying percentage discounts, use the **Company Rate** master. This allows you to link specific **rate codes** and **currencies** directly to a corporate account.

#### **Steps to Set Up Company-Wise Rates**

1. **Navigate to the Menu:**\
   Go to:\
   **FRONT OFFICE → MASTERS → RATE → COMPANY RATE**
2. **Initiate Setup:**
   * Click **New** to create a new company rate structure.
   * Click **Open** to modify an existing configuration.
3. **Define Parameters:**
   * Select the appropriate **Currency**.
   * Choose the **Company Type** and the required **Company** from the master list.
   * Select the **Rate Code** to be applied to the company.
4. **Assign Rate Type:**
   * Click **Add**.
   * Use the **Search** icon to select the required **Rate Type** from the list.
5. **Save the Configuration:**\
   Click **Save** to add the fixed company-wise rate.

#### **Difference Between Company Rate and Company Discounts**

* **Company Rate Master:**\
  Links a predefined **rate code** directly to a company for fixed company-specific pricing.
* **Company Discounts Master**\
  (**MASTERS → RATE → COMPANY DISCOUNTS**) is used to apply:
  * A **Discount Percentage (%)**, or
  * A **Discount Amount**\
    against a base room rate for a specific company.

#### **Key Requirement**

Before creating company-specific rates:

* The company must first be created in the **Company Master**.
* The company status must be set to **Approved**.

If the company remains in the default **Unapproved** status, the configured rates cannot be used for reservations or settlements.
