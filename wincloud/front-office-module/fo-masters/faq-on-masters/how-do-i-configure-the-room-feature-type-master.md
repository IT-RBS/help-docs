# How do I configure the Room Feature Type master?

To configure the Room Feature Type master, which allows you to create a predefined set of amenities for your property, follow these steps:

1\. **Navigate to the Menu:** Go to the FRONT OFFICE module, select MASTERS, then ROOMS, and finally ROOM FEATURE.

2\. **Create a New Feature:** Click the NEW button.

3\. **Enter Details:** Create a unique ID and a name for the specific room feature (e.g., "Sea View" or "Mini Bar").

4\. **Save:** Click the Save button to store the new feature.

**Modifying Room Features**

* **Access the Feature:** To make changes, click the OPEN button and select the specific Feature ID you wish to amend.
* **Edit Constraints:** While modifying, the system only allows you to edit the name of the feature; the ID cannot be changed.
* **Finalize Changes:** Click the Save button once your modifications are complete.

Once these features are established in the master, they can be added to specific rooms within the Room Master tool or viewed in the footer of the Room Search Screen during reservation creation.
