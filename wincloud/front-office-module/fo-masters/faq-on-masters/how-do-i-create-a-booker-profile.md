# How Do I Create a Booker Profile

**How do I create a Booker Profile?**

To create a **Booker Profile**, follow these steps:

1. **Navigate to the Booker Master:**\
   Go to the **Front Office** module → **Masters** → **Booker Profile**.\
   Alternatively, you can start the process from the **Booker Search Screen**.
2. **Add a New Profile:**\
   Click the **New** or **Add** button located at the bottom of the screen.
3. **Enter Booker Details:**\
   Fill in the required information, including:
   * **Booker Name**
   * **Title**
   * **Company**
   * **Telephone**
   * **Email**
   * **Mobile**
   * **Address**
   * **City**
4. **Save the Profile:**\
   Click **OK** or **Save** to complete the profile creation.

To modify an existing profile:

* Open the **Booker Search Screen**.
* Select the required record.
* Click **Amend** to update the details.
