# What are the rules for overbooking percentages

**What are the rules for overbooking percentages?**

To configure **overbooking percentages**, you must set the rules in the **Room Type Master** under the **Front Office** module.

The configuration rules are as follows:

#### **1. Enable Overbooking**

* For each room category where overbooking is permitted, enable the **Overbooking** option.

#### **2. Enter the Overbooking Percentage**

* After enabling the feature, specify the **overbooking percentage** allowed for that room type.
* This determines how many additional reservations can be accepted beyond the available physical rooms for that category.

#### **3. Select the Overbooking Parameter**

* Choose the appropriate **system parameter** that defines how the system applies and manages the configured overbooking limits.

#### **4. Define Occupancy Limits**

Overbooking rules work alongside other room type settings, including:

* **Maximum number of adults** allowed.
* **Maximum number of children** allowed.
* **Maximum occupancy** (total persons permitted) for the room type.

Configuring these settings ensures that overbooking is managed according to the property's operational policies while maintaining room occupancy limits.
