# Can I link multiple features to a single room number?

Yes, you can link multiple features to a single room number in the system.

This process is managed within the Room Master tool by following these steps:

1. **Access the Master:** Navigate to **FRONT OFFICE > MASTERS > ROOMS > ROOM MASTER.**
2. **Select the Room:** Open a new room or select an existing one to modify its details.
3. **Add Multiple Features:**

* Locate the **"FEATURE DETAILS"** section at the bottom of the room configuration screen.
* Click the **search icon** to select a feature from your predefined list.
* To add additional features to the same room, click the plus icon (+) to create more rows and select more features.

4. **Manage Features:** If you need to remove a feature, you can use the delete icon next to the specific feature row.
5. **Finalise:** Click the Save icon to store the links.

Once these features are linked, they will automatically appear in the footer of the Room Search screen when that specific room is highlighted during the reservation process, helping staff identify room amenities at a glance. Please note that these features must first be created in the Room Feature master before they can be assigned to individual rooms.
