# How do I link a Rate Code to a company?

To link a **Rate Code** to a specific company, you must use the **Company Rate** master tool, which allows you to establish a fixed pricing structure for corporate accounts.

**Steps to Link a Rate Code to a Company**

1. **Navigate to the Menu:** Go to the **Front Office** module, select **Masters**, then **Rate**, and finally **Company Rate**.
2. **Initiate Setup:** Click **New** to create a new link or **Open** to modify an existing configuration.
3. **Define the Parameters:**
   1. Choose the appropriate **Currency**.
   2. Select the **Company Type** and then select the specific **Company** from your master list.
   3. Select the **Rate Code** that you wish to associate with this company.
4. **Assign the Rate Type:** Click the **Add** button and use the **search icon** to choose the specific **Rate Type** from the search list.
5. **Save:** Click the **Save** button to successfully add the fixed company rate.

**Important Prerequisites**

* **Approved Status:** Before linking a rate, the company must exist in the **Company Master** and its status must be manually changed to **"Approved"**. By default, new companies are marked "unapproved," and the system will not allow their assigned rates or settlements to be used until this is updated.
* **Company Type:** Ensure the **correct company type** (e.g., Corporate, Travel Agent) is selected during the setup so that financial data and settlements reflect accurately in reports.

**Amending for In-House Guests**

If a guest is already checked in and you need to link a different company or rate code to their specific stay, you can do so by going to **Front Desk > In-House Guest Amend** and selecting **Rate Edit** to update the **Company** and **Rate Typ**e details.
