# How do I define a Paymaster room type

**How do I define a Paymaster room type?**

To define a **Paymaster (PM) room type**, configure it in the **Room Type Master** under the **Front Office** module.

#### **Steps to Define a Paymaster Room Type**

1. **Navigate to the Menu:**\
   Go to **FRONT OFFICE → MASTERS → ROOMS → ROOM TYPE**.
2. **Create a New Record:**\
   Click the **New** button to create a new room type category.
3. **Enter Category Details:**\
   Provide the required:
   * **Room Type ID**
   * **Room Type Name**
4. **Enable Paymaster Type:**\
   Select the **Paymaster Type** checkbox.\
   This identifies the room type as a Paymaster account used for internal, temporary folio, or clearing purposes rather than standard guest accommodation.
5. **Save the Configuration:**\
   Click the **Save** icon to add the new Paymaster room type.

#### **Context and Use Cases**

* **Internal Accounting:**\
  Paymaster rooms are commonly used for:
  * Temporary folios
  * Recording charges before check-in
  * Split billing
  * Third-party service charges
* **Monitoring:**\
  Paymaster rooms can be filtered in reports such as the **High Balance Report** to monitor outstanding balances in internal accounts.
* **In-House Tracking:**\
  In the **Guest Folio** query, the dedicated **PM** button allows users to view ledger details specifically for Paymaster rooms.
