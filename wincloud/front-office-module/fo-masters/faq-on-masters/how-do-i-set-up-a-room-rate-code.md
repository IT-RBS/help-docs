# How do I set up a Room Rate Code?

To set up a Room Rate Code, follow these steps:

1. **Navigate to the Menu:** Go to **Front Office >> Masters >> Rate >> Room Rate Code** and select New.
2. **Add New Code:** Click the Add button to begin creating a new entry.
3. **Define Core Details**: Enter the Rate Code Id, Rate Code Name, and specify the Nature of the rate.
4. **Configure Dependencies:** Click on Master Rate of Dependent to define how this rate might interact with or depend on other rates.
5. **Set Weekend Parameters:** Use the provided screen to update the Week End Days applicable to this Room Rate code.
6. **Finalize:** Click the Save button to successfully update and store the new rate code.

Once these codes are established, they can be utilized in several ways across the system:

* **Company Rates:** You can link a specific Rate Code to a company profile to provide fixed corporate pricing.
* **Daily Rates:** Rate codes are selected when defining or viewing daily rates in the Bar calendar.
* **Derived Rates:** You can use an existing rate code as a base for Derived Rate Codes, which automatically calculate new prices based on stay duration or market segments.
* **Analysis:** The system uses these codes to generate Rate Code Analysis reports, helping you track revenue contribution and room nights by rate category.
