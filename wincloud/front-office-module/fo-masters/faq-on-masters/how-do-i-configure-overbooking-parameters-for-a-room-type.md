# How do I configure overbooking parameters for a room type?

To configure overbooking parameters for a specific room category, you must access the Room Type master within the Front Office module.

**Steps to Configure Overbooking:**

1. **Navigate to the Menu:** Go to **FRONT OFFICE > MASTERS > ROOMS > ROOM TYPE** and click on **NEW** to create a new category or select an existing one.
2. **Enable Overbooking:** Locate and tick the overbooking checkbox to allow the system to accept more reservations than there are physical rooms for that specific category.
3. **Set the Percentage:** Enter the required overbooking percentage that the system should allow.
4. **Select Parameters:** You must select one of the system parameters to determine how the overbooking logic is applied.
5. **Define Allotment Limits** (Optional): If necessary, enter the count for maximum allotted persons per room to impose further restrictions.
6. **Finalise**: Click the Save icon to apply these settings to the room type.

While configuring these settings, you can also set the maximum count of persons permitted for the category, specifying separate limits for **adults and children.**
