# How do I link features to rooms in the Room Master?

To link features to specific rooms within the **Room Master**, follow these steps:

1. **Navigate to the Menu:** Go to **FRONT OFFICE > MASTERS > ROOMS > ROOM MASTER**.
2. **Select the Room:**
   1. If you are creating a new room, click **NEW**.
   2. To add features to an existing room, click the **open** icon and select the specific room number from the drop-down list.
3. **Access Feature Details:** Locate the **“FEATURE DETAILS”** section within the room configuration screen.
4. **Add Features:** Click the search icon under the **Feature Details** section to select and add the predefined features you created in the Room Feature master. To add multiple features, click the "plus" icon to create additional rows.
5. **Remove Features:** If you need to remove a linked feature, click the **delete** icon next to that specific feature row.
6. **Save:** Click the **save** icon to finalize the linkage and update the room record.

Once linked, these features will automatically be displayed in the **Room Feature** section at the footer of the **Room Search Screen** when you select that room during the reservation process.
