# How to Configure the Tab Sheet

**How do I specifically configure the Tab Sheet?**

The **Tab Sheet** is a versatile tool that provides a consolidated view of all **room-based postings and billings**. To configure it according to your requirements, follow these steps:

#### **1. Configure Revenue Columns (Masters)**

Before generating the report, define the financial information you want to track. The Tab Sheet is configured through the **"Tab Sheet Report Settings"** in the **Masters** section.

* **Add Revenue Heads:**\
  You can add an unlimited number of columns for different revenue heads, such as:
  * Room Tariff
  * Food & Beverage (F\&B)
  * Laundry
  * Other charges
* **Customization:**\
  These settings control which revenue streams appear as individual columns when the report is generated.

#### **2. Select a View Mode**

After configuring the master settings, filter the report based on guest status:

* **Guest Summary:**\
  Generates a report for a specific period selected by the user.
* **Current Guest:**\
  Displays only guests currently staying in-house on the account date.
* **Checked Out:**\
  Shows details of guests who have already departed within the selected period.

#### **3. Add Detailed Information Columns**

After selecting the view mode, customize the report further by adding required details:

* **Personal and Stay Details:**\
  Include columns such as:
  * Guest Name
  * Pax Details
  * Company Name
  * Other personal information
* **Accounting Data:**\
  For checked-out guests, enable the **"Brought Fwd. Amt." (Brought Forward Amount)** column if required.
* **Instructions:**\
  Display reservation instructions to provide additional context for specific billings.

By using the **Tab Sheet Report Settings**, view filters, and detail column options, the Tab Sheet can be configured to provide a complete view of all financial transactions associated with each room.
