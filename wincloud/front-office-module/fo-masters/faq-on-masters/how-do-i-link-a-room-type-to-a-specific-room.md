# How do I link a room type to a specific room?

To link a room type to a specific room, you must use the **Room Master** tool located in the Front Office module. This tool serves as the primary interface for creating rooms and associating them with their defined categories.

**Steps to Link a Room Type**

1. **Navigate to the Menu:** Go to **FRONT OFFICE > MASTERS > ROOMS > ROOM MASTER**.
2. **For a New Room:**
   1. Click on **NEW** to begin creating a new room record.
   2. Enter the room details and, in the provided field, add the corresponding **Room Type** from the list.
   3. Click the **Save** icon to finalize the link.
3. **For an Existing Room:**
   1. If you need to change the room type of an existing room, select the specific **room number** from the drop-down list.
   2. Select the new **Room Type** from the corresponding drop-down menu.
   3. Click **Save** to update the record.

**Important Considerations**

* **Modification Limits:** While the system allows you to change the **room type** associated with a room, you cannot change a room number once it has been created.
* **Deletion Policy:** A room cannot be deleted if it has already been referenced in any transactions.
* **Room Building:** During this process, you also have the option to link the room to a specific **Room Building** and enable the **sharer room** option if applicable.
