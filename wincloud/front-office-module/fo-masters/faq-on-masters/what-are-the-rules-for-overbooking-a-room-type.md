# What are the rules for overbooking a room type

**What are the rules for overbooking a room type?**

To manage overbooking for a specific **room type**, configure the settings in the **Room Type Master** under the **Front Office** module. If your property allows reservations beyond the available physical inventory, enable the **Overbooking** option for that room category.

Once overbooking is enabled, the following rules apply:

#### **1. Enter the Overbooking Percentage**

* Specify the **overbooking percentage** permitted for the selected room type.
* This defines the allowable number of reservations beyond the available rooms.

#### **2. Select the System Parameter**

* Choose the appropriate **system parameter** that determines how the overbooking logic is applied.

#### **3. Configure Occupancy Limits**

* Define the maximum occupancy allowed for the room type, including:
  * **Maximum Adults**
  * **Maximum Children**

#### **4. Specify Maximum Allotted Persons**

* If required, set the **maximum allotted persons per room** to enforce additional occupancy restrictions.

These settings allow the system to calculate room availability accurately while supporting controlled overbooking based on your property's operational policies.
