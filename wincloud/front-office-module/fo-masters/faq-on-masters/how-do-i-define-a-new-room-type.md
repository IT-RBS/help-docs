# How do I define a new Room Type?

To define a new Room Type, you must access the Room Type master within the Front Office module. This master allows you to categorise rooms and configure specific parameters like occupancy limits and overbooking rules.

**Follow these steps to create a new Room Type:**

1. **Navigate to the Menu:** Go to the **FRONT OFFICE** module, select **MASTERS,** then **ROOMS**, and click on **ROOM TYPE** followed by **NEW.**
2. **Configure Occupancy:** Enter the maximum count of persons permitted for the category. You can set these limits separately for adults and children.
3. **Set Overbooking Rules:** If the property allows for more bookings than physical rooms for this category, enable the overbooking option, enter the allowed percentage, and select the required parameter.
4. **Additional Configurations:**

* Enter the total count of maximum allotted persons per room if specific restrictions apply.
* Enable the Paymaster type checkbox if this room type is being created for internal or clearing purposes.
* Mention any specific room facilities associated with this category.

5. **Finalize:** Click the Save icon to create the room type.

Once a Room Type is defined, you can link it to specific room numbers within the Room Master tool.
