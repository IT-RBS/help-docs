# Category Employee

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Masters**.
3. In the **Employee** menu, select **Category Employee.**&#x20;

**Category Employee**

User can create employee for the property, and add details such as  category, employee ID, Employee Name, Mobile and email as shown below
