# GUEST REFERENCE TYPE

Guest Reference Type refers to the classification used to identify how a guest is associated with or referred to a property, such as through a corporate account, travel agent, online booking, or walk-in, helping the hotel track bookings, manage relationships, and analyze guest sources efficiently.
