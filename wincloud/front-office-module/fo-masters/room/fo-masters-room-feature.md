# ROOM FEATURE

ROOM FEATURE

Room feature tool helps to create a predefined set of amenities available in the property. All the features can be created here and can be later added to the corresponding rooms

1.To create room features, go to “**FRONT OFFICE**” module MASTERS ROOMS ROOM FEATURE NEW

2\. Create an ID and a name for the room feature and click ![](<../../../.gitbook/assets/0 (189).png>)

3\. To modify created room feature click ![](<../../../.gitbook/assets/2 (96).png>) and select the feature ID.

4\. Click ![](<../../../.gitbook/assets/10 (7).png>) once changes are made

5\. While modifying, only the name of the feature can be edited, the ID cannot be changed.
