# ROOM MASTER

Steps to create a room

**ROOM MASTER**

The Room master is a tool where the rooms are created; here the rooms are linked with the corresponding room types. The room numbers created once cannot be changed but the room type can be changed. A created room cannot be deleted if that room has been referred for transactions.

1.To create a room, go to **“FRONT OFFICE”** module MASTERS ROOMS ROOM MASTER NEW

2\. Create a room as shown in the below screenshot.
