# ROOM TYPE

ROOM TYPE

The Room type is created to separate rooms according to their categories. Here the maximum count of persons permitted under each category can be configured. It can also be configured separately for adults and children.

1.To create room types, go to “**FRONT OFFICE**” module MASTERS ROOMS ROOM TYPE NEW

2\. Create a room type as shown in the below screenshot

![](<../../../.gitbook/assets/Screenshot 2023-09-26 122451.png>)

3\. If overbooking is required for the particular room type, enable

![](<../../../.gitbook/assets/1 (200).png>)

4\. Once it is applied, enter the percentage required and select any one of the parameters

![](<../../../.gitbook/assets/2 (137).png>)

5\. Give the count of maximum allotted persons per room, if required

![](<../../../.gitbook/assets/3 (103).png>)

6\. If the created room type is a paymaster type then enable

![](<../../../.gitbook/assets/4 (7).png>)

7\. Room facilities to mention, if any

![](<../../../.gitbook/assets/5 (74).png>)

8\. Click ![](<../../../.gitbook/assets/6 (27).png>) once room type is created
