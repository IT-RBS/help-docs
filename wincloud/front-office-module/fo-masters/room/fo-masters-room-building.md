# ROOM BUILDING

ROOM BUILDING

Room building tool helps you add towers or blocks situated in the property. These help in categorizing rooms block-wise while creating them. Buildings created here help to view block wise room occupancy reports easily.

1.To create room buildings, go to “**FRONT OFFICE**” module MASTERS ROOMS ROOM BUILDING NEW

2\. Create a building ID and a name for the room feature and click ![](<../../../.gitbook/assets/0 (189).png>)

3\. To modify created room building, click ![](<../../../.gitbook/assets/2 (96).png>) and select the room building ID.

4\. Click ![](<../../../.gitbook/assets/10 (7).png>) once changes are made.

5\. While modifying, only the name of the building can be edited, the ID cannot be changed.
