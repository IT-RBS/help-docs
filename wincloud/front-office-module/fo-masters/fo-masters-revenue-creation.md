# REVENUE&#x20;

**REVENUE CREATION**

Revenue is created in the software to store revenue sales happened through the software. Each of the revenue collected in the software can be created as per the revenue’s name. Revenue created holds the data of total value collected on a daily basis.

1.To create revenue in “FRONT OFFICE” go to “**FRONT OFFICE**” module MASTERS REVENUE&#x20;

2\. Create the revenue required as shown in the below screenshot

![](<../../.gitbook/assets/Screenshot 2023-08-16 144649.png>)

3.The revenues created here can be assigned with a tax structure which gets calculated when the corresponding transaction takes place

4.Revenues created here are applicable for all the modules of the software

5.Users can link the outlets&#x20;

6.Click “**OPEN**” to amend any details of an existing revenue, and click ![](<../../.gitbook/assets/1 (169).png>) to select the revenue

7.Click ![](<../../.gitbook/assets/2 (175).png>) once changes are made
