# GROUP TYPE

**Steps to create a Group Type.**

**Group Type**

Defines guest groups using a Group Type ID and Group Type Name, with optional sub-groups for further classification and reporting.

1.To create a room, go to **“FRONT OFFICE”** module MASTERS GROUP GROUP TYPE NEW

2.Click on Add button we can able to add the new Group Type.
