**Group**

**Group Master** record must first be created in the system. The Group Master serves as the primary record that consolidates and manages all related reservations under a single group. Once the Group Master is created, it must be linked with the relevant individual reservations. Based on these linked records, the system will allow the creation of **Group Bookings**, enabling centralized management of reservations, billing, and reporting for the entire group.
