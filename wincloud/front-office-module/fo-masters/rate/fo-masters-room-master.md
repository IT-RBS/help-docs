# ROOM MASTER

ROOM MASTER

The Room master is a tool where the rooms are created; here the rooms are linked with the corresponding room types. The room numbers created once cannot be changed but the room type can be changed. A created room cannot be deleted if that room has been referred for transactions.

1.To create a room, go to “**FRONT OFFICE**” module MASTERS ROOMS ROOM MASTER NEW

2\. Create a room as shown in the below screenshot.

![](<../../../.gitbook/assets/0 (51).png>)

3\. Add the corresponding room type, room building and also enable the sharer room option if the room is eligible

![](<../../../.gitbook/assets/1 (13).png>)

4\. Add the features of the room by selecting ![](<../../../.gitbook/assets/2 (108).png>) icon under “FEATURE DETAILS” to add more features click on ![](<../../../.gitbook/assets/3 (57).png>).

5\. To delete any of the added features click ![](<../../../.gitbook/assets/4 (131).png>) icon.

6\. To change the room type of a particular room number, click ![](<../../../.gitbook/assets/5 (1).png>) select the room number from the drop down and click on ![](<../../../.gitbook/assets/6 (83).png>).

7\. Once enabled select the new room type from the drop down.

![](<../../../.gitbook/assets/7 (71).png>)

8\. Click ![](<../../../.gitbook/assets/8 (36).png>) when changes are made.
