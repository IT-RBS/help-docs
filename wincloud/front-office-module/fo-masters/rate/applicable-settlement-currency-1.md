# APPLICABLE SETTLEMENT CURRENCY

**APPLICABLE SETTLEMENT CURRENCY**

1.To create a room, go to **“FRONT OFFICE”** module MASTERS RATE APPLICABLE SETTLEMENT CURRENCY NEW.

2.Click on open button we can able to see the Company Discounts/Rate.

<figure><img src="../../../.gitbook/assets/a1 (2).png" alt=""><figcaption></figcaption></figure>

3.Click on Search Icon we can able to see the Currency Name  by chose we can able to add the rate currency

<figure><img src="../../../.gitbook/assets/a2 (3).png" alt=""><figcaption></figcaption></figure>

4.Enter the Discount % and click on search icon.

<figure><img src="../../../.gitbook/assets/a3 (2).png" alt=""><figcaption></figcaption></figure>

5.Click on Link Revenue It will shows the Revenue list by clicking the Revenue will be added successfully.

<figure><img src="../../../.gitbook/assets/a4 (2).png" alt=""><figcaption></figcaption></figure>

6.click on Save button it will be updated successfully.
