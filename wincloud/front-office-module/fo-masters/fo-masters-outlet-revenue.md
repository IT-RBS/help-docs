# OUTLET REVENUE

**OUTLET REVENUE**

Outlet revenue option is used to link the created revenues with the corresponding outlets. One or more revenues can be linked to a particular outlet

1.To link the revenues with an outlet, ” go to “**FRONT OFFICE**” module MASTERS OUTLET REVENUE OPEN

![](<../../.gitbook/assets/Screenshot 2023-08-16 145311.png>)

2\. Select the outlet from the drop down![](<../../.gitbook/assets/1 (240).png>)

3\. Select ![](<../../.gitbook/assets/2 (31).png>) icon under the revenue heading and search for the corresponding revenue

<img src="../../.gitbook/assets/Screenshot 2023-08-16 145344.png" alt="" width="229">

![](<../../.gitbook/assets/Screenshot 2023-08-16 145444.png>)
