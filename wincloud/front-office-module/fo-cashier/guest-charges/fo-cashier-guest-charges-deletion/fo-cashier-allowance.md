# Allowance Creation

### **Allowance Creation**

**Steps to Create an Allowance**

1. Go to **Front office>>Cashier >> Guest Charges.**

<figure><img src="../../../../.gitbook/assets/image (156).png" alt=""><figcaption></figcaption></figure>

2\. Guest charges can be based on the reservations and rooms allocated.&#x20;

<figure><img src="../../../../.gitbook/assets/image (157).png" alt=""><figcaption></figcaption></figure>

3. Select the room number for which the Allowance has to be created from the room field using the magnifier.

<figure><img src="../../../../.gitbook/assets/image (158).png" alt=""><figcaption></figcaption></figure>

4. Double-click on the guest record in the in-house guest list.

<figure><img src="../../../../.gitbook/assets/image (159).png" alt=""><figcaption></figcaption></figure>

5. Click the Outlet field to open the Outlet window. Double-click the appropriate outlet to select it. Once the outlet is selected, the PMS will display the revenue names linked to that outlet.
6. &#x20;Click the Allowance button. The user can then select the revenue name against the “Allowance”. &#x20;

<figure><img src="../../../../.gitbook/assets/image (160).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../../../.gitbook/assets/image (162).png" alt=""><figcaption></figcaption></figure>

7. Enter the amount to be posted.

<figure><img src="../../../../.gitbook/assets/image (163).png" alt=""><figcaption></figcaption></figure>

8. Finally, click the Save button ![](<../../../../.gitbook/assets/image (165).png>)in the toolbar at the top of the Guest Charges window to update the entry in the guest ledger.
