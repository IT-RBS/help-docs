# Guest Charges Deletion

### **Guest Charges Deletion**

This option is used to Delete the posted charges from guest ledger.

#### **Steps to Guest Charges**

1.  Go to **Front Office>>Cashier>> Guest Charges.**

    <figure><img src="../../../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure>
2.  Click on the **view** button to see all the guest charges posted already

    <figure><img src="../../../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>
3.  Once the user clicks the **view button**, the following screen appears from where you can select the guest.

    <figure><img src="../../../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>
4.  Select the guest and click on the Delete button as shown below to delete the charge posted

    <figure><img src="../../../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>
5.  Once the delete button is selected, provide the reason for deleting the record. \
    Click on **OK** and the charges will be deleted.<br>

    <figure><img src="../../../../.gitbook/assets/image (1105).png" alt=""><figcaption></figcaption></figure>
