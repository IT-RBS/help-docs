# Guest Charges

Use this option to post charges to the guest ledger in cases where revenue has not been recorded(missed). This function can be performed from the Cashier Menu, Calendar, or Flash screen.

1. Select Reservation, Room, Miscellaneous, or Checked-out from the _For_ field. This field specifies the category for which the guest charges are being posted. Based on the selection, the subsequent field will be displayed accordingly.

<figure><img src="../../../.gitbook/assets/image (77).png" alt=""><figcaption></figcaption></figure>

2. Click on the magnifier in the room field. Since '_Room'_ is selected in the '_For'_ field, clicking the magnifier icon will display the room list for selection.&#x20;

<figure><img src="../../../.gitbook/assets/image (78).png" alt=""><figcaption></figcaption></figure>

3. Select the appropriate option in the _For_ field and choose the Reservation Number or Room Number to which the charges need to be posted.&#x20;
4. Select the required **outlet** using the magnifier from the outlet field.
5. The system will display the **revenue names** linked to the selected outlet.

<figure><img src="../../../.gitbook/assets/image (79).png" alt=""><figcaption></figcaption></figure>

6. Choose the appropriate **revenue name**.

<figure><img src="../../../.gitbook/assets/image (80).png" alt=""><figcaption></figcaption></figure>

7. Enter the **amount** to be posted.
8. The taxes are automatically populated.

<figure><img src="../../../.gitbook/assets/image (81).png" alt=""><figcaption></figcaption></figure>

9. Click **Save** <img src="../../../.gitbook/assets/image (82).png" alt="" data-size="line">on the toolbar to post the charges to the guest ledger.

<figure><img src="../../../.gitbook/assets/image (1023).png" alt=""><figcaption></figcaption></figure>

10. Under the **Guest Charges** option, the user can post telephone charges, laundry charges, and other miscellaneous charges to the guest ledger as required. This option also allows the user to post allowances, if applicable.

**Important Note:** Posting any amount to the guest ledger is possible under the guest charges based on the accounting date. The user cannot select the previous day’s charges in this guest charge.
