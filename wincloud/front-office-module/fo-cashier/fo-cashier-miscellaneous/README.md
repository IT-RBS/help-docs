# Miscellaneous Sales

### **Miscellaneous Sales**

This option is used to make bills for outsiders. By using this option, user can create and settle bills for an outsider

#### **Steps to Miscellaneous Sales**

1. Go to Front Office >>**Cashier  Guest Charges.**
2.

    <figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>
3. From the 'For' Field select Miscellaneous.

<figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

4\. Select the specific outlet to which revenue will be charged from the Outlet field.

<figure><img src="../../../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

5. Double-click the specific outlet.&#x20;
6. Enter the charges in the amount field. The corresponding taxes and charges are populated automatically.
7.  The user can add the settlement methods by clicking on the Plus button ![](<../../../.gitbook/assets/image (43).png>)next to the settlement mode.

    <figure><img src="../../../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure>
8.  Once the settlement methods are added, click the save button ![](<../../../.gitbook/assets/image (45).png>).

    <figure><img src="../../../.gitbook/assets/image (44).png" alt=""><figcaption></figcaption></figure>
9. Confirmation message of transaction being recorded appears.

<figure><img src="../../../.gitbook/assets/image (46).png" alt=""><figcaption></figcaption></figure>
