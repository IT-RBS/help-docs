# Miscellaneous Sales Deletion

### **Miscellaneous Sales Deletion**

1.Go to Front Officed>>**Cashier >> Guest charges.**

<figure><img src="../../../.gitbook/assets/image (1049).png" alt=""><figcaption></figcaption></figure>

2. Click on the View button ![](<../../../.gitbook/assets/image (1050).png>)to select the bill number that you need to delete.
3. Select 'Miscellaneous' from the drop-down list under the 'For' field in the Guest Charge Search screen.
4.  The system displays all the miscellaneous transactions. Select the bill you want to delete.

    <figure><img src="../../../.gitbook/assets/image (1051).png" alt=""><figcaption></figcaption></figure>
5.  Once you select the transaction record, the delete button <img src="../../../.gitbook/assets/image (1053).png" alt="" data-size="line">is displayed on the toolbar.

    <figure><img src="../../../.gitbook/assets/image (1052).png" alt=""><figcaption></figcaption></figure>
6. Click on the Delete button. Once the delete button is clicked, the system prompts for cancellation reason.![](<../../../.gitbook/assets/image (1054).png>)



7. A message confirming the deletion pops up next to the toolbar.![](<../../../.gitbook/assets/image (1055).png>)
