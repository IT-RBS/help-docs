# Temp Folio Settlement

This functionality helps the user settle the transactions created under Temp Folio.

#### **To settle a temp Folio:**

1.  Go to Front Office>>Cashier>>Temp Folio Settlement

    <figure><img src="../../.gitbook/assets/image (1149).png" alt=""><figcaption></figcaption></figure>
2.  Search for Temp Folios created using the magnifier in the Temp Folio field.

    <figure><img src="../../.gitbook/assets/image (1151).png" alt=""><figcaption></figcaption></figure>
3.  Select the guest/ Folio.

    <figure><img src="../../.gitbook/assets/image (1152).png" alt=""><figcaption></figcaption></figure>
4.  Click on the drop-down arrow under the 'Settle Mode' to select an appropriate settlement mode.

    <figure><img src="../../.gitbook/assets/image (1154).png" alt=""><figcaption></figcaption></figure>
5.  Once the settlement mode is selected, click 'Save'.

    <figure><img src="../../.gitbook/assets/image (1155).png" alt=""><figcaption></figcaption></figure>
