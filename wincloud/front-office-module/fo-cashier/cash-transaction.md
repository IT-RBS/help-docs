# Cash transaction

The Cash Transaction module is used to view all cash transactions recorded on a specific day, providing a clear overview for tracking and reconciliation

### Creating a Cash Transaction Report.

To list out cash transactions, go to Front Office>> Cashier>> Cash Transactions

<figure><img src="../../.gitbook/assets/image (1157).png" alt=""><figcaption></figcaption></figure>

1\. Choose the Transaction type from the TRN field. Check the boxes against the transaction types you want to list out. Click OK.

<figure><img src="../../.gitbook/assets/image (1158).png" alt=""><figcaption></figcaption></figure>

2. Select the date of the transaction from the 'As On' field.
3.  Select the checkboxes corresponding to miscellaneous payments, collections, and deposits if you want  to include these transactions in the displayed list.

    <figure><img src="../../.gitbook/assets/image (1159).png" alt=""><figcaption></figcaption></figure>
4.  Click on the display button.

    <figure><img src="../../.gitbook/assets/image (1160).png" alt=""><figcaption></figcaption></figure>
5. The user can either print the report using the print button ![](<../../.gitbook/assets/image (1161).png>)or Export to Excel using the Excel button ![](<../../.gitbook/assets/image (1162).png>) , which is located at the top right corner of the screen.
