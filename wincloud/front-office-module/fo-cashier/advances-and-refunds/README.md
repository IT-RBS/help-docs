# Advances & Refunds

* Go to **Front Office>> Cashier>> Check-out>>Advances**

This option is used to refund any excess amount received as an advance during check-in when processing the guest’s checkout. This window can be used to process advances as well as refunds.

* Select the transaction process from the transaction field.
* Based on your selection in  the transaction field, this screen either functions as an advance or a refund window

### Advances

1. Click on the new button<img src="../../../.gitbook/assets/image (47).png" alt="" data-size="line"> to create a new advance transaction.
2. Select the transaction process as Advance

<figure><img src="../../../.gitbook/assets/image (1042).png" alt=""><figcaption></figcaption></figure>

3. In the _For_ field, select either _Reservation_ or _Room_ based on the requirement.
4. The “For” field acts as an additional filter and allows the user to select options such as Rooms or Reservations. The next field (currently reservation) will update based on the option selected in the “For” field.

<figure><img src="../../../.gitbook/assets/image (1041).png" alt=""><figcaption></figcaption></figure>

5. Select the room number to post the Advance. The system displays the 'in-house guest list' when the user clicks on the room field.
6. You can select the room number from the in-house guest list.

<figure><img src="../../../.gitbook/assets/image (1031).png" alt=""><figcaption></figcaption></figure>

7. Enter the amount to be posted as advance.

<figure><img src="../../../.gitbook/assets/image (136).png" alt=""><figcaption></figcaption></figure>

8. To add an advance amount to the reservations, click on the blue hand next to the Amount field.

<figure><img src="../../../.gitbook/assets/image (137).png" alt=""><figcaption></figcaption></figure>

9. Select the settlement method from the dropdown list provided in the settlement field
10. Enter the advance amount and enter the narration for clarity.
11. Click the OK button to return to the Advance window.

<figure><img src="../../../.gitbook/assets/image (138).png" alt=""><figcaption></figcaption></figure>

12. Click on the save button<img src="../../../.gitbook/assets/image (139).png" alt="" data-size="line"> in the top right corner of the window.

**The new**![](<../../../.gitbook/assets/image (987).png>)**, open**![](<../../../.gitbook/assets/image (988).png>)**, view**![](<../../../.gitbook/assets/image (989).png>)**, and print**![](<../../../.gitbook/assets/image (990).png>) **buttons in the Advance menu bar**

<figure><img src="../../../.gitbook/assets/image (986).png" alt=""><figcaption></figcaption></figure>

* The new button allows the user to create a new advance transaction.
* The open button helps open all refunds that have been processed. This button helps in modifying an advance created.
* The view button lets the user view the list of refunds created.
