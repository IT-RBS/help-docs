# Refund

1. Go to Front Office >> Cashier>> Advances
2. Click on the new button<img src="../../../.gitbook/assets/image (47).png" alt="" data-size="line"> to create a new Refund transaction.
3. Select the transaction process as Refund.

<figure><img src="../../../.gitbook/assets/image (1039).png" alt=""><figcaption></figcaption></figure>

3. In the _For_ field, select either _Reservation_ or _Room_ based on the requirement.
4. The “For” field acts as an additional filter and allows the user to select options such as Rooms or Reservations. The next field (currently reservation) will update based on the option selected in the “For” field.&#x20;

<figure><img src="../../../.gitbook/assets/image (1043).png" alt=""><figcaption></figcaption></figure>

5. Click on the reservation/room field to search for rooms or reservations. Here in the screenshot,  reservation has been chosen.
6. Upon clicking the magnifier in the reservation field, the list of reservations is displayed.
7. Choose the reservation for which the refund has to be applied.&#x20;

<figure><img src="../../../.gitbook/assets/image (1044).png" alt=""><figcaption></figcaption></figure>

8. Here, reservation number 2037 has been chosen. Enter the narrations.
9. Edit the amount using the 'hand' icon<img src="../../../.gitbook/assets/image (1046).png" alt="" data-size="line"> next to the amount field if there are any changes to be applied to the amount displayed by default.&#x20;

<figure><img src="../../../.gitbook/assets/image (1045).png" alt=""><figcaption></figcaption></figure>

10. Save <img src="../../../.gitbook/assets/image (1047).png" alt="" data-size="line">the refund transaction.
11. A confirmation message is displayed.![](<../../../.gitbook/assets/image (1048).png>)
