# Modifying Refund

### **To modify the voucher.**

1. Go to Front Office >> Cashier>> Advances
2. Click on Refresh open![](<../../../.gitbook/assets/image (24).png>) . The system displays the voucher search.

<figure><img src="../../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure>

3. Change the transaction field on the voucher to Refund.
4. Select Reservation/ Room from the 'For' field in the voucher.
5.  Upon changing the transaction field to Refund, the system displays all the refund vouchers.

    <figure><img src="../../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>
6. Select the guest from the list. Make necessary changes.
7.  Here, the amount has been amended.

    <figure><img src="../../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>
8.  Enter an amendment reason. Click OK.

    <figure><img src="../../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>
9. A confirmation message pops up ![](<../../../.gitbook/assets/image (29).png>)
