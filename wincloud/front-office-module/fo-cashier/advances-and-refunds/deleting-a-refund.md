# Deleting a Refund

1. Go to Front Office>> Cashier>> Advances
2. Click on the view button<img src="../../../.gitbook/assets/image (31).png" alt="" data-size="line"> and select the specific voucher number to delete the refund transaction, as shown below
3.  Select the transaction field as Refund.

    <figure><img src="../../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
4. Select Reservation/ Room from the 'For' field in the voucher.
5. Upon changing the transaction field to Refund, the system displays all the refund vouchers.
6.  Upon selecting the refund transaction to delete, the system displays the delete button ![](<../../../.gitbook/assets/image (33).png>)on the toolbar .

    <figure><img src="../../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>
7. Select the delete button ![](<../../../.gitbook/assets/image (33).png>)to delete.
8.  The reason for cancellation has to be recorded.

    <figure><img src="../../../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>
9. Confirmation of deletion is displayed.

<figure><img src="../../../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>
