# How do I perform a Post Tariff All function?

To perform the **Post Tariff All** function, navigate to the **Front Desk Main Menu**. From there, select **Front Desk > Post Tariff - All**. Once the Post Tariff - All screen appears, click the **Post button** to charge the room rates to all guest rooms simultaneously.

This function is a mandatory requirement that must be completed before the **Night Audit** process can be executed. It is important to note that the system only allows you to perform this action after **10:00 PM**. If this step is missed, the **Night Audit Checklist** will flag "Tariff not posted" as a pending job, and the system will block the transition to the new accounting date until the tariffs for all in-house guests are finalized.
