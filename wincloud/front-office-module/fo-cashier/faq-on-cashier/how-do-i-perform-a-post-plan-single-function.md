# How do I perform a Post Plan Single function?

To perform the **Post Plan-Single** function, which allows you to post plan charges for a specific guest separately from room tariffs, follow these steps:

1. **Navigate to the Menu:** Go to the **FRONT OFFICE** module and select **CASHIER > POST PLAN - SINGLE**.
2. **Select the Room:** Click the **room selection icon** to choose the specific room number where the plan amount should be posted.
3. **Verify Guest Details:** Select the **guest name** and carefully check the **amount** to be posted.
4. **Check Child Plans:** If a **child plan** is being charged, verify that specific amount as well.
5. **Complete the Posting:** Once all details are confirmed, click the **post icon** to finalize the transaction.

#### **Important Precautions**

* **Avoid Double Postings:** Before performing this action, it is highly recommended to check the **"CURRENT GUEST LEDGER"** report (located under QUERIES 1 in the Front Office module) to ensure the charges haven't already been applied.
* **Night Audit Preparation:** While plan charges can be posted along with the room tariff, this dedicated option is used if those charges were missed earlier in the day. If left unposted, this will appear as a **"Plan not posted"** error on your Night Audit Checklist.
