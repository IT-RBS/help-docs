# How do I use the Allowance Creation tool?

The Allowance Creation tool is used to issue credits or adjustments to a guest's folio and is managed within the Guest Charges interface.

**Steps to Create an Allowance**

1. **Navigate to the Menu:** Go to the Cashier Main Menu and select Cashier > Guest Charges.
2. **Select the Room:** From the guest charges screen, select the specific room number for which you want to create the allowance.
3. **Choose the Allowance Outlet:** In the guest charges window, you must select the Allowance outlet (sometimes referred to as the "Allowance window" in the system).
4. **Select Revenue and Amount:**

* Once the allowance outlet is selected, the software will display the revenue names linked to it.
* Select the relevant revenue name and enter the amount to be posted.

5\. **Save:** Click the Save button located in the toolbar at the top of the guest charges window to update the guest ledger.

**Monitoring and Impact of Allowances**

* **Allowance List Report:** To track these transactions, you can use the Allowance List report, which shows all allowances given to guests within a selected date range. This report can be filtered to show specific transaction types, guest splits, or bill information.
* **Financial Reporting:** Allowances directly affect your property's financial statistics. For example, in the Night Audit Report, the system calculates Net Revenue by subtracting allowances from the total revenue generated (Amount - Allowance = Net).
* **Audit Trail:** Like guest charges, allowances are recorded in the system's log for auditing purposes.
