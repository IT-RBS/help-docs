# How do i use the POST TARIFF SINGLE ?

he Post Tariff-Single option is used within the Cashier module to post the room tariff for a specific guest, typically performed at the time of check-out.To use the Post Tariff-Single feature, follow these steps:

1. **Access the Menu:** Go to the Cashier Main Menu.
2. **Open the Tool:** Click on Cashier > Post Tariff - Single.
3. **Verify the Date:** By default, the system will display the current account date for the posting.
4. **Select the Room:** Choose the specific room number for which you want to post the tariff.
5. **Review and Post:** The system will automatically display the tariff assigned to that room and the number of days it should be posted (calculated based on the check-out time in master settings). Click the Post button to finalize.

Managing Posted TariffsIf you need to adjust a tariff that has already been posted:

* **To Cancel:** Select the room number, click Cancel, and provide a reason for deleting the posted record.
* **To Re-post:** If the tariff was modified, select the room and click the Re-post button. You will be required to enter a reason before the system updates the record
