# How do I create a paid-out for an in-house guest

## **How Do I Create a Paid-Out for an In-House Guest?**

To create a **paid-out for an in-house guest**, which is used to **refund an excess credit balance or return an amount to a guest**, follow these steps within the **Cashier module**.

## **Steps to Create a Paid-Out**

### **1. Access the Menu**

* Navigate to the **Cashier Main Menu**.
* Select **Cashier > Paid Out**.

### **2. Select the Room**

* From the **Paid Out screen**, select the **specific room number** for which you want to record the transaction.

### **3. Enter Details**

* Enter the **amount to be paid out**.

### **4. Save**

* Click the **Save button** to complete the process.

## **Key Information for Paid-Outs**

* **System Prompts:**\
  During **checkout**, if a guest's **credit amount exceeds their debit amount** in the ledger, the system will automatically prompt the user to perform a **paid-out** for the excess refund.
* **Auditing:**\
  All **paid-out transactions** are recorded and can be viewed in the **Cashier Transaction Audit report**.
* **Modifications and Voids:**\
  You can **modify or void an existing paid-out voucher** by clicking the **Open or View buttons** on the **Paid Out screen**, provided the transaction was made on the **current account date**.\
  A **valid reason must be provided** for any deletions.
