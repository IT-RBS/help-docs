# How do I create a Miscellaneous Sale for an outsider?

To create a bill for an outsider (a non-staying guest), you use the Miscellaneous Sales feature within the Guest Charges tool. This allows you to generate and settle bills immediately.

**Steps to Create a Miscellaneous Sale**

1. **Navigate to the Menu:** Go to the **Cashier Main Menu** and click on **Cashier > Guest Charges.**
2. **Select Miscellaneous Mode**: On the Guest Charges screen, select the Miscellaneous option.
3. **Choose the Outlet and Revenue:**

* Select the required outlet from the list.
* Choose the specific revenue item you wish to charge. Note that only revenues specifically enabled for miscellaneous sales in the Outlet Revenue master will be available for selection here.

4. **Enter Transaction Details:**

* Input the charge amount.
* Select the appropriate settlement mode (e.g., Cash or Credit Card).

5. **Finalize the Bill:** Click the Save button to complete the transaction and generate the bill.

**Configuration Requirement**

For a revenue item to appear in the Miscellaneous Sales screen, it must be linked to the corresponding outlet in the Outlet Revenue master with the **"applicable for miscellaneous sales"** checkbox enabled.

**Tracking Miscellaneous Sales**

You can track these transactions using the Entries Posted at FO - Revenue wise report by ensuring the **"Include Miscellaneous Sales"** checkbox is selected. Additionally, the Miscellaneous Sales Analysis report allows you to filter by specific outlets to see a summary of items charged to **"others"** rather than in-house guests.&#x20;
