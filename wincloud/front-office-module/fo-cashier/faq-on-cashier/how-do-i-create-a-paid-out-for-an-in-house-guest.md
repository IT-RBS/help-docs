# How do I create a paid-out for an in-house guest?

To create a **paid-out** for an in-house guest, which is used to refund an excess credit balance or return an amount to a guest, follow these steps within the **Cashier** module:

1. **Access the Menu:** Navigate to the **Cashier Main Menu** and select **Cashier > Paid Out**.
2. **Select the Room:** From the Paid Out screen, select the specific **room number** for which you want to record the transaction.
3. **Enter Details:** Input the **amount** to be paid out.
4. **Save:** Click the **save button** to complete the process.

#### **Key Information for Paid-Outs**

* **System Prompts:** At the time of checkout, if a guest's **credit amount exceeds their debit amount** in the ledger, the system will automatically prompt the user to perform a paid-out for the excess refund.
* **Auditing:** All paid-out transactions are recorded and can be viewed in the **Cashier Transaction Audit** report.
* **Modifications and Voids:** You can modify or void an existing paid-out voucher by clicking the **open** or **view** buttons on the Paid Out screen, provided the transaction was made on the **current account date**. A reason must be provided for any deletions.
