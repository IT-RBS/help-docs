# How to use the Allowance Creation tool

## **How Do I Use the Allowance Creation Tool?**

The **Allowance Creation Tool** is used to **issue credits or adjustments to a guest's folio** and is managed within the **Guest Charges interface**.

## **Steps to Create an Allowance**

### **1. Navigate to the Menu**

* Go to the **Cashier Main Menu**.
* Select **Cashier > Guest Charges**.

### **2. Select the Room**

* From the **Guest Charges screen**, select the **specific room number** for which you want to create the allowance.

### **3. Choose the Allowance Outlet**

* In the **Guest Charges window**, select the **Allowance outlet** (also referred to as the **"Allowance window"** in the system).

### **4. Select Revenue and Amount**

1. After selecting the **Allowance outlet**, the software will display the **revenue names linked to it**.
2. Select the **relevant revenue name** and enter the **amount to be posted**.

### **5. Save**

* Click the **Save button** located in the **toolbar at the top of the Guest Charges window** to update the **guest ledger**.

## **Monitoring and Impact of Allowances**

* **Allowance List Report:**\
  Used to track allowance transactions. It displays all **allowances given to guests within a selected date range** and can be filtered by:
  * **Transaction Types**
  * **Guest Splits**
  * **Bill Information**
*   **Financial Reporting:**\
    Allowances directly affect the property's **financial statistics**. In the **Night Audit Report**, the system calculates **Net Revenue** by subtracting allowances from total revenue:

    **Amount - Allowance = Net Revenue**
* **Audit Trail:**\
  Similar to guest charges, all **allowances are recorded in the system log** for **auditing purposes**.
