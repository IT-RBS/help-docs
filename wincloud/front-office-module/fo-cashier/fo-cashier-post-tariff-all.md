# Post Tariff – All

If the final day's tariff has not yet been posted,  the Post Tariff-All option in the Cashier menu can be used to update the ledgers all at a go.

### **Post Tariff – All**

This option allows the user to post tariffs for all rooms simultaneously. It is typically used before the Night Audit process to ensure that tariffs are posted for all occupied rooms.

#### **Steps to Post Tariff-All**

1.Go to **Front Office>>**  **Cashier >>Post Tariff - All.**

<figure><img src="../../.gitbook/assets/image (970).png" alt=""><figcaption></figcaption></figure>

4. Click the “Specific” checkbox. Once selected, the system prompts the user to choose a specific company or group.&#x20;

<figure><img src="../../.gitbook/assets/image (971).png" alt=""><figcaption></figcaption></figure>

5. Once the Group or Company option is selected, the system displays the corresponding selection field, allowing the user to choose the specific company or group.

<figure><img src="../../.gitbook/assets/image (973).png" alt=""><figcaption></figcaption></figure>

5.  Select the company/group. Here in the example, a company is chosen, and hence the list of companies are displayed.

    <figure><img src="../../.gitbook/assets/image (974).png" alt=""><figcaption></figcaption></figure>
6. Once the user clicks on the Post button, a confirmation pop-up is displayed, and the Tariff will be posted to all the rooms. This option can be used before the night audit process to post tariffs to all the rooms.

<figure><img src="../../.gitbook/assets/image (975).png" alt=""><figcaption></figcaption></figure>
