# Post Tariff-Single

If the final day's tariff has not yet been posted,  the Post Tariff-Single option in the Cashier menu can be used to update the ledger.

### **Post Tariff-Single**

This option is used to post the Tariff by selecting the room. This option can be used at the time of checkout to post the tariff to a single room.

#### **Steps to Post Tariff-Single**

1.Go to **Front Office>>Cashier >>Post Tariff - Single.**

<figure><img src="../../.gitbook/assets/image (181).png" alt=""><figcaption></figcaption></figure>

3. By default, the Post-tariff single screen shows the current date. Choose the room number using the magnifier from the room No field.

<figure><img src="../../.gitbook/assets/image (169).png" alt=""><figcaption></figcaption></figure>

4. Select the room number from the in-house guest search list for which the Tariff is to be posted.

<figure><img src="../../.gitbook/assets/image (170).png" alt=""><figcaption></figcaption></figure>

5. The system displays the tariff assigned to the selected room and the total number of days the tariff has been applied. The number of days is determined according to the checkout time defined in the Master Settings.&#x20;
6. Click on the post button to post the tariff.

&#x20;

<figure><img src="../../.gitbook/assets/image (172).png" alt=""><figcaption></figcaption></figure>

A confirmation pop-up confirms the tariff posting.

![](<../../.gitbook/assets/image (374).png>)

### &#x20;**To cancel / Re-post the posted tariff**

6. Select the room number for which the tariff is already posted. Now the system will display options to Re-post or cancel the tariff.

<figure><img src="../../.gitbook/assets/image (174).png" alt=""><figcaption></figcaption></figure>

7. Click on the trash can ![](<../../.gitbook/assets/image (175).png>) to cancel or delete the already posted Tariff. The system asks for for a confirmation of deletion.

<figure><img src="../../.gitbook/assets/image (176).png" alt=""><figcaption></figcaption></figure>

8.  Click **Yes** to confirm and continue.

    * In the pop-up message box, enter the reason for deleting the posted tariff.
    *

        <figure><img src="../../.gitbook/assets/image (177).png" alt=""><figcaption></figcaption></figure>

    &#x20;           Click **OK** to confirm and delete the record.
9.

    <figure><img src="../../.gitbook/assets/image (178).png" alt=""><figcaption></figcaption></figure>

&#x20;Click on the Re-post Button to post the modified tariff again.

5. Click on the RePost button to RePost the Tariff, which already posted.
