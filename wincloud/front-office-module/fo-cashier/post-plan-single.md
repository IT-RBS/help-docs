# Post Plan-Single

### **POST PLAN – SINGLE**

**Post Plan – Single** allows the user to post all plan charges to a specific guest, separate from tariff postings. This option also enables the user to post child plan charges, if applicable at the property. Although plan charges can be posted along with the tariff posting, this dedicated option can be used to post the plan separately if it was missed earlier.

**NOTE:** Before posting any charges, ensure that you check the “Current Guest Ledger” report under “Queries 1” in the Front Office module to prevent duplicate postings.

1. To post plan - single, go to **FRONT OFFICE>>CASHIER**>>**POST PLAN - SINGLE**
