# Proforma Invoice

A proforma invoice is a preliminary document issued to a buyer before the final sale, outlining the estimated cost of goods or services. It is not a demand for payment but provides details such as pricing, quantities, and terms for reference.

#### To create a proforma invoice

1. Go to Front Office>> Cashier>> Proforma Invoice
2. Click on the Plus button ![](<../../.gitbook/assets/image (1164).png>)on the toolbar.

<figure><img src="../../.gitbook/assets/image (1163).png" alt=""><figcaption></figcaption></figure>

3. Clicking the plus button makes the screen active.
4.  From the Guest field, select the guest to be billed.

    <figure><img src="../../.gitbook/assets/image (1165).png" alt=""><figcaption></figcaption></figure>



5.  Upon selecting the guest, the system automatically populates all outstanding bills that are to be settled.

    <figure><img src="../../.gitbook/assets/image (1168).png" alt=""><figcaption></figcaption></figure>



6.  Click on the save button to create the proforma invoice.

    <figure><img src="../../.gitbook/assets/image (1167).png" alt=""><figcaption></figcaption></figure>



#### Viewing a proforma Invoice

1. Click on the File Open icon ![](<../../.gitbook/assets/image (1169).png>).
2.  Click on the proforma number field.&#x20;

    <figure><img src="../../.gitbook/assets/image (1170).png" alt=""><figcaption></figcaption></figure>
3.  Upon clicking the proforma field, the system lists out all the proforma invoices created.

    <figure><img src="../../.gitbook/assets/image (1171).png" alt=""><figcaption></figcaption></figure>



4. Select the previously saved record from the list to view.
5. The recreate button ![](<../../.gitbook/assets/image (1172).png>)helps the user recreate the invoice.
6. The refresh button ![](<../../.gitbook/assets/image (1173).png>)helps refresh the screen.
7. The Print button ![](<../../.gitbook/assets/image (1174).png>)helps print, and the Excel button ![](<../../.gitbook/assets/image (1175).png>)helps export the file to Excel.
