# Modifying Paid out

Users can modify the existing paid-out voucher by making changes to the existing record.

1. Go to **Front Office>>Cashier > > Paid Out.**
2. Click on the Open button <img src="../../../.gitbook/assets/image (53).png" alt="" data-size="line"> on the toolbar.

<figure><img src="../../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure>

3. Search for already Paid-out vouchers using the magnifier. Click on the desired voucher to be modified.

<figure><img src="../../../.gitbook/assets/image (59).png" alt=""><figcaption></figcaption></figure>

4. Double-click on the record to open the voucher.

<figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure>

5. Modify the record as required. Click the save button ![](<../../../.gitbook/assets/image (61).png>)to save the changes.

<figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure>

6. Clicking the save button prompts the user to add a justification for the modification.

<figure><img src="../../../.gitbook/assets/image (63).png" alt=""><figcaption></figcaption></figure>

7. Click Ok to complete the transaction.

<figure><img src="../../../.gitbook/assets/image (64).png" alt=""><figcaption></figcaption></figure>
