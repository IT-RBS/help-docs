# Paid Out

### **Paid Out**

This option is used to make a payout to an in-house guest. If the credit balance in the guest ledger exceeds the debit balance at the time of checkout, the system will prompt the user to process a paid-out for the excess amount. This ensures that any refundable balance is returned to the guest.

#### **Steps to Paid Out**

1. Go to **Front Office>>Cashier >> Paid Out.**

4\. Choose the room number from the _Room_ field where the paid-out is to be applied. The system displays In house Guest Search, enabling the user to choose.
