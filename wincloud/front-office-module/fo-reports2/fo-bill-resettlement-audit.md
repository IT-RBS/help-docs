# FO Bill Resettlement Audit

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Advanced Reports** menu.
3. Select **FO Bill Resettlement Audit.**

**FO Bill Resettlement Audit**

This report shows you the re settlements made for a selected period. It will show the old and new settlements and the reason for the settlements.

![](<../../.gitbook/assets/Screenshot 2023-08-07 114250.png>)

**Users** is to filter User wise or for selecting all the Users.
