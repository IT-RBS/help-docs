# Cashier Transaction Audit

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Advanced Reports** menu.
3. Select **Cashier Transaction Audit**.

**Cashier Transaction Audit**

This report shows you all the transactions made by the cashier. If the cashier has made in change/modification or cancelled anything or transferred charges then it will be visible.

![](<../../.gitbook/assets/Screenshot 2023-08-07 110128.png>)
