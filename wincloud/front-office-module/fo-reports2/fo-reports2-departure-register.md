# Departure Register

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Advanced Reports** menu.
3. Select **Departure Register**.

**Departure Register**

It shows the information about the departures within the selected period if all the information has been filled in Reservation while booking. You can also with the use of Multiple Check Box and Filters available add columns and sort. It will also show the total billing amount (till last posted).By default it will only show basic information about departure.

**Manual Companies:** It will open the list of Guests where you did not linked the Company which was created in Master but typed in manually in the Guest Profile.

**Rate /Total Amount:** It will add a column in the report to see the total billing amount of the guest.

**Pax Details :** This column shows the details of the guest

**Address:** To See the Address.

**E-Mail:** Email Information of the guest as a column will be added.

**DOB:** To Add Date of Birth if given as a column.

**Phone:** Mobile or any Contact no. will display (if it has been filled in the profile).

**Checked Out By:** If the guest has already checked within the selected period, you will be able to see which user checked the guest out.
