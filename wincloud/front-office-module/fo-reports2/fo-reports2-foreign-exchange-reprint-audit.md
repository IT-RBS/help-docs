# Foreign Exchange Collection

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Advanced Reports** menu.
3. Select **Foreign Exchange Collection**.

**Foreign Exchange Reprint Audit**

This report shows you all the foreign exchange transactions you printed from any module.

![](<../../.gitbook/assets/Screenshot 2023-08-07 110334.png>)

You can filter based on **Bill Type**.

![](<../../.gitbook/assets/1 (5).png>)

**Users** is to filter User wise or for selecting all Users.

![](<../../.gitbook/assets/1 (261).png>)

You can also sort the report based on the given option of **Sort On**.

![](<../../.gitbook/assets/3 (89).png>)

It shows the reason for the reprint, date and no. of reprints.
