# Reinstate Checkout Audit

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Advanced Reports** menu.
3. Select **Reinstate Checkout Audit**.

**Reinstate Checkout Audit**

This shows the user the Audit report of all the Re-Instated Checkouts during a period of time as shown below.
