# Which reports help track guest upgrades across the property?

The primary tool for tracking these instances is the **Upgrade Audit report**, which specifically displays in-house guest room upgrades for a selected date or date range. This report can be sorted based on various criteria and provides a date-wise view of all upgrades performed across the property.

In addition to the specific upgrade audit, you can use several other reports to monitor room moves and pricing variances:

**Guest Shift Rooms Report:** This report tracks all room shifts that occurred during a specific period. By selecting the Reason Summary checkbox, you can view a direct count of shifts categorized by their specific reasons, such as upgrades. Removing this checkbox provides a more detailed report on each individual move.

**Occupancy Statistics Report:** This report features a Difference % filter. Enabling this option adds a column that analyzes the percentage difference between the actual Tariff Charged and the room's Rack Rate. This is useful for identifying "complimentary upgrades" where the guest is in a high-value room but paying a lower rate.

**Amend Guest Stay Audit:** This audit log provides details on any modifications made to a guest's stay by staff, including the specific amendment reason provided at the time of the change.

**Guest Shift Rooms Report** (Analysis): As mentioned in our conversation history, this report can be generated from the Queries menu to see shifts as a reason summary or as a detailed log for in-depth analysis.
