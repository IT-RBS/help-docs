# Erase Check-in Audit

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Advanced Reports** menu.
3. Select **Erase Check-in Audit.**

**Erase Check-in Audit**

This shows the user the Audit report of all the Erase Check-ins during a period of time as shown below.
