# Tag/Clear Room Audit

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Advanced Reports** menu.
3. Select **Tag/Clear Room Audit** .

**Tag/Clear Room Audit**

This report provides you all the changes the staff made to a room by Tagging a Room Dirty or Tagging it Clean, also displays the reason.
