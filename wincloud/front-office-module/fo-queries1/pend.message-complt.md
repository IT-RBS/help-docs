# Pend.Message/Complt

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Queries**.
3. Select **Pend.Message/Complt**.

Pend.Message/Complt

This report helps the user to view all the pending messages, requests or complaints from the guest. User can choose to view the report from the selected date range and also filter between Message/Complaints or Requests
