# Pickup/Drop List

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Queries menu**.
3. Select **Pickup/Drop List**.

**Pickup Drop List**

This report helps you to see defined Pickup and Drops both on the same screen on a daily basis and also you can see the previous data by using the **Date Range** Option.
