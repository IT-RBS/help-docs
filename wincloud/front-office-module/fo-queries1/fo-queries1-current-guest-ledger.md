# Current Guest Folio

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Queries menu**.
3. Select **Current Guest Folio.**

**Current Guest Folio**

As the name suggests it helps you see the current guest folio/ledger, which means anything and everything posted into the rooms as of now. By default if you select a room it will only show you the selected day’s transactions and previous day/s transaction as the opening balance. To see all the transactions we have multiple options and you can mark the checkbox ‘arrival’ to see the details since arrival.

![](<../../.gitbook/assets/Screenshot 2023-07-31 111159.png>)

You need to select a room no. to see the ledger details.

![](<../../.gitbook/assets/1 (91).png>)

&#x20;Once you click it will open the below screen which will list all the current guests in house.

![](<../../.gitbook/assets/Screenshot 2023-07-31 112153.png>)

Click on **PM** Button to see only PM room.

**All Guest** Button will display names of all the guests available in the rooms and  not just Primary guest profile

As you can on the screen there are search boxes on top of each column as filter for ease of operation and getting the data faster for users.

![](<../../.gitbook/assets/Screenshot 2023-07-31 112239.png>)

With that we also have **Advance** Button to filter based on Mobile no. etc.

![](<../../.gitbook/assets/4 (142).png>)

When you select a room it will display the current day’s posting with all previous postings as opening balance

![](<../../.gitbook/assets/Screenshot 2023-07-31 113046.png>)

And if you click on **Arrival**

![](<../../.gitbook/assets/6 (88).png>)

It will show the in room postings of the guests from the date of their arrival.

![](<../../.gitbook/assets/7 (13).png>)

If the routing has been done and multiple splits were created, you can also see split wise.

![](<../../.gitbook/assets/8 (29).png>)
