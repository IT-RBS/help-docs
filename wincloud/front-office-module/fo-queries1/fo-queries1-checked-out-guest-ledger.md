# Checked Out Guest Ledger

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Queries menu**.
3. Select **Checked Out Guest Ledger.**

**Current Guest Ledger**

As it says in the name itself it helps you to see the checked guest ledger. This means anything and everything posted into the rooms before checkout.&#x20;

You need to select a RegNo. To see the ledger details.

![](<../../.gitbook/assets/1 (198).png>)

&#x20;Once you click it will open the below screen which will list all the checked out guests in the last few months which can be extended by selecting the date.

![](<../../.gitbook/assets/2 (47).png>)

Click on **PM** Button to see only PM room.

**All Guest** Button will display names of all the guests available in the rooms and not just the Primary guest profiles.

As you can see on the screen there are search boxes on top of each column as filters for ease of operation and getting the data faster for users.

![](<../../.gitbook/assets/4 (113).png>)

With that we also have the **Advance** Button to filter based on Mobile no. and Reservation ID etc.

When you select a RegNo. It will display the postings while their stay.
