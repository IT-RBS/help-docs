# Today's Arrival

**Today’s Arrival**

As the name suggests it shows you the list of Expected Arrivals for today. By default it will show the minimum data in the report but there are filters available to extend the report or options to sort the report based on multiple options.

![](/broken/files/tUyPSkzqkJdPciD5M0v7)

This report will only show on the day arrival(One day only). Next to Date and Display Button it has a Funnel Filter (for sorting) and Options Filter to add on columns of detailed information about the guest or booking.

<img src="../../.gitbook/assets/Screenshot 2023-07-28 104456.png" alt="" width="272">

**Funnel Filter:** If you use this option, you can sort or arrange the sequence of reports based on the options available such as room no and room type etc.

<img src="../../.gitbook/assets/Screenshot 2023-07-28 104422.png" alt="" width="375">

**Options Filter:** This option can be used in to add on multiple columns of information based on the requirement. You can click on any box and it will add a column.

<img src="../../.gitbook/assets/Screenshot 2023-07-28 104553.png" alt="" width="171">

For example the user can add columns to see the info. Of Pax and Mobile and Email

![](<../../.gitbook/assets/4 (150).png>)

And on the right it shows Summarized no. of Today’s Arrivals.
