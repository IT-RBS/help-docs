# Today's Departure

**Today’s Departure**

As the name clarifies it shows you the list of Expected Departure for today. By default it will show the minimum data in the report but there are filters available to extend the report or options to sort the report based on multiple options.

This report will show today's departure(One day only). Or also select from the date range as shown below

<img src="../../.gitbook/assets/Screenshot 2023-07-28 104846.png" alt="" width="355">

<figure><img src="../../.gitbook/assets/Screenshot 2023-07-28 105029.png" alt=""><figcaption></figcaption></figure>

**Funnel Filter:** If you use this option, you can sort or arrange the sequence of reports based on options available such as room no and room type etc.

<img src="../../.gitbook/assets/Screenshot 2023-07-28 104422.png" alt="" width="375">

**Options Filter:** This option can be used to add on multiple columns of information based on the requirement. You can click on any box and it will add a column.

<img src="../../.gitbook/assets/Screenshot 2023-07-28 104553.png" alt="" width="171">
