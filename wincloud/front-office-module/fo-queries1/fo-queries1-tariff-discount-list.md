# Tariff Discount List

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Queries menu**.
3. Select **Tariff Discount List**.

**Tariff Discount List**

This report is to see the Discount provided to the guest with additional options to see the report in detail and multiple filters like, **Room Type wise discount, Segment wise** etc.
