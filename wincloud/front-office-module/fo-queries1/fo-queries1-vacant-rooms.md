# Vacant Rooms

**VACANT ROOMS**

Vacant rooms show the unoccupied rooms available in the property. This report shows the number of rooms which are vacant floor wise, bed type wise. This report even shows vacant rooms which are dirty. Date range can be set to view available rooms for a period of time

1.To view the report, go to “FRONT OFFICE” module “QUERIES” “VACANT ROOMS”

![](<../../.gitbook/assets/Screenshot 2023-07-28 173520.png>)

2.Rooms can be filtered by Vacant, Linked or blocked rooms. To set date range in the report click on ![](<../../.gitbook/assets/3 (71).png>) set the period and click Date Range

![](<../../.gitbook/assets/Screenshot 2023-07-28 174448.png>)

3.Click on the filter option to view more advance room search option as shown below
