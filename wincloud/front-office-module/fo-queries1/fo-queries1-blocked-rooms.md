# Blocked Rooms

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Queries menu**.
3. Select **Blocked Rooms.**

**Blocked Rooms**

This report helps you to see the list of rooms blocked as of now and the status of the room w.r.t level and type of maintenance. For example, if it is **Out of Order** (considers long term) or **Out of Service** (short term) or for any other reasons.

![](<../../.gitbook/assets/0 (83).png>)

Filter to search **Blocked for** is provided to search for specific type of block.

![](<../../.gitbook/assets/1 (155).png>)

![](<../../.gitbook/assets/2 (84).png>)

A few check boxes are provided to search **Room Category** wise and to look for **OOS** or **OOO**.

![](<../../.gitbook/assets/3 (75).png>)

![](<../../.gitbook/assets/4 (105).png>)

A report will be generated by default for all block types, unless you use filter for a specific block type.

![](<../../.gitbook/assets/5 (123).png>)
