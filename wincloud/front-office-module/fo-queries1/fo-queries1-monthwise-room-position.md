# Month wise Room Position

**MONTH WISE ROOM POSITION**

Month wise room position shows the availability of rooms for a particular month. This report can be viewed room type-wise as well. This report helps in planning occupancy based on the data shown in the report.

1.To view the report, go to **“FRONT OFFICE”** module and select the following icon.

<figure><img src="../../.gitbook/assets/Screenshot 2023-07-27 153247.png" alt=""><figcaption></figcaption></figure>

![](<../../.gitbook/assets/Screenshot 2023-07-27 152842.png>)

2.To view occupancy based on filters, choose the filter from top left hand side as shown below

<figure><img src="../../.gitbook/assets/Screenshot 2023-07-27 153559.png" alt=""><figcaption></figcaption></figure>

3.To see the room allocation status, select the drop down as shown below

&#x20;![](<../../.gitbook/assets/Screenshot 2023-07-27 153811.png>)

4. Select property from the dropdown or choose **All Properties** to view the Room Position for all the properties as shown below

<figure><img src="../../.gitbook/assets/Screenshot 2023-07-27 154058.png" alt=""><figcaption></figcaption></figure>

5. To see the Room Position details for **Past Date** or to add more filters like ADR or RevPAR, choose rom the dropdown as shown below
