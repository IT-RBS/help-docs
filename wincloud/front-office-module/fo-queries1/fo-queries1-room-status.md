# Room Status

**ROOM STATUS**

Room status shows the current in-house occupancy of the property which is described through various colors to see the status of the rooms. This report shows the occupied room along with the guest name. Block wise, floor wise filters are available in this report.

1.To view the report, go to “FRONT OFFICE” module “QUERIES ” “ROOM STATUS”

![](<../../.gitbook/assets/Screenshot 2023-07-27 154616.png>)

2.Room status wise counts are given along with the description of colors

![](<../../.gitbook/assets/1 (52).png>)

3.To view the filtered report, select from the drop downs
