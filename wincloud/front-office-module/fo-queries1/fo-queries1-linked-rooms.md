# Linked Rooms

**LINKED ROOMS**

Linked rooms displays the rooms which are linked together under a master room. All the linked rooms created in “LINK/DELINK ROOM” option under “FRONT DESK” menu get displayed here.

1.To view the report, go to “FRONT OFFICE” module “QUERIES 1” “LINKED ROOMS”

2.To change the date, click on ![](<../../.gitbook/assets/0 (138).png>) icon and select the required date

3.As shown in the below screenshot, the main room is displayed in blue color and the linked rooms in violet
