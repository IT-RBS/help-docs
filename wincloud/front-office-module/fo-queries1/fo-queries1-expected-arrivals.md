# Expected Arrivals

EXPECTED ARRIVALS

Expected arrivals shows the upcoming confirmed reservations yet to arrive. Day wise arrivals can be viewed along with the filters to search for the market segment, reservation status etc. Past date arrivals can also be viewed in this report.

1.To view the report, go to “FRONT OFFICE” module “QUERIES ” “EXPECTED ARRIVALS”

![](<../../.gitbook/assets/Screenshot 2023-07-28 110849.png>)

2.  Select the From and To date from the screen as shown below

    <figure><img src="../../.gitbook/assets/Screenshot 2023-07-28 170135.png" alt=""><figcaption></figcaption></figure>

&#x20;3.Click on ![](<../../.gitbook/assets/3 (130).png>) icon to filter and search for any reservation

<img src="../../.gitbook/assets/Screenshot 2023-07-28 110939.png" alt="" width="375">

4.To see more details of the reservation, click ![](<../../.gitbook/assets/5 (63).png>)

<img src="../../.gitbook/assets/Screenshot 2023-07-28 111136.png" alt="" width="225">

6.Select required fields from the list and click ![](<../../.gitbook/assets/7 (38).png>) which adds up columns on the report with details if it was added during reservation

7.Click ![](<../../.gitbook/assets/8 (6).png>) to view the report once filters are applied

8.This report can be either converted to excel by clicking ![](<../../.gitbook/assets/9 (10).png>) or printed by clicking ![](<../../.gitbook/assets/10 (9).png>)
