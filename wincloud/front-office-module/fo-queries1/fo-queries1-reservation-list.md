# Reservation List

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Queries menu**.
3. Select **Reservation List.**

**Reservation List**

As the name suggests, this report will show you the list of all the reservations in the selected date range and also features multiple other sorting options in it.

![](<../../.gitbook/assets/Screenshot 2023-07-31 115127.png>)

**Selection Option:** These options are to sort the report based on your requirement and focus on the selected data to load.

<img src="../../.gitbook/assets/Screenshot 2023-07-31 115220.png" alt="" width="218">

A **Funnel filter** search is provided to search for any specific data. It is placed next to dates.\
A filter to see **Country wise** will group reservations based on Countries.

<img src="../../.gitbook/assets/Screenshot 2023-07-31 115311.png" alt="" width="375">

And Options filter also helps you to add other data as columns within Reports to see a detailed reservation report.

<img src="../../.gitbook/assets/Screenshot 2023-07-31 115611.png" alt="" width="177">

On the far right it shows the total **no. of Reservation** on the Page.

![](<../../.gitbook/assets/5 (60).png>)
