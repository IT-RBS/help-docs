# How do I track room shifts in the Shifted Rooms report?

To track room changes in the system, you use the Guest Shift Rooms report (also referred to as the Shifted Rooms report). This report allows you to monitor all room shifts that occurred on a specific day or within a selected time period.

**How to Use the Report**

**Reason Summary View:** If you enable the Reason Summary checkbox, the report will show a direct count of the number of shifts that occurred along with the specific reasons provided by staff.

**Detailed Information:** If you want to see a full, detailed report containing specific information about each individual shift, you must remove the Reason Summary checkbox.

This report is the primary tool for auditing room movements, whether they were performed via the visual drag-and-drop method on the Calendar or through the Change Room Menu.
