# Verify Posting In The Guest Folio

**How do I verify postings in the Current Guest Ledger?**

To verify postings in the **Current Guest Ledger** (also referred to as the **Guest Folio**), follow these steps:

#### **1. Navigate to the Report**

Go to:

**FRONT OFFICE → QUERIES → GUEST FOLIO**

Alternatively, you can access the **CURRENT GUEST LEDGER** report under **QUERIES 1**.

#### **2. Select the Room**

Choose the required **Room Number** to view the ledger details for the current in-house guest.

#### **3. Review Transactions**

* **Default View:**\
  By default, the report displays the **current day's postings**, while transactions from previous days are shown as an **opening balance**.
* **Full Transaction History:**\
  Select the **Arrival** checkbox to display all transactions recorded from the guest's **check-in date**.

#### **4. Use Filters to Verify Specific Data**

* **PM Button:** Displays only **Pay Master (PM)** rooms.
* **All Guest Button:** Shows the names of **all guests** assigned to the room instead of only the primary guest.
* **Search/Advance:** Use the search fields or the **Advance** option to filter records by specific information, such as **mobile number**.

#### **5. Verify Split Postings**

If **billing routing** or **split billing** has been configured for the reservation, review the transactions **split-wise** to ensure all charges have been allocated correctly.

**Recommendation:**\
Verify the **Current Guest Ledger** before posting additional charges (such as **Post Plan – Single**) to help prevent duplicate postings.
