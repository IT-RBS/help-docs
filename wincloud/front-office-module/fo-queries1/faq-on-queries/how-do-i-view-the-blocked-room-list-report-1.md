# How do I view the Blocked Room List report

**How do I view the Blocked Room List report?**

To view the **Blocked Room List** report, navigate to:

**FRONT OFFICE → QUERIES → Blocked Room List**

This report is a comprehensive tool that helps manage and track room restrictions with the following features:

* **Historical and Current Data:** Displays all rooms that are currently blocked, as well as rooms that were blocked recently or previously.
* **Specific Filters:** Allows you to filter the list to show:
  * **Out of Order (OOO)** rooms.
  * **Out of Service (OOS)** rooms.
  * **Both OOO and OOS** rooms.
* **Sorting Options:** The report can be sorted by:
  * **Room No.**
  * **Room Type**

This report is especially useful for verifying room availability and status before the **Night Audit**, as maintenance-related room blocks can affect hotel statistical calculations.
