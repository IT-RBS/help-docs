# How do I view the Blocked Room List report?

To view the Blocked Room List report, you should navigate to **FRONT OFFICE > QUERIES > Blocked Room List**.

This report is a comprehensive tool that allows you to manage and track room restrictions with the following features:

* **Historical and Current Data**: It shows all rooms that are currently blocked, as well as those that were blocked recently or previously.
* **Specific Filters:** You can filter the list to show only **Out of Order (OOO)** rooms, **Out of Service (OOS)** rooms, or both.
* **Sorting Options:** The report can be sorted by **Room No.** or **Room Type** to help you organize the data based on your operational needs.

This report is particularly useful for verifying the status of rooms before the Night Audit, as maintenance blocks can impact your hotel's statistical calculations.
