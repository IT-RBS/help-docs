# How do I filter for specific room features during search?

To filter for or identify rooms with specific features during your search, you can utilise the Room Search screen during the reservation process or the Vacant Rooms query for a more detailed analysis.

**Identifying Features via the Room Search Screen**

When you are creating a reservation and click the Room number field, the system opens the Room Search screen.

* **Visual Identification:** Once you highlight a specific room from the list, its assigned features (such as "Sea View" or "King Bed") are displayed in the Room Feature section located in the footer of the window.
* **Status Filtering:** The search screen also uses **color codes** to help you visually filter rooms by their current condition, such as Vacant, Dirty, Occupied, or Blocked for maintenance.

**Advanced Filtering in Vacant Rooms Query**

For a more proactive search, you can navigate to **FRONT OFFICE > QUERIES > VACANT ROOMS.**

**Advanced Search Options:** Within this report, you can click on the filter option to access advance room search options. This allows you to set specific date ranges and view unoccupied rooms based on criteria like floor or bed type.

**Configuration Requirements for Filtering**

For room features to be visible and searchable, they must be properly linked in the back-end:

* **Linking Features:** In the Room Master **(MASTERS > ROOMS > ROOM MASTER)**, you must add amenities to specific rooms under the **"FEATURE DETAILS"** section. You can link multiple features to a single room by clicking the plus icon (+) to add new rows.
* **Master Setup:** These features must be pre-created in the Room Feature master tool, where you define each amenity with a unique ID and Name.
