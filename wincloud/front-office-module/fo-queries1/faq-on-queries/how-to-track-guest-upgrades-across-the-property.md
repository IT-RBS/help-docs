# How to track guest upgrades across the property

**Which reports help track guest upgrades across the property?**

Several reports help track **guest upgrades**, room changes, and related pricing variations across the property.

#### **1. Upgrade Audit Report**

The **Upgrade Audit Report** is the primary report for tracking guest upgrades.

It:

* Displays all **in-house guest room upgrades** for a selected date or date range.
* Provides a **date-wise** view of upgrades performed across the property.
* Can be sorted using different criteria for easier analysis.

#### **2. Guest Shift Rooms Report**

This report tracks all room movements during a selected period.

* Enable the **Reason Summary** checkbox to view a count of room shifts categorized by their reasons, such as **upgrades**.
* Disable the **Reason Summary** option to view detailed information about each individual room shift.

#### **3. Occupancy Statistics Report**

This report helps identify pricing differences that may indicate complimentary upgrades.

* Enable the **Difference %** filter to display a column showing the percentage difference between:
  * **Tariff Charged**
  * **Rack Rate**
* This helps identify guests occupying higher-category rooms while paying a lower rate.

#### **4. Amend Guest Stay Audit**

This audit report records modifications made to a guest's stay.

It includes:

* Details of changes made by staff.
* The **amendment reason** entered at the time of the modification, including room upgrade-related changes.

#### **5. Guest Shift Rooms Report (Analysis)**

Available from the **Queries** menu, this report can be generated as:

* **Reason Summary** – provides a summarized count of room shifts by reason.
* **Detailed Report** – displays complete information for each room shift, supporting in-depth analysis of guest upgrades and room movements.

Together, these reports help monitor guest upgrades, room transfers, amendment history, and pricing differences across the property.
