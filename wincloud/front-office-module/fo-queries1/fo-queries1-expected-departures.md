# Expected Departures

**EXPECTED DEPARTURES**

Expected departures report shows the upcoming departures of the guest. This report will display departures for a particular day. This report also allows the user to view the departures list for the next number of days as per the value entered by the user.

1.To view the report, go to “FRONT OFFICE” module “QUERIES” “EXPECTED DEPARTURES”

![](<../../.gitbook/assets/Screenshot 2023-07-28 170952.png>)

2.To change the date, click on ![](<../../.gitbook/assets/1 (265).png>) icon and select the required date

3.Click on ![](<../../.gitbook/assets/4 (59).png>) icon to filter and search for any departure list

<img src="../../.gitbook/assets/Screenshot 2023-07-28 173001.png" alt="" width="375">

5.This report can be either converted to excel by clicking or printed out
