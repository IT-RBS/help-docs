# Sales Day Book (MOD)

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Reports Menu**.
3. Select **Sales Day Book (MOD)**.

**Sales Day Book (MOD)**

Sales Day Book (MOD) shows the sales of Minor Operative Division (Smaller secondary outlets) such as Minibar, Extra Bed, laundry etc. from both of transactions ‘Guest Charges’ and ‘Miscellaneous Sales’. By default it will only show the current day’s sale.

![](<../../.gitbook/assets/Screenshot 2023-08-03 110654.png>)

![](<../../.gitbook/assets/Screenshot 2023-08-03 112315.png>)

You can select all the outlet from the ‘**Outlet**’ Dropdown and/ or their respective ‘**Revenue**’ if required.

<img src="../../.gitbook/assets/Screenshot 2023-08-03 112443.png" alt="" data-size="original"> ![](<../../.gitbook/assets/Screenshot 2023-08-03 112509.png>)

You can add the name of the **Guest** and **Company**’s name against sales. And it will add columns of information.

![](<../../.gitbook/assets/4 (35).png>)

![](<../../.gitbook/assets/Screenshot 2023-08-03 112736.png>)

You can also see the entries done by HK Department (exclusively) by using given check box ‘**HK Entries**’.

![](<../../.gitbook/assets/6 (40).png>)

By default it shows only ‘Guest Charges’ posted so if you want see total sales you need to Add Miscellaneous through ‘**Miscellaneous Incl.**’ or to see only Misc.

![](<../../.gitbook/assets/7 (62).png>)

It will display the report based on the provided checkbox to add and also features a ‘Date Range’ option to see the sales within a period.

![](<../../.gitbook/assets/Screenshot 2023-08-03 112808.png>)
