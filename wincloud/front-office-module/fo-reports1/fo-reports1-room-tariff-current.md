# Room Tariff- Current

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Reports Menu**.
3. Select **Room Tariff- current.**

**Room Tariff- Current**

This report shows you the data of Defined and Posted Tariff for in House Guests. There are many options to add required information within the report, and for sorting the report.

![](<../../.gitbook/assets/Screenshot 2023-08-03 151320.png>)

**Sort On:** You can sort the report based on Room No., Room Type, guest Name, Company Room, and Registration No..

A search Bar is provided on top of the main columns (Room, Guest and Company Name), so you can search for any specific data that you are looking for.
