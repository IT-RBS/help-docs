# Pending Bills

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Reports Menu**.
3. Select **Pending Bills**.

**Pending Bills**

This report shows the Bills you have generated while checking out the guest, but have not settled them yet. So if this report shows data, it means the Bill is printed but the payment has not been made. Usually this report must be empty within 5-10 minutes to have an optimal practice of the check out process.
