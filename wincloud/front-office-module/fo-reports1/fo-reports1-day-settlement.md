# Day Settlement

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Reports Menu**.
3. Select **Day Settlement**.

**Day Settlement**

Day Settlement shows the user the types of settlements such as cash, CC, Cheque, City Ledger etc. In this report the types of settlements are as columns against the bills which are in rows and you can add Misc. Payments/collections and Tips.

![](<../../.gitbook/assets/Screenshot 2023-08-03 113127.png>)

![](<../../.gitbook/assets/1 (196).png>)

It will also show zero amount billings if you click on the checkbox ‘Zero Amount Bill’.

![](<../../.gitbook/assets/2 (91).png>)

You can filter it ‘**User**’ wise with multiple user selection and/ or all users all together.

<img src="../../.gitbook/assets/Screenshot 2023-08-03 113322.png" alt="" width="354">

You have the option to group this report ‘User’ wise or ‘Bill Type’ ,or 'Bill No' wise.

![](<../../.gitbook/assets/Screenshot 2023-08-03 113740.png>)

There is an option in the report to see ‘**Day Settlement Type**’ wise report, which opens a different. format and features many other options.

![](<../../.gitbook/assets/5 (18).png>)

![](<../../.gitbook/assets/Screenshot 2023-08-03 113505.png>)

You can see a specific type of settlement only and/ or all.

![](<../../.gitbook/assets/7 (19).png>)

There are few other columns that you can add and also see ‘**POS Receipts**’ from the filter
