# Allowance List

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Reports Menu**.
3. Select **Allowance List.**

**Allowance List**

This report shows the allowance which has been given to the guests. And from within this report you can also see the Advance and Refund posted and if any kind of discount has been provided on any ‘Guest Charge’ etc. for a selected date period.

**Allowance:** This will show the allowance posted along with a filter to select one or all along with Bill information and also guest split wise.
