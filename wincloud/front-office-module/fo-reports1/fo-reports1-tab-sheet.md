# Tab Sheet

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Reports Menu**.
3. Select **Tab Sheet**.

**Tab Sheet**

The Tab sheet can be the most viable, useful and Single source report to see all kinds of postings and billings (if generated) in a room, This report is based on masters (Tab sheet report settings) and by using that we can add ‘n’ no. of columns of revenue heads. It also showcases multiple filters and add-ons and different columns of details can also be added within the report.

![](<../../.gitbook/assets/Screenshot 2023-08-01 172048.png>)

![](<../../.gitbook/assets/Screenshot 2023-08-01 172117.png>)

If you click on **Guest Summary**, It will give you a report for a selected period and even in that you can add columns like guest name, pax details, company name and other personal info. Etc.

![](<../../.gitbook/assets/2 (160).png>)

![](<../../.gitbook/assets/3 (18).png>)

If you click on **Current Guest**, It will show you only the guests in house right now (on the day) and you can add their personal information as columns.

![](<../../.gitbook/assets/6 (2).png>)

You can also see all the **Checked Out** guests based on the period of selection and it will display the data with the info. along with the reservation instructions. It will also show one more check box ‘**Brought Fwd. Amt.**’ which can be added as a column.
