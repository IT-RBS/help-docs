# Can I filter the Night Audit Report for multiple properties?

Yes, you can filter the Night Audit Report for multiple properties within the system.

By selecting the property from the top left-hand side of the report screen, you can view the specific revenue and collection data for that individual location. Additionally, if you select the **“All Properties”** option, the system will generate a consolidated report that includes data from all properties in your group.

**Key Features of the Night Audit Report**

* **Detailed Financial Breakdown:** The report displays figures for today’s closed day, **Month Till Date (MTD)**, and **Year Till Date (YTD).**
* **Net Revenue Calculation:** Each column is sub-divided into the total amount, any allowances issued, and the resulting Net Amount (Amount - Allowance = Net).
* **Cumulative Period Filtering:** While the report defaults to the last closed day, you can use a "From and To" date filter to view collective revenue and collections for any specific period.
* **Comparison Tools:** A filter is available to compare current revenues and collections against the same period from the previous year, providing insights for management.

Other analytical reports, such as the Occupancy Analysis and the Manager Report, also support this multi-property functionality, allowing you to switch between individual properties or view a group-wide summary
