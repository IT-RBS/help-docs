# How do I use the Flash Budget Report?

The Flash Budget Report is a management tool used to compare your property's Actual Sales against the Budget Defined in the **Night Audit (NA)** Masters for any selected period.

**Key Components of the Report**

The report displays performance data in rows, allowing you to track specific metrics alongside revenue, including:

* **Actual vs. Budgeted Sales.**
* **Rooms Sold.**
* **Average Room Rate (ARR).**
* **Average Revenue per Pax (ARP).**

**Filtering and Analysis Options**

You can customize the report to view business trends using the following filters:

* **YTD (Year Till Date):** To see cumulative performance for the current fiscal year.
* **Last Year:** To compare current sales and budget figures against the same period from the previous year.
* **Average/Year:** To view average performance metrics over the course of the year.

**Related Master Setup**

For the Flash Budget Report to display accurate data, several configurations must be completed in the Masters section:

* **Defining Budgets:** Budgets for specific periods must be entered in the NA Monthly Budget master.
* **Grouping Data:** You can use Flash Budget Grouping to create specific Group IDs and names that organize how Night Audit Group Names appear in the report.
* **Adding Statistics:** If you need to track custom metrics, you can use the Flash Budget Statistics master to add new items with defined sequence numbers and decimal preferences.
