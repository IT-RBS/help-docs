# How to use the Flash Budget Report

**How do I search for a cancelled reservation to reinstate?**

To search for a **cancelled reservation** and reinstate it, follow these steps:

1. **Navigate to the Menu:**\
   Go to the **Reservations** module and click the **Reinstate Cancel** button located on the sub-menu bar.
2. **Access the Search Screen:**\
   The system will automatically open the **Reservation Search** screen, which is filtered to display only **cancelled reservations**.
3. **Enter Search Criteria:**\
   Locate the required booking by searching using either:
   * **Reservation Number**
   * **Guest Name**
4. **Select the Reservation:**\
   Once the correct reservation is found, double-click on it to open the reservation details for verification and reinstatement.

Before saving the reinstatement, ensure that you:

* Verify the guest’s **contact information**.
* Check **room availability** for the required dates.
* Enter a **mandatory reason** for the reinstatement.
