# How do I see guest birthdays?

To view the guest birthday list, which shows a complete list of birthdays for currently staying in-house guests for a specific month, follow these steps:

1. Navigate to the **FRONT OFFICE** module.
2. Select the **NIGHT AUDIT** menu.
3. Click on **GUEST BIRTHDAY.**
4. Select the required month and date and then click the Display icon.

**Additional Features:**

* **Anniversaries:** You can enable a specific option to see guest anniversaries along with the birthday list.
* **Spouse Birthdays:** If a spouse's birth date was added to the guest profile, it can also be reflected in this report by enabling the corresponding filter.
* **Date Frequency:** You can adjust the date frequency to view past birthdays from the previous month.
* **Export and Print:** The report can be converted to Excel or printed using the icons provided on the screen
