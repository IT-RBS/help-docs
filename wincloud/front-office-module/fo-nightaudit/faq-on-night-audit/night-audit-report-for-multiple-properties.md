# Night Audit Report for multiple properties

## **Can I Filter the Night Audit Report for Multiple Properties?**

**Yes**, you can **filter the Night Audit Report for multiple properties** within the system.

By selecting the **Property** from the **top left-hand side of the report screen**, you can view the **revenue and collection data** for a **specific property**.

Alternatively, by selecting **"All Properties"**, the system generates a **consolidated report** containing data from **all properties** in your group.

## **Key Features of the Night Audit Report**

* **Detailed Financial Breakdown:**
  * Displays figures for:
    * **Today's Closed Day**
    * **Month Till Date (MTD)**
    * **Year Till Date (YTD)**
* **Net Revenue Calculation:**
  * Each column is divided into:
    * **Amount**
    * **Allowance**
    * **Net Amount**
  * **Formula:**\
    **Amount − Allowance = Net Amount**
* **Cumulative Period Filtering:**
  * By default, the report displays the **last closed day**.
  * You can use the **"From" and "To" date filters** to view **collective revenue and collections** for any selected period.
* **Comparison Tools:**
  * A comparison filter allows you to compare the **current revenue and collections** with the **same period in the previous year**, helping management analyze performance.
