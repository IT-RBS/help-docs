# Collection Summary

### **COLLECTION SUMMARY**

Collection summary shows the overall collection for the day in a summarized manner, arranged with various modes of collection types

Using filter check boxes helps to derive reports on the basis of the filters applied

1.To view the “COLLECTION SUMMARY” report, go to “FRONT OFFICE” module “NIGHT AUDIT” “COLLECTION SUMMARY”

2.Select the date frequency required and click ![](<../../.gitbook/assets/0 (160).png>)

3.Using module filters helps to categorize collection reports module wise

![](<../../.gitbook/assets/Screenshot 2023-07-21 123814.png>)

![](<../../.gitbook/assets/Screenshot 2023-07-21 123727.png>)

4.If date wise summary is required enable ![](<../../.gitbook/assets/3 (4).png>)

![](<../../.gitbook/assets/Screenshot 2023-07-21 123909.png>)

5.Each filter applied for shows the same report in a different manner according to the filter.

6.To view the collection summary user-wise, enable ![](<../../.gitbook/assets/5 (40).png>)

7.Module wise filters can be applied for each type of this report selected

![](<../../.gitbook/assets/image (796).png>)

8.This report can be either converted to an excel by clicking ![](<../../.gitbook/assets/7 (53).png>) or printed by clicking ![](<../../.gitbook/assets/8 (57).png>)
