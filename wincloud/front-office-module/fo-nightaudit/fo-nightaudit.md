# Night Audit

### **Night Audit**

The night audit process will allow the user to close the account date and create a new account date. Before executing the night audit process, it is mandatory to check and complete the following process.

#### **Following things to be verified prior to night audit:**

#### **Night Audit Check List**

1.**Verification of in-house guest list and registration details**

Before executing the night audit process, It is mandatory to check whether all the checks-Ins are made and registration numbers are allotted as per the reservations and expected arrival list. This can be verified by the guest information amendment window. In the guest amendment window, the user can check and modify the guest details, tariff details and the guest profile, if any changes are required

2.**Room Tariff and Rate code**

It is necessary to check whether the room tariff and rate codes posted for all the in house guests are correct. If any changes are required, it has to be done before the night audit process. The user can do this by using the Room Tariff Report option.

3.**Checked out Guest and settlement details**

All the settlement bills and checked out guest details are to be verified with printed bills and the settlement report available in the system. If any changes are to be made in the settlement mode, resettlement to be done, any charges missed out,  all of this should be verified before the night audit.

All the settled and voided bill copies (For all outlets and all modules) have to be verified with the system reports before the night audit process.

In the Front office and Point of sale modules, the settlement type report will show all the bills with the settlement details.

The voided bills can be verified by using the void bill report option provided in the  Point of sale and Front office modules.

**1.Checking of all revenues**

It is mandatory to check that all the revenues (like Telephone calls, Room service bills) are properly posted into the guest ledger as per the mode of settlement.

**2.Pending bills and KOT**

It is mandatory to check if any bills are to be settled in outlets and any KOTs are pending in the Restaurant or Room service outlets. The System will not allow executing the night audit process until the bills are cleared.

If any guest is having an over due departure, then the system will not allow executing the night audit process until the stay is extended or the checkout is made.

**3.Posting of Tariff for the current guests**

The System will not execute the night audit process before the Tariff posting is done for all the guests. The Tariff can be posted into all the rooms by using the **Post Tariff all** option. This option will allow the user to post tariff into all the rooms only after 10:00 PM. The Night audit process can be started only at the day end (after 23:59).

After the verification and completion of all the above processes, the user can verify the preparedness to execute the night audit process by using the Night Audit Check List option..

If the tariffs are posted, all the bills are verified and cleared, then the Night audit check list will not show any process as pending. If any of the bills are pending or any of the above processes is incomplete, then it will show the pending jobs and will allow the night audit only after completing the pending jobs.

After the completion of all verification and tariff posting, the user can execute the night audit process by clicking on **Night Audit** Menu. Night Audit will close the current account date and open the new account date.

**Important Note**:- Once the night audit is completed, then the system will not allow anyone to post or modify the closed dates. It is mandatory to check and clear all the processes and not to miss out on any settlement and any posting for the day before executing the night audit.
