# Night Audit Check List

### **NIGHT AUDIT CHECKLIST**

The Night audit checklist shows the report of all the pending works left out before proceeding with the night audit process. This report shows the pending works in all the major transaction modules. It is necessary to check this report once and make sure it's empty before proceeding on with the night audit.

1. To view the report, go to the “FRONT OFFICE” module “NIGHT AUDIT” “NIGHT AUDIT CHECKLIST”
2. Here the common pending scenarios shown are:

![](<../../.gitbook/assets/Screenshot 2023-07-21 124026.png>)

1. Tariff not posted – post tariff for all in-house guests
2. Plan not posted – post plan for all in-house guests
3. Overdue departures – check out today’s departures or extend their stay as per the requirement
4. Checked out guest unpaid bills – final bill created but not settled
5. Pending KOT – pending KOT in the point of sale module which must be either settled with the bill or canceled in the POS module
6. Pending bills – pending bills in point of sale which also must be settled or canceled accordingly



1. To view the report only with the list tariff not posted, enable ![](<../../.gitbook/assets/1 (19).png>)
2. Clearing out all these pending things will allow the user to perform the night audit.
