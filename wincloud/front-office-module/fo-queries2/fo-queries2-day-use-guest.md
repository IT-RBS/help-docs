# Day Use Guest

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Advanced Queries**.
3. Select **Day Use Guest.**

**Day Use Guest**

This report helps to see the Guests that have arrived and left within a day in a selected period.

![](<../../.gitbook/assets/Screenshot 2023-08-01 164817.png>)

You can filter with the checkbox to see only the **Departed, In house and expected** or all Guests to use Day Use.

![](<../../.gitbook/assets/1 (79).png>)

Report will show with the check box option header and report will be divided in sections based on these.

![](<../../.gitbook/assets/Screenshot 2023-08-01 165227.png>)
