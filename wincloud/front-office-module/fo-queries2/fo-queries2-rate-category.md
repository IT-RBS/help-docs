# Rate code analysis

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click **Advanced Queries**.
3. Select **Rate Code Analysis.**

**Rate code analysis**

This report provides you the analytical information of Room Nights based on Rates and it's Contribution.
