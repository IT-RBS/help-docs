# Guest Search

Guest Search – enables front office and back-end users to locate guest-related records quickly using multiple identifiers, ensuring efficient service delivery and accurate information retrieval.

The Guest Search option will, by default, show the current In-House Guest List.  The Guest Search option will also list the expected guest list, the checked-out guest list, and the list of no-show guests. By default, the list shows for 7 days and can be changed to any no of days up to 999 Days.

### **Steps to Search Guest**

1. Go to Front Desk Main Menu.&#x20;
2. Click on Front Desk > Guest Search.
3. Once the user clicks on Guest Search, the WinCloud displays the list of guests currently staying by default.

<figure><img src="../../.gitbook/assets/image (208).png" alt=""><figcaption></figcaption></figure>

4. The user can search for the Guest based on requirements like checked out, expected guest, No Show, or Cancellation.
