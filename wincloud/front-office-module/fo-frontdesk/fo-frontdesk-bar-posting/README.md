# Bar Posting

### **What is Bar Posting?**

Bar Posting is a feature that allows the front office team to block any charges or credits from being posted to a guest’s room. Once a room is bar-posted during the guest’s stay, any services used or items consumed must be paid for immediately and cannot be charged to the room.

### **Steps to enable Bar Posting:**

1. Go to **Front Office>>Front Desk >>In-House Guest Amend**

<figure><img src="../../../.gitbook/assets/image (958).png" alt=""><figcaption></figcaption></figure>

3. Click on the **Room No.**  and select the particular guest that needs to be Bar Posted.

<figure><img src="../../../.gitbook/assets/image (959).png" alt=""><figcaption></figcaption></figure>

4\. Double-click the selected guest to display the guest's details on the screen. From the ellipsis (three vertical dots), select “Bar Post.”

<figure><img src="../../../.gitbook/assets/image (960).png" alt=""><figcaption></figcaption></figure>

5. Once the user has clicked on **Bar Post,** he will get a pop-up of the **Bar Posting** Screen where he can select the particular transaction for which he needs to prohibit posting to the room and then click save.

<figure><img src="../../../.gitbook/assets/image (961).png" alt=""><figcaption></figcaption></figure>

6\. If the user wants to Bar Post a Specific outlet from Guest Charges or POS, click specific as shown below

<figure><img src="../../../.gitbook/assets/image (964).png" alt=""><figcaption></figcaption></figure>

7\. Select the particular **Outlet** which the user needs to **Bar Post** and click **OK**

<figure><img src="../../../.gitbook/assets/image (963).png" alt=""><figcaption></figcaption></figure>

8\. Click on save to save the amendments.
