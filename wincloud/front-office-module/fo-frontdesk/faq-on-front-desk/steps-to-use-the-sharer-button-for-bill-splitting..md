# Steps to use the Sharer button for bill splitting.

## **Steps to Use the Sharer Button for Bill Splitting**

To use the **Sharer button for bill splitting** during the reservation process, follow these steps:

### **1. Initiate a New Reservation**

* Go to the **Reservation menu** from the **Main Menu**.
* Click the **Add New Item** button.

### **2. Enter Stay Details**

* Select the **Room Type**.
* Enter the **Arrival Date**.
* Select the number of **Nights** and **Adults**.

### **3. Assign a Room**

* Click on the **Room Number field** to open the **Room Search screen**.
* Select an **available room**.

### **4. Enter Guest Information**

* Type the **guest names** into the designated rows.
* Alternatively, search for **returning guests** using the **Magnifier icon**.

### **5. Tick the Sharer Box**

* If the **bill is to be shared by another guest**, locate and tick the **Sharer button box**.

### **6. Complete Compulsory Fields**

* Select the **Business Source**, which is mandatory for **analytical reporting**.
* Complete any optional **segments or guest types** if required.

### **7. System Prerequisite**

* Ensure that the selected room is **eligible for sharing**.
* Verify that the **Sharer Room option is enabled** in:\
  **Masters > Rooms > Room Master**

Once the **Sharer box is ticked**, the system identifies that the **bill will be divided between the guests assigned to that room.**
