# Bills Receivable

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Bills Receivable.**

**Bills Receivable**

This report gives you the list of all the City Ledger Bills generated within the selected period in the Name of the Company/ Guest. This will always show all the bills even if they are paid.
