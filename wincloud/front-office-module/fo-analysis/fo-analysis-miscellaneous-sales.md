# Miscellaneous Sales Analysis

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Miscellaneous Sales Analysis.**

**Miscellaneous Sales Analysis**

This report shows the Sales of MOD (Minor Operative Division), where you can filter a specific Outlet and see the details of the Item Charged and in Summary as well, for a selected date period.

![](<../../.gitbook/assets/Screenshot 2023-08-11 103521.png>)

You can filter to see Charges made **To** **Guest** or **To Other** and see the **Charge Items** and **Revenue**.

![](<../../.gitbook/assets/Screenshot 2023-08-11 103608.png>)
