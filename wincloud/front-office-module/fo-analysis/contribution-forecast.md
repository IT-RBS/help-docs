# Contribution Forecast

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Contribution Forecast.**

**Contribution Forecast**

This report helps the user to view the forecasted report of the contributions from different segments from selected date range.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2023-08-09 102539.png" alt=""><figcaption></figcaption></figure>

User can select the segments from the filter option as shown below

![](<../../.gitbook/assets/Screenshot 2023-08-09 102648.png>)
