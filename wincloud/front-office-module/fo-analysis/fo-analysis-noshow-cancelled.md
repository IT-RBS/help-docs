# No Show/Cancelled Reservation

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **No Show/Cancelled Reservation Audit**

**No Show/Cancelled Reservation Audit**

This report gives you the list of all the No Shows or Cancelled or Reinstated Reservations within a selected period. It shows the summarised no. on the right (on top).

![](<../../.gitbook/assets/Screenshot 2023-08-09 153644.png>)

User can also view the Cancelled Reservation and Reinstate Reservation
