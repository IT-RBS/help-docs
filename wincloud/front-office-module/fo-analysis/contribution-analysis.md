# Contribution Analysis

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Contribution Analysis**.

**Contribution Analysis**

Contribution Analysis shows the report based on Revenue Contribution and Room Nights Contribution from various aspects such Country Contribution, Market Segment Contribution, Business Contribution etc. for a selected period.

![](<../../.gitbook/assets/Screenshot 2023-08-09 103920.png>)

**Segment:** Contribution Based on Segments or aspect of business can also be selected from here.

<img src="../../.gitbook/assets/Screenshot 2023-08-09 104006.png" alt="" width="108">

There are a few options available to add the Comp. Use and to add RevPAR as columns along With Day Use as well.

![](<../../.gitbook/assets/2 (188).png>)

Users can choose to view the report for Daywise, Quarterly and Monthlywise or select detail to view the report in detail as shown below

![](<../../.gitbook/assets/Screenshot 2023-08-09 104134.png>)

The following filter shows the quarterly contribution report, the user can also choose to view the report of last year and the variance as well

<figure><img src="../../.gitbook/assets/Screenshot 2023-08-09 104344.png" alt=""><figcaption></figcaption></figure>

Once the user selects **Detail,** the following report is generated, which has different segment's contribution in detail guest wise from the selected date range
