# Segment Analysis

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Segment Analysis.**

**Segment Analysis MTD/YTD**\
\
The segment analysis report shows the Nights, Room revenue, ADR, Occupancy percentage and pax details for different segments. This report provides details for the day, month and year.
