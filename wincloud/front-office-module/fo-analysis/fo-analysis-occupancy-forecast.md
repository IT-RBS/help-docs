# Occupancy Forecast

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Occupancy Forecast.**

**Occupancy Forecast**

The Occupancy Forecast report shows you the information about the Future Occupancy based on reservations made (including tentative). It shows the Guest Name and Revenue to be generated out of these future bookings. You can select the period of future dates for generating the report.

<img src="../../.gitbook/assets/Screenshot 2023-08-11 105247.png" alt="" width="366">

![](<../../.gitbook/assets/Screenshot 2023-08-11 105233.png>)

**With Compl/HU:** This shows the report including Complimentary Booking or House Use or Management Booking.

**With Day Use:** If you click on this, the report will show the forecast for Day Use Guests.

![](<../../.gitbook/assets/5 (94).png>)

Columns and rows can be added and sorted based on two types of Filters provided. Options Filter (Checkbox) and Funnel Filter (Dropdown specific).

<img src="../../.gitbook/assets/Screenshot 2023-08-11 105247.png" alt="" width="366">

**Options Filter:** It adds the checked box information, by adding a corresponding column within the report in a predefined sequence, Such as Business Source, Segment, Room type etc. This will always show you all data of all future reservations.

<img src="../../.gitbook/assets/Screenshot 2023-08-11 105605.png" alt="" width="174">

![](<../../.gitbook/assets/Screenshot 2023-08-11 105648.png>)

**Funnel Filter:** This you can use to filter and sort the report based on your requirement. For example if you want a report based on one source of booking only etc. In this you can select specific Company, Travel Agent etc. or select all.

<img src="../../.gitbook/assets/Screenshot 2023-08-11 110446.png" alt="" width="302">
