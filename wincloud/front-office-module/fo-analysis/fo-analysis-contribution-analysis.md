# Contribution

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Contribution**.

**Contribution**

This report helps the user to view the segment wise contribution for Nights, Occupancy, Pax , Room Revenue etc. from a selected date range

<figure><img src="../../.gitbook/assets/Screenshot 2023-08-09 101143.png" alt=""><figcaption></figcaption></figure>

This report supports Multi-Property. User can choose properties from the filter as shown below and view report for selected property and also a consolidated report of all the properties.
