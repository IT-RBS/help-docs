# Guest Analysis

**Navigation Path:**

1. Navigate to the **Front Office** module.
2. Click the **Analysis** menu.
3. Select **Guest Analysis.**

**Guest Analysis**

This report shows the detailed guest analysis were the users select use the following filters and add those filters in the report.&#x20;

![](<../../.gitbook/assets/Screenshot 2023-08-14 104856.png>)

Details like Country, market segment, business source can selected from here.

![](<../../.gitbook/assets/Screenshot 2023-08-14 105212.png>)

Users can add more details which will be displayed in the report.

![](<../../.gitbook/assets/Screenshot 2023-08-14 105124.png>)

Once the user select the filters, click on display to view the report

![](<../../.gitbook/assets/Screenshot 2023-08-14 105332.png>)
