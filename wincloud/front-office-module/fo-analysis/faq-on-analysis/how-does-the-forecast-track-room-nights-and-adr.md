# How does the forecast track room nights and ADR

**How does the forecast track room nights and ADR?**

The system tracks **Room Nights** and **ADR (Average Daily Rate)** through various forecasting and analytical reports by evaluating existing reservations and future booking trends.

#### **Key Reports for Tracking Nights and ADR**

**1. Business on Books Report**

* Calculates monthly revenue based on:
  * **Total Nights**
  * **Revenue Generated (or expected revenue)**
  * **ADR**
* Can be filtered by **Room Type**.
* Allows users to exclude tentative bookings and focus only on confirmed business.

**2. Forecast Report**

* Tracks future contributions from different market segments, such as:
  * Corporate
  * Individual guests
* Provides metrics including:
  * **Nights**
  * **Pax**
  * **ADR**
  * **ARP**
  * **RevPAR**
* Can be generated for a selected future date range.

**3. Segment Analysis (MTD/YTD)**

* Provides a detailed breakdown of:
  * **Nights**
  * **ADR**
* Displays performance for:
  * Current day
  * Month-to-date (MTD)
  * Year-to-date (YTD)
* Helps analyze segment performance trends.

**4. History and Forecast Report**

* Combines:
  * Past performance (rooms sold and revenue collected)
  * Future projections based on current bookings
* Allows comparison between actual and projected:
  * Room Nights
  * Revenue

#### **Analytical Breakdowns**

**5. Rate Code Analysis**

* Provides information on **Room Nights** based on specific rate codes.
* Shows the contribution of each rate code to overall property revenue.

**6. Average Length of Stay (ALOS)**

* Shows the average number of days a guest stays.
* Helps analyze how stay duration impacts:
  * Total revenue
  * ADR

**7. Room Wise Income Analysis**

* Provides income details by:
  * Room number
  * Room type
* Displays:
  * Room Nights
  * Revenue
  * ARR (Average Room Rate)
* Can be generated for a selected month range.

These reports help management monitor current performance, forecast future demand, and analyze the impact of room nights and ADR on hotel revenue.
