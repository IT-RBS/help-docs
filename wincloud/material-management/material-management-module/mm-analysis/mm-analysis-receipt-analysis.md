# Receipt Analysis

The **Receipt Analysis Report** provides detailed information about all receipt transactions recorded in the **Inventory Module**. This report is similar to the **Receipt List Report** but offers additional analytical capabilities to help users review and evaluate receipt transactions more effectively.

## Steps to View the Receipt Analysis Report

Step 1: Navigate to the **Analysis** menu in the **Inventory** module.

1. Select **Receipt Analysis**.

* The Receipt Analysis Report screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 16-41-03.png" alt=""><figcaption></figcaption></figure>

Step 2: Click the **Funnel Filter** icon.![](<../../../.gitbook/assets/Screenshot from 2026-06-02 16-41-45.png>)

1. Select the required filter criteria to refine the report.
2. Use the **Group By** drop-down to organise the report data.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 16-42-10.png" alt=""><figcaption></figcaption></figure>

Step 3: Click the **Options** button.![](<../../../.gitbook/assets/Screenshot from 2026-06-02 16-42-41.png>)

1. Select the required options to customise the report output.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 16-43-15.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the required filters, grouping options, and report settings, click the **Display** button.

1. The system will generate and display the Receipt Analysis Report.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 16-44-30.png" alt=""><figcaption></figcaption></figure>
