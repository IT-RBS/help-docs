# Stock Value Summary

The **Stock Value Summary** report provides a consolidated view of the current inventory stock and its corresponding value as of a specified date. It displays stock quantities and valuation either item-wise or category-wise, enabling users to monitor inventory levels, assess stock value, and support financial and operational decision-making.

## Steps to View the Stock Value Summary Report

Step 1: Navigate to the **Analysis** menu in the **Inventory** module.

1. Select **Stock Value Summary**.

* The **Stock Value Summary** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 12-31-43.png" alt=""><figcaption></figcaption></figure>

Step 2: After opening the report page, apply the necessary filters to generate the required report data.

1. Use the Group By Option

* The **Group By** drop-down allows users to organise and summarise report data in different formats.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 12-32-19.png" alt=""><figcaption></figcaption></figure>

Step 3: After selecting the required filters and grouping options, click **Display** button.

* The system will display the Stock Value Summary report based on the selected criteria.
