# Item Receipt Summary

**Item Receipt Summary**

This report provides a summarised report of all the items received for product groups. It has many easy to use filters and formats with the help of Sorting and Grouping for a selected period.

Funnel Filter is provided to look for a Specific Supplier or stores or Product/s.
