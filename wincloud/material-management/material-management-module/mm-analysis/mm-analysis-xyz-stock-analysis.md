# XYZ Stock Analysis

The **XYZ Stock Analysis** report classifies inventory items based on their stock value and consumption patterns. It helps organisations identify which items contribute the most and the least to inventory value, enabling better inventory control and stock management.

## Steps to View the XYZ Stock Analysis Report

Step 1: Navigate to the **Analysis** menu in the **Inventory** module.

1. Select **XYZ Stock Analysis**.

* The **XYZ Stock Analysis** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 11-36-49.png" alt=""><figcaption></figcaption></figure>

Step 2: After opening the report page, choose the appropriate analysis criteria.

* The **Stock % Filter** allows users to classify inventory items according to their contribution to the total stock value.
* The system classifies items into X, Y, and Z categories based on the selected stock percentage criteria.

1. **X Item Class -** Represents items with the highest stock value.
2. **Y Item Class -** Represents items with moderate stock value.
3. **Z Item Class -** Represents items with the lowest stock value.

* This classification helps organisations allocate resources and inventory management efforts more effectively.

Step 3: Use the Funnel Filter.![](<../../../.gitbook/assets/Screenshot from 2026-06-03 09-52-22 (6).png>)

* The **Funnel Filter** allows users to search and analyse specific inventory data.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 11-38-35.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the required criteria and filters, click **Display** button.

1. The system will display the XYZ Stock Analysis report based on the selected parameters.
