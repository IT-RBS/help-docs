# Departmentwise Item Consumption Summary

The **Departmentwise Item Consumption Summary** report provides a consolidated view of items consumed by each department during a selected period. It displays the quantity of items used and, where applicable, the corresponding consumption value based on issued, consumed, or recorded inventory transactions.

## Steps to View the Departmentwise Item Consumption Summary

Step 1: Navigate to the **Analysis** menu in the **Inventory** module.

1. Select **Departmentwise Item Consumption Summary**.

* The **Departmentwise Item Consumption Summary** Report screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 09-49-33.png" alt=""><figcaption></figcaption></figure>

Step 2: After opening the report page, select the required filters to generate the data.

* The report supports multiple filters, allowing users to narrow down and customise the results according to specific requirements.

Step 3: Use the **Funnel Filter.**![](<../../../.gitbook/assets/Screenshot from 2026-06-03 09-52-22.png>)

* The **Funnel Filter** allows you to refine the report by applying additional search conditions.

1. Use the Group By Option

* The **Group By** drop-down enables users to organise report data in different formats for easier analysis.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 09-50-09.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the required filters and grouping options, click **Display** button.

1. The system will display the Departmentwise Item Consumption Summary based on the selected criteria.
