# Supplier wise Item Receipt Summary

**Supplier wise Item Receipt Summary**

This report is to see the summarised list of items along with the name of the suppliers for a given date period.

You can select a specific store from **Store** dropdown.

A Funnel Filter is provided to search for specific Product, Supplier etc.

![](<../../../.gitbook/assets/1 (2).png>)

By Default, when you click the Display Button to see the data, it will show you the Summary but you click on Details, it will show the information of last receipt made for those items as well.
