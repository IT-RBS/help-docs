# Issue Analysis

The **Issue Analysis Report** provides detailed information about all issue transactions recorded in the **Materials Management (MM) Module**. This report is similar to the **Issue List Report** but offers additional analytical capabilities to help users evaluate and monitor inventory issues more effectively.

## Steps to View the Issue Analysis Report

Step 1: Navigate to the **Analysis** menu in the **Inventory** module.

1. Select **Issue Analysis**.

* The **Issue Analysis** Report screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 17-06-21.png" alt=""><figcaption></figcaption></figure>

Step 2: Click the **Funnel Filter** icon.![](<../../../.gitbook/assets/Screenshot from 2026-06-02 17-06-43.png>)

1. Select the required filter criteria to refine the report.
2. Use the **Group By** drop-down to organise the report data.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 17-07-37.png" alt=""><figcaption></figcaption></figure>

Step 3: After selecting the required filters and grouping options, click the **Display** button.

* The system will generate and display the Issue Analysis Report.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 17-08-47.png" alt=""><figcaption></figcaption></figure>
