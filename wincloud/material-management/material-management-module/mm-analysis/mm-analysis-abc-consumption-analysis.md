# ABC Consumption Analysis

The **ABC Consumption Analysis** report classifies inventory items based on their consumption value during a specified period. It helps organisations identify which items contribute the most and the least to overall consumption value, enabling better inventory control, cost management, and purchasing decisions.

## Steps to View the ABC Consumption Analysis Report

Step 1: Navigate to the Analysis menu in the Inventory module.

1. Select **ABC Consumption Analysis**.

* The **ABC Consumption Analysis** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 14-38-37.png" alt=""><figcaption></figcaption></figure>

Step 2: After opening the report page, apply the necessary filters to generate the report.

1. Configure the Consumption Percentage Filter

* The **Consumption % Filter** allows users to classify items based on their contribution to the total consumption value.
* The system classifies items into A, B, and C categories based on the selected consumption percentage criteria.

1. **A Class Items -** Represent the highest consumption value.
2. **B Class Items -** Represent moderate consumption value.
3. **C Class Items -** Represent the lowest consumption value.

Step 3: Use the Funnel Filter![](<../../../.gitbook/assets/Screenshot from 2026-06-03 14-40-05.png>)

* The **Funnel Filter** allows users to search for and analyse specific information within the report.

1. Use the Group By Option

* The **Group By** drop-down allows users to organise report data into meaningful categories.
* The report can be grouped by Product Group

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-03 14-39-01.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the required filters, consumption percentage criteria, grouping options, and Funnel Filters, click **Display** button.

* The system will display the ABC Consumption Analysis report based on the selected parameters.
