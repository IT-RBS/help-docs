# Item Consumption Query

The **Item Consumption Query** report provides a detailed list of all **Receipt** and **Issue** transactions that have occurred for a selected item within a specified date range in a store. This report helps users track item movement and analyze consumption patterns over a particular period.

### Steps to View Item Consumption Query

Step 1: Navigate to the **Queries** menu in the **Inventory** module.

1. Select **Item Consumption Query**.

* The **Item Consumption Query** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 09-53-59.png" alt=""><figcaption></figcaption></figure>

Step 2: Click the **Item Search** icon.

1. Select the required item from the list of available items.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 09-54-26.png" alt=""><figcaption></figcaption></figure>

2. Specify the **From Date** and **To Date** to define the period for which the transaction details are required.

Step 3: Click the **Advanced Search Filter** option available on the screen.

1. Select the required filter criteria to refine the query results.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-02 09-55-10.png" alt=""><figcaption></figcaption></figure>

Step 4: Click the **Display** button.

* The system will display all Receipt and Issue transactions for the selected item within the specified date range.

<figure><img src="../../../.gitbook/assets/c1 (1).png" alt=""><figcaption></figcaption></figure>

&#x20;Export the Report to Excel:

1. After reviewing the displayed transaction details, click the **Excel** button.
2. The system will generate and download the report in **Microsoft Excel** format.
