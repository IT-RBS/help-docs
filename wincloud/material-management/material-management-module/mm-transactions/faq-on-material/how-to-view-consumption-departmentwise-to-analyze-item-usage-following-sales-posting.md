# How to view Consumption  Departmentwise to analyze item usage following sales posting ?

To analyze item usage following your sales posting, you can use either the Item Consumption Query for a specific product or the Departmentwise Item Consumption Summary for an overall departmental view.

***

1\. Item Consumption Query (Product-Level View)This query provides a detailed list of all receipt and issue transactions for a selected item within a specified store and time frame.

1. Go to Queries > Item Consumption Query.
2. Click the Item Search icon, choose the item, and select the date range.
3. Click the Display button to load the transactions.
4. _(Optional)_ Click the Advance search Filter option to refine your view, or click the Excel button to download the report.

***

2\. Departmentwise Item Consumption Summary (Department-Level View)This report presents a consolidated summary of items consumed across each department, detailing total quantities and monetary values based on issued and recorded transactions.

1. Go to Analysis > Departmentwise Item Consumption Summary.
2. Use the Funnel filter or Group By drop-down options to filter for specific information or customize the grouping.
3. Review the departmental usage and consumption patterns on your screen.
