# How to run a POS Inventory Post if you need to post POS sales and inventory updates into system?

To run a POS Inventory Post to record Point of Sale sales and update inventory levels, follow these steps:

1. Go to Transaction > POS Inventory Post.
2. Select the Outlet and the required date range.
3. Select the Store and choose the Product name.
4. Click the Save button to post the inventory updates into the system.

***

Prerequisite Setup: POS Post Settings

If you need to configure or update the rules that control how POS sales map to specific inventory stores and product groups, you can set them up beforehand:

1. Go to Master > POS Post Settings.
2. Click Open and select the Outlet name.
3. Click Add and select the relevant Product group and CC store.
4. Click Save to finalize the settings.
