# Material Request – Cancel

The **Material Request Cancel** option is used to cancel an existing Material Request that was created by mistake or is no longer required.This feature allows users to cancel a complete Material Request and prevents further processing of the request.

## Steps to Perform a Material Request Cancellation

Step 1: Navigate to **Transactions** in the **Inventory** module.

1. Select **Material Request Cancel**.

* The Material Request Cancel screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 11-12-19.png" alt=""><figcaption></figcaption></figure>

Step 2: Locate the **Store** field.

1. Select the appropriate store from the available list.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 11-26-07.png" alt=""><figcaption></figcaption></figure>

Step 3: Click on the **Receipt No** field.![](<../../../.gitbook/assets/Screenshot from 2026-06-01 11-00-10 (1).png>)

1. Select the Material Request number that needs to be cancelled.

* The details of the selected Material Request will be displayed on the screen.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 11-27-17.png" alt=""><figcaption></figcaption></figure>

Step 4:Click the **Cancel** button.

1. A dialog box will appear requesting a cancellation reason.
2. Enter the reason for cancellation (Examples: Material Request created by mistake, Request no longer required).
3. Click **OK** to confirm the cancellation reason.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 11-29-16.png" alt=""><figcaption></figcaption></figure>

Step 5: Review the cancellation details.

1. Click the **Save** button.![](<../../../.gitbook/assets/Screenshot from 2026-06-01 10-26-56 (2).png>)

* The selected Material Request will be successfully cancelled and removed from further processing.
