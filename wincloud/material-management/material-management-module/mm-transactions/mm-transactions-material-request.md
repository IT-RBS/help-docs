# Material Request

A **Material Request (MR)** is a process used by departments to request materials or products from a specific store. This feature helps users request the required items and transfer them from one store to another in a controlled and documented manner.

## Steps to Create a Material Request

Step 1: Navigate to **Transactions** in the **Inventory** module.

1. Select **Material Request**.

* The Material Request screen will open.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-16-29.png" alt=""><figcaption></figcaption></figure>

Step 2: Click the **Store** field.

1. Select the store from which the material request will be created.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-16-55.png" alt=""><figcaption></figcaption></figure>

**Note:** The selected store will display the available inventory items.

Step 3: Click the **Add (+)** icon.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-22-57.png" alt=""><figcaption></figcaption></figure>

1. Select the required product item from the list.

* The selected item will be added to the Material Request document.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-18-18.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the product item, locate the **MR Quantity** field.

1. Enter the quantity required for the selected item.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-25-09.png" alt=""><figcaption></figcaption></figure>

Step 5: Locate the **Request Store** field.

1. Select the destination store where the requested material is needed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-19-19.png" alt=""><figcaption></figcaption></figure>

Step 6: Verify all entered details and click **Save**.![](<../../../.gitbook/assets/Screenshot from 2026-06-01 10-26-56.png>)

* The Material Request will be successfully created and recorded in the system.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-20-13.png" alt=""><figcaption></figcaption></figure>

If you want to print the Material Request immediately:

1. Select the **Print** checkbox before saving.

* The Material Request document will be generated and printed automatically.
