# Material Request Reprint

The **Material Request Reprint** option allows users to print an additional copy of a previously generated Material Request document. This feature is useful when the original printout is lost, damaged, or when extra copies are required for record-keeping and operational purposes.

## Steps to Perform a Material Request Reprint

Step 1: Navigate to **Transactions** in the **Inventory** module.

1. Select **Material Request Reprint**.

* The Material Request Reprint screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-37-27.png" alt=""><figcaption></figcaption></figure>

Step 2: Locate the **Issue CC Store** field.

1. Select the appropriate store from the available list.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-38-06.png" alt=""><figcaption></figcaption></figure>

2. Click the **Display** button.

* The system will display all Material Request records associated with the selected store.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-39-25.png" alt=""><figcaption></figcaption></figure>

Step 3: Select the Material Request document that needs to be reprinted.

* Ensure that the correct document is selected before proceeding.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-06-01 10-40-42.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the required Material Request, click the **Print** button![](<../../../.gitbook/assets/Screenshot from 2026-06-01 10-41-24.png>) located in the top-right corner of the screen.

1. The system will generate and print a copy of the selected Material Request document.
