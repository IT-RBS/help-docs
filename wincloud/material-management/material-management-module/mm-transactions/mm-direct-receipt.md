# Direct Receipt

**Direct Receipt**

3.2.1 Once the user has selected the stores,You have to Select the Department, Screen shown below.

![](../../../.gitbook/assets/44.png)

3.2.2. Once the User has selected The Department, click on the Item search icon to list out the Items, screen shown below.

![](../../../.gitbook/assets/45.png)

3.2.3 After selecting the required items, the Issue quantity has to entered.

![](<../../../.gitbook/assets/4 (71).png>)

3.2.3 Once the user entered the Issue quantity, click save to generate the Issue.

![](../../../.gitbook/assets/43.png)

Note: If you select Print check Box the Issue will be printed.
