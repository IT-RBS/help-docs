# What is PR Short-Close?

PR Short-Close (navigated in the system as Purchase Order Short Close) is an option used to close out a purchase order or request that has not been used or has been pending for a long time.If you need to perform a PR Short-Close, the steps are:

1. Go to the Purchase main menu.
2. Click on **Transaction > Purchase Order Short Close.**
3. Click on the short-close purchase order option on the screen.
4. Click the Open button and select the appropriate Request Number.
5. Click the Save button to complete the process.

_(Note: If the purchase order itself has already been generated and needs to be short-closed, you would instead use the_ PO ShortClose _option under **Transaction > PO ShortClose**_
