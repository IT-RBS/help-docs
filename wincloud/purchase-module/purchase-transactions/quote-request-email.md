# Quote Request Email

The **Quote Request Email** option is used to send Request for Quotation (RFQ) details to vendors through email. This feature helps organizations communicate quotation requests quickly and efficiently to suppliers.

## Steps to View and Send Quote Request Email

Step 1: Go to the **Purchase** main menu.

1. Click **Transaction**.
2. Select **Quote Request Email**.

* The Quote Request Email screen will appear.

<figure><img src="../../.gitbook/assets/Screenshot from 2026-05-27 17-10-01.png" alt=""><figcaption></figcaption></figure>

Step 2: Select the required **From Date** and **To Date**.

* The selected date range will help display the required quotation requests.

Step 3: Click the **Display** button.

* The system will display the list of Quote Request emails based on the selected date range.

<figure><img src="../../.gitbook/assets/Picture1 (2).png" alt=""><figcaption></figcaption></figure>

Step 4: Choose the required email or RFQ entry from the displayed list.

1. Verify the vendor and quotation details before sending.

Step 5: Click the **Send** button.

* The selected Quote Request email will be sent to the vendor successfully.
