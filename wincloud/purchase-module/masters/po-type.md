# PO Type

The **PO Type (Purchase Order Type)** master is used to create and manage different types of Purchase Orders in the system.

## **Steps to Create PO Type**

Step 1: Navigate to the **Purchase** main menu from the dashboard.

1. Click on **Masters**.
2. From the Masters menu, select **PO Type**.

* After clicking **PO Type**, the PO Type management screen will open.

<figure><img src="../../.gitbook/assets/Screenshot from 2026-05-29 12-16-06.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **Add** button.![](<../../.gitbook/assets/Screenshot from 2026-05-29 12-16-50.png>)

1.  Enter the required details in the fields provided:

    * **PO Type Name** – Enter the name of the purchase order type
    * **PO ID** – Enter a unique identification code for the PO type

    <figure><img src="../../.gitbook/assets/Screenshot from 2026-05-29 12-17-11.png" alt=""><figcaption></figcaption></figure>

Step 3: Select the **Active** checkbox to activate the PO Type.

1.  Enable or disable the required menus based on business requirements.

    * This helps control which features are available for this PO type.

    <figure><img src="../../.gitbook/assets/Screenshot from 2026-05-29 12-24-27.png" alt=""><figcaption></figcaption></figure>

Step 4: After entering all required details and settings, click on the **Save** ![](<../../.gitbook/assets/Screenshot from 2026-05-29 12-19-07 (2).png>)button.

* The system will successfully create and store the new PO Type.
