# Purchase Requisition Status Report

**Purchase Requisition Status Report**

This report shows you all the PR (Purchased Requests) raised with the current status.

Multiple filters are provided for ease of use.

**Report By** is to select the primary data of sequence for the report.

![](<../../.gitbook/assets/1 (277).png>)

**Funnel Filter** is to search for specific PR, Department or Cost Center etc.

![](<../../.gitbook/assets/2 (2).png>)

**Status** is provided to search for a PR with a specific Status.

![](<../../.gitbook/assets/3 (96).png>)

It shows all the information related to PR and it's processes such as if the PO against this PR has been generated or not and if yes what is the PO no. etc.

![](<../../.gitbook/assets/4 (87).png>)
