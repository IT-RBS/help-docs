# PR Audit Report

**PR Audit Report**

This report is to show any change or modification (if) that has happened in a PR. It will show the data of any PR from creation to its operationally closed status or Completed or Cancelled status.

You can filter changes made by any specific **User**:

![](<../../.gitbook/assets/1 (53).png>)

Search for the Specific PO which you are looking for:

![](<../../.gitbook/assets/2 (173).png>)

**Sort** the report based on the following:

![](<../../.gitbook/assets/3 (197).png>)

The “**Critical Change**” usually means any rate change or cancellation.

![](<../../.gitbook/assets/4 (17).png>)

And through **PR Operation**, You can select the kind of transaction status you are looking for

![](<../../.gitbook/assets/5 (75).png>)

![](<../../.gitbook/assets/6 (35).png>)

The report will reveal data based on the changes made and what was the data before the changes.

![](<../../.gitbook/assets/7 (9).png>)
