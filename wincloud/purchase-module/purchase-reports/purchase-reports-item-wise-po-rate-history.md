# Item wise PO Rate History

**Item wise PO Rate History**

What is **Item Wise PO Rate History ?**

Using this report the user can check the item wise rates with supplier details along with taxes, PO quantity. All of the details will appear here.

Steps to open **Item Wise PO Rate History,**

1. Go to **Reports >** I**tem Wise PO Rate History,**
2. After opening the user can sort on as shown in the screen below.

![](<../../.gitbook/assets/0 (156).png>)

1. After selection click display and the report will be generated.

**Note** : The user can convert the report to excel by clicking on this Icon ![](<../../.gitbook/assets/2 (49).png>)
