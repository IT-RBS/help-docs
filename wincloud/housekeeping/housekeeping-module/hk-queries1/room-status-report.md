# Room Status Report

The **Room Status Report** is used to view the current status of all rooms in the hotel. This report helps hotel staff monitor room availability, occupancy, housekeeping status, and maintenance conditions.

## Steps to Open the Room Status Report

Step 1: Go to the **Housekeeping** main menu.

1. Select the **Queries** menu.
2. Click on **Room Status Report**.

* The **Room Status Report** screen will open.

Step 2: Choose the additional options that you want to include in the report.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 11-50-55.png" alt=""><figcaption></figcaption></figure>

Step 3: Select the required filters![](<../../../.gitbook/assets/Screenshot from 2026-05-26 11-53-12.png>) to narrow down the report results.

* Filters help users display only the rooms that match the selected criteria.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 11-52-25.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the required options and filters, click on the **Display** button.

* The **Room Status Report** will appear on the screen.
