# Room Status

The **Room Status** report provides a complete overview of the current status of all hotel rooms. This report helps hotel staff monitor room occupancy, room availability, housekeeping conditions, and blocked rooms in a single screen.Each room status is displayed with a separate color for easy identification and quick monitoring.

* The report can also be sorted floor wise, group wise, room type wise
* This feature is highly useful for the Front Office, Housekeeping, Reservation, and Management departments.

## Steps to Open Room Status

Step 1: Go to the **Housekeeping** main menu.

1. Select the **Queries** menu.
2. Click on **Room Status**.

* The **Room Status** screen will open.

Step 2: Click on the **Advanced Filter** option.![](<../../../.gitbook/assets/Screenshot from 2026-05-26 12-12-41.png>)

* The Advanced Filter allows users to filter room details based on specific criteria.
* Select the required sorting option from the available list.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 12-09-39.png" alt=""><figcaption></figcaption></figure>

Step 3: After selecting the sorting and filter options, the Room Status details will be displayed on the screen.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 12-10-56.png" alt=""><figcaption></figcaption></figure>

**Important Note:**

* Each room status is displayed using a separate color for quick identification.
