# How do I view the room status report?

To view the Room Status Report, you should use the Queries menu within the Housekeeping module. Following these steps will generate the report:

1. **Access the Menu:** Navigate to the Queries menu and select Room Status Report.
2. **Apply Filters (Optional):** Choose any additional options you want printed in the report or use the available filter options to narrow down the results.
3. **Display:** Click the Display button to view the report.

Related Room Status ReportsThe system also offers other ways to view room status information depending on the level of detail or the specific format you require:

* **Room Status (Visual/Interactive):** Go to Queries > Room Status. This report provides a color-coded overview of room occupancy, including Vacant, Blocked (Management/Guest/Maintenance), and Dirty rooms. You can sort this view by floor, group, or room type and use advanced filters as needed.
* **Housekeeping Room Status List:** Navigate to REPORTS > HOUSE KEEPING ROOM STATUS LIST and click Display. This report provides real-time information specifically on whether rooms are Clean, Dirty, Inspected, or Out-of-Order to help staff manage daily operations.
