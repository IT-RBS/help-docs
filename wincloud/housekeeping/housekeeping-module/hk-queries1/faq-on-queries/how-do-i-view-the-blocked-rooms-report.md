# How do I view the Blocked Rooms report?

To view the Blocked Rooms report within the Housekeeping module, which allows you to check details like the reason for the block, the user who performed it, and the current status, follow these steps:

1. Navigate to the Queries menu and select Blocked Rooms.
2. Choose any additional options you want printed in the report or use the available filter options to narrow your results.
3. Click the display button to generate and view the report.

This report provides a comprehensive list of rooms currently out of service, including the blocked for reason, the room type, the username of the person who blocked it, the date it was blocked, and the room's current status
