# How to view in-house guest lists?

To view the In House Guest List, which allows you to check details such as arrival and departure dates, guest types, and pax details, follow these steps within the Housekeeping module:

1. **Navigate to the Menu:** Go to the Queries menu and select In House Guest List.
2. **Select Options:** Choose any additional options or filters you want to be applied to the report.
3. **Sort:** You can sort the list as needed using the sorting options on the screen.
4. **Display:** Click the display button to generate and view the report
