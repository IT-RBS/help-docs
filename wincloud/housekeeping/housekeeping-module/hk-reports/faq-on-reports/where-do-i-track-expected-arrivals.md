# Where do I track expected arrivals?

To track Expected Arrivals, you should use the specific report located within the Housekeeping module. This report displays upcoming confirmed reservations that have not yet arrived.To access and manage this information, follow these steps as outlined in the sources:

* **Navigation:** Go to the Housekeeping module, select Reports, and then click on Expected Arrivals.
* **Viewing Options:**
  * **Date Range:** You can view day-wise arrivals or change the date to view past date arrivals.
  * **Filters:** Use the filter icon to search for specific reservations based on criteria like market segment or reservation status.
  * **Additional Details:** To see more information, you can select specific fields to add columns to the report, provided that information was entered during the initial reservation.
* **Output:** The report can be converted to Excel or printed directly from the system
