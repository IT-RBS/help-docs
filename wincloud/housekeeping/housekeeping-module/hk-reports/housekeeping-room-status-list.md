# Housekeeping Room Status List

The **House Keeping Room Status List** report provides real-time information about the current status of guest rooms within the property. It helps housekeeping staff monitor and manage room operations efficiently by displaying room conditions such as Clean Rooms, Dirty Rooms, Inspected Rooms and Out-of-Order Rooms.

* This report assists the housekeeping department in planning cleaning schedules, room allocation, and operational activities effectively.

## Steps to View House Keeping Room Status List

Step 1: Open the **Housekeeping** module.

1. Click on **Reports**.
2. Select **Housekeeping Room status List**.
