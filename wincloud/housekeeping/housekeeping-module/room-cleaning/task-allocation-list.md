# Task Allocation List

The **Task Allocation List** is a feature in the Housekeeping module that allows users to view the list of tasks assigned to housekeeping attendants. This screen helps supervisors monitor task assignments, track room cleaning activities, and verify which attendant is responsible for specific tasks.

## Steps for Viewing the Task Allocation List

Step 1: Go to the **Housekeeping** main menu.

1. Click on **Room Cleaning**.
2. Select **Task Allocation List** from the sub menu.

* The **Task Allocation List** screen will open.

<figure><img src="../../../.gitbook/assets/a3 (1).png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **Task** field.

1. Select the required task type from the available options.

Step 3: Click on the **Attendant** dropdown field.

1. Choose the required housekeeping attendant from the list.

<figure><img src="../../../.gitbook/assets/a3.1 (1).png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the task and attendant, click on the **Display** button.

* The system will display the **Task Allocation List** based on the selected criteria.
