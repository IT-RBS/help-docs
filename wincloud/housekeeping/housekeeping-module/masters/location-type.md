# Location Type

The **Location Type** master in the House Keeping module is used to define and manage different categories of locations within the property. These location types help organize housekeeping operations by classifying areas such as guest areas, service areas, storage areas, laundry sections, and other operational zones.

## Steps to Create a Location Type

Step 1: Go to the **Housekeeping** module from the main menu.

1. Click on **Masters** and select **Location Type.**

* The **Location Type** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 16-47-28.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **New** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-26 16-47-46.png>)

1. Enter the required details in the respective fields:

* **Location Type ID -** enter the unique identification code for the location type.
* **Location Type Name -** enter the name of the location type.
* **Location Type -** select or enter the category/type as required.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 16-48-32.png" alt=""><figcaption></figcaption></figure>

Step 3: After entering all required details, click on the **Save** button.

* The Location Type will be created successfully and added to the master list.
