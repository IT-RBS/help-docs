# Store

The **Store Master** in the House Keeping module is used to create and manage stores where housekeeping stock items are maintained. These stores help organize inventory based on stock type and stock category, enabling efficient stock management and tracking.

* The Store Master supports better inventory control, stock allocation, and operational management within the housekeeping department.

## Steps to Create a Store

Step 1: Go to the **Housekeeping** module from the main menu.

1. Click on **Masters** and select **Store.**

* The **Store** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 17-01-01.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **New** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-26 16-47-46 (3).png>)

1. Enter the required details in the respective fields.

* **Store ID -** enter the unique identification code for the store.
* **Store Name -** enter the name of the store.
* **Stock Type -** select the required stock type.
* **Stock Category -** select the appropriate stock category.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 17-01-41.png" alt=""><figcaption></figcaption></figure>

Step 3: After entering all required details, click on the **Save** button.

* The store will be created successfully and added to the Store Master list.
