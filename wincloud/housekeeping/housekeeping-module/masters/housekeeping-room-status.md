# Housekeeping Room Status

The **Housekeeping Room Status** master in the House Keeping module is used to define and manage different room status types. These statuses help the housekeeping department track and update the current condition of rooms such as clean, dirty, inspected, or out-of-order.

## Steps to Create Housekeeping Room Status

Step 1: Go to the **Housekeeping** module from the main menu.

1. Click on **Masters** and select **Housekeeping Room Status.**

* The **Housekeeping Room Status** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 18-08-08.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **New** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-26 18-08-28.png>)

1. Enter the required details in the respective fields.

* **Status ID -** enter a unique identification code for the room status.
* **Status Name -** enter the name of the room status.
* **Status Type -** select the appropriate status type.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 18-10-08.png" alt=""><figcaption></figcaption></figure>

Step 3: After entering all required details, click on the **Save** button.

* The Room Status will be created successfully and added to the master list.
