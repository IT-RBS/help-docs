# Store Transaction Type

The **Store Transaction Type** master in the House Keeping module is used to define and manage different types of store transactions. These transaction types help track stock movements such as stock issue, stock receipt, transfer, return, and adjustment activities within housekeeping stores.

## Steps to Create a Store Transaction Type

Step 1: Go to the **Housekeeping** module from the main menu.

1. Click on **Masters** and select **Store Transaction Type.**

* The **Store Transaction Type** screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 17-25-52.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **New** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-26 16-47-46 (1).png>)

1. Enter the required details in the respective fields.

* **Store -** select the required store from the list.
* **Transaction ID -** enter the unique identification code for the transaction type.
* **Transaction Name -** enter the name of the transaction type.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 17-27-21.png" alt=""><figcaption></figcaption></figure>

Step 3: After entering all required details, click on the **Save** button.

* The Store Transaction Type will be created successfully and added to the master list.
