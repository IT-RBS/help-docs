# What is the process for lost item disposal?

The process for Lost and Found Disposal within the Housekeeping module involves the following steps:

1. **Access the Menu:** Go to the House Keeping main menu and click on Transaction > Lost and Found Disposal.
2. **Select the Record:** Click on Lost and Found No. and select the specific lost and found transaction from the list that requires disposal.
3. **Review Information:** Once the reference number is selected, the system will automatically display all the information originally entered for that lost and found transaction.
4. **Enter Disposal Details:** Click on the Dispose Tab and select the following details:
   * The type of disposal.
   * The Dispatch mode.
   * The name of the person Dispatched by.
5. **Finalize:** Click the save button to complete the disposal process.

For administrative setup, the system also includes Masters menus for Dispose and Dispatch, where authorized users can create and manage specific IDs and names for various disposal types and dispatch methods
