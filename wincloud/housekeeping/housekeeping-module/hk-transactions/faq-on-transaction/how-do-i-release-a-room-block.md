# How do I release a room block?

To release a room block within the Housekeeping module, you should follow these specific steps:

1. **Access the Menu:** Go to the Housekeeping Main Menu.
2. **Open Room Blocking:** Click on the Room Blocking Menu.
3. **Select Release Option:** Click on the Block Release option for the block that needs to be released.
4. **Identify the Block:** Once the respective screen opens, click select on the particular block that needs to be released.
5. **Enter Narration:** Type in a proper release narration explaining why the block is being removed.
6. **Finalize:** Click the release block button to complete the process
