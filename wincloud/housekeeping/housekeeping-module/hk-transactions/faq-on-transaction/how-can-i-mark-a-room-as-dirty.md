# How can I mark a room as dirty?

To mark a room as dirty, you should use the Tag room as Dirty/Inspected/Pickup option within the Housekeeping module. Following these steps will update the room's status:

1. **Access the Menu:** Go to the Housekeeping Main Menu.
2. **Navigate to Transactions:** Click on Transaction > Room Blocking.
3. **Select Rooms:** Choose the specific types of rooms you wish to update.
4. **Finalize:** Click the Save button to tag the selected room as dirty.

**Key Considerations:**

* **Status Indicators:** The system allows you to mark a room as "Dirty" even if it is currently occupied or blocked. In these instances, the visual status color (for occupied or blocked) will remain unchanged, but the room will show a "dirty" text indication.
* **Operational Impact:** It is important to clear the dirty status before a new guest arrives, as the system will not allow a check-in for any room currently marked as "Dirty"
