# How do I clear a dirty status?

To clear a "Dirty" room status, you must use the Clear Dirty Room option within the Housekeeping module. It is critical to perform this task because the system will not allow a check-in for any room that currently has a "Dirty" status.Follow these steps to clear the status:

1. **Access the Menu:** Go to the House Keeping main menu.
2. **Navigate to Transactions:** Click on Transaction > Clear dirty room.
3. **Select the Room:** Choose the specific Dirty Room No. from the list provided on the screen.
4. **Finalize:** Provide a narration for the action and click the save button to successfully clear the status
