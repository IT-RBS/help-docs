# How do I block a room for maintenance?

To block a room for maintenance within the Housekeeping module, you use the Room Blocking feature. This function allows you to temporarily take a room out of service for various reasons, including maintenance, management, or guest-specific needs.Follow these steps to complete the process:

1. **Access the Menu:** Go to the Housekeeping Main Menu.
2. **Open Room Blocking:** Click on the Room Blocking Menu.
3. **Specify Block Type:** In the "blocking for" option, select the specific block type (e.g., Maintenance) and then select the relevant room type.
4. **Select the Room:** Choose the specific Room No. that needs to be blocked.
5. **Set the Duration:** Select the From and To dates for the maintenance period.
6. **Provide a Reason:** Enter a narration explaining the reason for the block.
7. **Finalize:** Click the Save button to complete the process.

The system will allow you to tag these blocked rooms as "Dirty" if necessary, though the status color will remain the same as the blocked room status with a "dirty" text indication. To track these rooms later, you can view the Blocked Rooms report or the Room Status report under the Queries menu
