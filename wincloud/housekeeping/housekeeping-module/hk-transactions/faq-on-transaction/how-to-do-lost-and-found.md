# How to do lost and found ?

To manage Lost & Found items within the Housekeeping module, you must follow specific procedures for recording the item, printing documentation, and eventually disposing of it.

**1. Recording a Found Item**&#x20;

To create a new lost and found entry, follow these steps:

* **Access the Menu:** Go to the Transaction Main Menu and select Lost & Found.
* **Location Selection:** Select the Location type. If the location is a Room, you can select the guest name from the Checked out Room List. For checked-out guests, the system will automatically pull the address from their guest profile.
* **Time and Date:** The system defaults to the current date and time (in HH:MM format), though these can be manually changed if the item was found earlier.
* **Item Description:** Provide a detailed description of the found object (up to 200 characters).
* **Personnel Details:** Enter the name of the informer (who found the item) and the name of the person who stored the information.
* **Finalize:** Click the Save button to update the record successfully.

**2. Printing and Letters**

* **Lost and Found Letters:** You can print a formal letter if this feature is enabled in your master settings; the format is customizable based on client requirements.
* **Article Printing:** To print details for a specific article, navigate to Transaction > Lost & Found - Printing, select the specific article, and click Save.

**3. Lost and Found Disposal**

When an item needs to be cleared from the system, follow the disposal process:

* **Navigate:** Go to the House Keeping main menu and select Transaction > Lost and Found Disposal.
* **Select Record:** Click on Lost and Found No. to select the specific transaction from the list. Once selected, all original transaction information will populate the screen.
* **Dispose Details:** Click the Dispose Tab to select the type of disposal, the dispatch mode, and the person who dispatched it.
* **Save:** Click the Save button to finalize the disposal.

**4. Tracking and Status**

To monitor the status of lost or found items, you can use the Lost And Found Status report located under the Queries menu. This report allows you to view items categorized by their current status or item type
