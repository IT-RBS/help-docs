# Requests/Messages

The **Guest Complaints / Requests / Messages** option is used to record and manage guest communications within the hotel management system.

* This feature helps staff track Guest complaints, Service requests and Guest messages.
* It ensures that all guest-related issues and requests are properly documented and followed up by the concerned department.

## Steps to Create Guest Complaints / Requests / Messages

Step 1: Go to the **Housekeeping Main Menu**.

1. Click on **Transaction**.
2. Select **Guest Complaints / Requests / Messages**.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 14-34-16.png" alt=""><figcaption></figcaption></figure>

Step 2: Choose the required type from the available options.

* Select the option based on the guest communication requirement.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 14-35-42.png" alt=""><figcaption></figcaption></figure>

Step 3: Choose the appropriate guest type.

* The available guest list will be displayed based on the selected guest type.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 14-37-27.png" alt=""><figcaption></figcaption></figure>

Step 4: Click on the **Reserve No Search** option.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 14-42-25.png" alt=""><figcaption></figcaption></figure>

1. Search for the guest reservation.
2. Select the required **Guest Name** from the list.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 14-43-31.png" alt=""><figcaption></figcaption></figure>

Step 5: Enter the Complaint / Request / Message details.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 14-48-00.png" alt=""><figcaption></figcaption></figure>

Step 6: After entering all required details, click on the **Save** button.![](<../../../.gitbook/assets/Screenshot From 2026-05-25 16-29-15 (2).png>)

* Once saved successfully, the Complaint / Request / Message will be recorded in the system for further action and follow-up.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 14-50-02.png" alt=""><figcaption></figcaption></figure>
