# Tag room as Dirty/Inspected/ Pickup

The **Tag Room as Dirty / Inspected / Pickup** option is used to update the housekeeping status of rooms. This feature helps the housekeeping department track room cleaning progress and room readiness efficiently.

**Important Note**

* The system allows rooms to be marked as **Dirty** even if the room is **Occupied** or **Blocked**.
* In such cases the room colour/status remains the same based on occupancy or block status.
* However, the room will display a **“Dirty”** text indication.

## Steps to Tag a Room as Dirty / Inspected / Pickup

Step 1: Go to the **Housekeeping Main Menu**.

1. Under **Transactions,** select **Tag a Room as Dirty.**

* The Room Status screen will appear displaying the list of available rooms.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 13-02-08.png" alt=""><figcaption></figcaption></figure>

Step 2: Select the required room status type.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-05-25 13-03-37.png" alt=""><figcaption></figcaption></figure>

Step 3: Choose the room for which the status needs to be updated.

Step 4: Click on the **Save** button.![](<../../../.gitbook/assets/Screenshot From 2026-05-25 16-29-15 (4).png>)

* Once saved successfully, the selected room status will be updated in the system.
