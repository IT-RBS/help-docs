# Guest Charges

The **Guest Charges** option is used to post additional charges into the guest ledger when revenue postings are missed or need to be added manually. This feature allows users to add various charges such as telephone charges, laundry charges, miscellaneous charges, and allowances directly to the guest account.

## Steps to Create Guest Charges

Step 1: Go to the **Housekeeping** main menu.

1. Click on **Cashier**.
2. Select **Guest Charges** from the submenu.

* The **Guest Charges** screen will open.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-40-32.png" alt=""><figcaption></figcaption></figure>

Step 2: In the Guest Charges window, select the **Room Number** for which the charges need to be posted.

* Ensure the correct room number is selected before proceeding.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-41-42.png" alt=""><figcaption></figcaption></figure>

Step 3: In the Guest Charges window, the available revenues will be linked under different **Outlet Names**.

1. Select the required **Outlet** from the list.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-43-05.png" alt=""><figcaption></figcaption></figure>

2. Once the outlet is selected, the system will display the revenue names linked to the selected outlet.
3. Select the required **Revenue Name**.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-45-39.png" alt=""><figcaption></figcaption></figure>

Step 4: After selecting the revenue name confirm the room number.

1. Enter the amount to be posted into the guest ledger.

* Ensure the entered amount is correct before saving.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-48-01.png" alt=""><figcaption></figcaption></figure>

Step 5: Click on the **Save** button provided in the toolbar at the top of the Guest Charges window.

* The charges will now be updated successfully in the guest ledger.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-49-21.png" alt=""><figcaption></figcaption></figure>

**Additional Features in Guest Charges**

Using the Guest Charges option, users can also:

* Post telephone call charges.
* Post laundry charges.
* Add miscellaneous charges.
* Pass allowances to the guest ledger.

This helps maintain accurate guest billing records.

**Important Note**

* Guest charges can only be posted based on the current **Account Date**.
* The system does not allow users to post previous day charges through the Guest Charges option.

If a charge has been posted incorrectly, the system allows the user to modify the guest charge bill using **Open Mode**.

**Steps to Modify Guest Charges**

Step 1: Open Guest Charges Window

Step 2: Click on the **Refresh** button provided in the toolbar at the top of the Guest Charges window.

* This will enable the Open Mode option.![](<../../../.gitbook/assets/Screenshot from 2026-05-26 10-50-58.png>)

Step 3: Select the bill that needs to be modified from the displayed list.

* Ensure the correct bill is selected before making changes.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-52-00.png" alt=""><figcaption></figcaption></figure>

Step 4: Modify the Bill.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-26 10-54-17.png" alt=""><figcaption></figcaption></figure>

Step 5: After completing the modifications, click on the **Save** button.

* The updated charges will now be reflected in the guest ledger.
