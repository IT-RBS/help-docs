# How can I post guest charges for laundry?

To post laundry charges to a guest ledger, you use the Guest Charges option within the Housekeeping module.Steps to Post Laundry Charges

1. **Access the Menu:** Go to the House Keeping Main Menu and click on Cashier > Guest Charges.
2. **Select the Room:** Choose the specific room number for which you would like to post the laundry charges.
3. **Choose the Outlet and Revenue:**
   * In the guest charges window, select the required outlet where laundry revenue is linked.
   * Once the outlet is selected, choose the specific revenue name (e.g., Laundry).
4. **Enter the Amount:** Select the room number again if prompted and enter the amount to be posted.
5. **Finalize:** Click the Save button in the top toolbar to update the charges into the guest ledger.

**Important Considerations**

* **Account Date:** You can only post charges based on the current account date. The system does not allow you to post charges for a previous day.
* **Other Charges:** This same menu is also used for posting telephone calls, miscellaneous charges, or passing allowances.
* **Modifications:** If an amount is posted incorrectly, you can modify it by clicking the Refresh button in the toolbar to enter "open mode," selecting the bill, making the necessary changes, and saving it again
