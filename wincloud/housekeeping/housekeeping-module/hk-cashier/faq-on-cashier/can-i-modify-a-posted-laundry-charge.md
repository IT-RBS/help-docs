# Can I modify a posted laundry charge?

Yes, you can modify a posted laundry charge if it was entered incorrectly. To do this, you must use the open mode within the Guest Charges window.Follow these steps to modify the charge:

1. **Access Guest Charges:** Navigate to the House Keeping Main Menu and select Cashier > Guest Charges.
2. **Enter Open Mode:** Click the Refresh Button located in the toolbar at the top of the window.
3. **Select the Bill:** Choose the specific bill that requires modification from the list.
4. **Update and Save:** Make the necessary changes to the bill and click the Save button to finalize the correction.

**Important Note:** While you can modify incorrect entries, the system only allows posting or managing charges based on the current account date. You cannot post or manage charges for a previous day
