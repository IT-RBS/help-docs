# User

The **User Creation** option is used to create and manage user accounts for individuals who need access to the software. Through this option, you can create new user accounts, modify the details of existing users and deactivate users who no longer require system access.

## Steps to Create a New User Account:

Step 1: Open the **Masters** module.

1. Click on the **Company** menu.
2. Select **User**.

Step 2: Click **New**![](<../../../.gitbook/assets/Screenshot From 2026-06-11 15-07-59.png>) to create a new user account.

1. Fill in all the required user information in the available fields.

* Ensure that the details entered are accurate and complete.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-11 15-08-46.png" alt=""><figcaption></figcaption></figure>

Step 3: After entering all the necessary information, click **Save**.![](<../../../.gitbook/assets/Screenshot From 2026-06-11 15-09-24.png>)

* The new user account will be created successfully.

**Note:**

* Click **Open** to access an existing user record, then click the **Search** button to locate and select the required user.
