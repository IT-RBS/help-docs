# KOT Audit

The **KOT Audit Report** is used to track and review Kitchen Order Ticket (KOT) activities in detail. It provides a complete history of KOT transactions, including created, amended, and cancelled orders.

* This report helps in monitoring kitchen operations and order accuracy.

## Steps to View KOT Audit Report

Step 1: Navigate to the **Point of Sale** module and click the **Advanced Reports** menu.

1. Select **KOT Audit**.

* The KOT Audit Report screen will open.

<figure><img src="../../.gitbook/assets/Screenshot from 2026-05-12 17-00-37.png" alt=""><figcaption></figcaption></figure>

Step 2: Choose the required **additional options** that you want to include in the report.

1. If needed, apply **sorting options** to organize the data as required.

* These options help customize the report for better analysis.

Step 3: Generate the Report

1. After selecting all required options, click on the **Display** button.
2. The system will generate and display the **KOT Audit Report**.

<figure><img src="../../.gitbook/assets/Screenshot from 2026-05-12 17-03-08.png" alt=""><figcaption></figcaption></figure>

* The report will show detailed KOT information, including created, amended, and cancelled entries.
