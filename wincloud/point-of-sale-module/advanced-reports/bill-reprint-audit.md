# Bill Reprint Audit

The **Bill Reprint Audit Report** is used to track and monitor how many times a bill has been reprinted by users in the system. It provides a detailed audit of reprint activities for accountability and control.

## Steps to View Bill Reprint Audit Report

Step 1: Navigate to the **Point of Sale** module and click the **Advanced Reports** menu.

1. Select **Bill Reprint Audit**.

* The Bill Reprint Audit screen will open.

<figure><img src="../../.gitbook/assets/Screenshot from 2026-05-12 16-57-21.png" alt=""><figcaption></figcaption></figure>

Step 2: Choose the required **Outlet** from the drop-down list.

* This ensures the report is generated for the correct outlet.

Step 3: Enable the **“User All”** checkbox if you want to filter specific users.

1. Select the required users from the list.

This helps you view reprint activity for selected users only.

Step 4: Select Date Range

1. Select the **From Date**.
2. Select the **To Date**.

This defines the period for which the report will be generated.

Step 5: Generate the Report

1. After applying all filters, click on the **Display** button.
2. The system will generate the **Bill Reprint Audit Report**.

<figure><img src="../../.gitbook/assets/Screenshot from 2026-05-12 16-58-58.png" alt=""><figcaption></figcaption></figure>

* To **print the report directly**, click the **Print** option.
* To **save the report in Excel format**, click the **Excel Export Icon**.
