# How do I view the NC KOT report?

To view the Non-Chargeable (NC) KOT reports, you can access either a detailed view or a summarized view depending on your needs. Both reports are found within the Advance module,.

**NC KOT Details Report**

This report provides specific information for each NC KOT, including the item details, KOT number, covers, table number, bill number, cost and sales values, and user remarks.

1. Navigate to **Advance Reports > NC Kot Details.**
2. Select the desired Advance Filter options to define what information you want printed in the report.
3. Click on Display to generate the outlet-wise report.
4. Optional: You can convert this report into an Excel format by clicking the Excel icon.

**NC KOT Type – Summary Report**

Use this version if you need a consolidated view of Non-Chargeable KOTs categorized by their specific type.

1. Navigate to **Advance Reports > NC Kot Type – Summary.**
2. Choose your preferred Advance Filter options.
3. Click Display to view the summarized outlet-wise report.
4. **Optional:** This report can also be exported to Excel using the provided icon.
