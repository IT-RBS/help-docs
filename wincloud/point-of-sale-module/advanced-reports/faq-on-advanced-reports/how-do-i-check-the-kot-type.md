# How do I check the KOT type?

To check the KOT type, you can use several reports within the system that explicitly include this information as part of their data view.

**1. Bill Audit Report**

The Bill Audit report allows you to view the KOT type along with bill numbers, steward details, items, amounts, and transaction timings.

* **Navigation:** Go to **Advance Reports > Bill Audit.**
* **Action:** Apply any necessary sorting and click Display to view the report.

**2. Bill Split Audit Report**

Similar to the standard Bill Audit, the Bill Split Audit is specifically designed for split transactions and includes the KOT type for each entry.

* **Navigation:** Go to **Advance Reports > Bill Split Audit.**
* **Action:** Click Display to load the report after applying any required filters.

**3. Non-Chargeable (NC) KOT Reports**

If you are specifically looking for the type of Non-Chargeable KOT, you can use the following specialized reports:

* **NC KOT Details:** This provides the specific NC KOT type for individual tickets, along with item details, table numbers, and user remarks.
  * **Navigation: Advance Reports > NC Kot Details.**
* **NC KOT Type Summary:** This is a consolidated report that summarizes transactions categorized by NC KOT type.
  * **Navigation: Advance Reports > NC Kot Type – Summary.**

**Configuration of KOT Types**

If you need to define or manage these categories, the system provides setup menus in the Master settings:

* **Creating NC KOT Types:** You can define new types (including Type ID and Name) by navigating to **Master1 > NC KOT Type.**
* **Report Settings:** You can configure settings for how these types appear in reports via **Master1 > Sales DayBook / NC KOT Report Settings**
