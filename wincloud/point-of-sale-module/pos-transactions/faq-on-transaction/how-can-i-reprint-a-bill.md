# How can I reprint a bill?

To reprint a bill in the POS system, you must access the Bill Reprint tool within the transactions menu. Follow these specific steps:

1. **Navigate to the Menu:** Go to the Transaction Main Menu and click on Bill Reprint.
2. A**pply Filters:** Choose the correct outlet name and select the System name from the options provided on the screen.
3. **Select the Bill:** Click the Display button to load the list of bills, then select the specific bill you wish to reprint.
4. **Print:** You must enter a Reprint Reason before clicking the Print Button to generate the new copy.

**Monitoring Reprints**

For management and oversight, the system includes a Bill Reprint Audit report. This report tracks:

* The number of reprints taken for a particular bill.
* The specific user who performed the reprint.
* A distinction between the original billed date/time and the reprint date/time.

To view this audit, go to the reports section, select your outlet and date range, and apply any necessary user filters. This report can be printed directly or exported to Excel
