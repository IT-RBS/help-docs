# Reservation Report

By clicking the ellipsis (three dots) in the top-right corner, you can access the Table Reservation Report page, where the complete reservation details can be exported either for printing or in Excel format.

Finally, once the reserved table is billed in the TPOS screen, the corresponding booked table will be automatically removed from the reservation screen.
