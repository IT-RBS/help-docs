# Creating a New Table Reservation

1. If it is a multi-property company, you can select the desired property or company from the options provided in the drop-down list before managing reservations.

<figure><img src="../../../.gitbook/assets/image (238).png" alt=""><figcaption></figcaption></figure>

2. After selecting the property, choose the desired outlet from the Outlet dropdown list to manage reservations for that specific location. The system displays only those outlets that are enabled with Table reservations within this field.

<figure><img src="../../../.gitbook/assets/image (239).png" alt=""><figcaption></figcaption></figure>

3. After selecting the outlet, choose the desired session from the Session Selector to view and manage reservations for that session.

<figure><img src="../../../.gitbook/assets/image (240).png" alt=""><figcaption></figcaption></figure>

4. There are two ways to create a booking. &#x20;
   * By clicking and dragging on the desired place on the table or &#x20;
   * By clicking the (+) icon in the left panel.&#x20;

<figure><img src="../../../.gitbook/assets/image (241).png" alt=""><figcaption></figcaption></figure>

5. Wincloud requires the mandatory client details and their status before finalizing the booking. The user is directed to the booking screen upon dragging or clicking the plus icon.

<figure><img src="../../../.gitbook/assets/image (242).png" alt=""><figcaption></figcaption></figure>

* The outlet name, session, time, and date are automatically populated. However, you can make amendments to the session, time/ duration, and date from the booking screen.&#x20;
* The pax is shown as one by default, and the user needs to make the necessary changes.&#x20;
* Status can be given as Confirmed or waiting list. &#x20;
* Click on the **View Table button** to view the available tables.&#x20;

<figure><img src="../../../.gitbook/assets/image (243).png" alt=""><figcaption></figcaption></figure>

* Select the number of tables according to the number of guests. Each table shows the default seating capacity. The pax will be displayed in the booking screen once tables are selected.

<figure><img src="../../../.gitbook/assets/image (244).png" alt=""><figcaption></figcaption></figure>

_In this example, the number of guests is 5, and the user has selected two tables, each with a default capacity of 4 guests. This is because, by default, each table is set to accommodate four people. user, with each table’s pax as 4._

* Complete the booking by filling in guest details like mobile number, Guest name, and title.&#x20;
* Select the guest status from the dropdown menu. The options are populated from the front office data.&#x20;
* If there are any notes, post them under the instruction field.&#x20;
* Save the booking. A booking confirmation message pops up to indicate a successful booking with table numbers, pax, and date.&#x20;

<figure><img src="../../../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure>

* An SMS/WhatsApp message is sent to the guest confirming their booking.&#x20;
*  Booking confirmations can be integrated with both **SMS and WhatsApp**, according to the client’s preference.&#x20;
* _The default confirmation setting is set to WhatsApp._ &#x20;

6. Once the reservation is booked, the left panel of the table reservation screen displays the status of the booking in real time as:&#x20;

<p align="center"><em>‘Reserved for Mr. Praveen Kumar, at 1 PM, Pax 05, two tables.’</em> </p>
