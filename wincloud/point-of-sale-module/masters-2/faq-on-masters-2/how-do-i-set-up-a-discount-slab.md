# How do I set up a discount slab?

To set up a discount slab (specifically for Happy Hours), you should follow these steps within the Master2 module:

1. Navigate to **Master2 > Happy Hours Discount.**
2. Click the New button to start a new configuration.
3. Select the desired discount Slab from the options provided on the screen.
4. Click the Save button to finalize the setup.

Additionally, if you need to create general categories for discounts, you can define them in **Master3 > Outlet - Discount Type**, where you can enter the discount type, narration, and the specific days the discount should be applicable
