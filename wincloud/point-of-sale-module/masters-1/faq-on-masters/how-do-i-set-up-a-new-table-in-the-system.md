# How do I set up a new table in the system?

To set up a new table in the system, you must access the KOT Table creation menu within the Master1 section.Follow these steps to complete the setup:

1. **Navigate to the Menu:** Go to **Master1 > Kot > Kot Table.**
2. **Start a New Entry:** Click on the New button.
3. **Select the Outlet:** Choose the specific Outlet where the table will be located.
4. **Enter Table Details:**
   * Input the Table name or number.
   * Specify the No of covers (seating capacity).
   * Enter the Seq no (sequence number).
5. **Select Shape:** Choose the Shape(TPOS) for the table from the provided options.
6. **Save:** Click the save button to finalize and create the new table in the system
