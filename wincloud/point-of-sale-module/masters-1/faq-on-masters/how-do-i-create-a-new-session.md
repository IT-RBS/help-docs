# How do I create a New Session?

To create a POS session, follow these steps within the Master1 module:

1. Navigate to the Menu: Go to **Master1 > POS – Session.**
2. Access the Interface: Click on the Open button.
3. Add a New Session: Click on the Add button.
4. **Enter Details:** Input the session Id and the Name in the provided fields.
5. **Save:** Click the Save button to finalize the creation.

You can also view existing Session Statistics by navigating to the Queries Main Menu and selecting Session Statistics. Additionally, if you need to analyze sales volume by session, the Cover Analysis report under the Analysis menu provides session-wise details for guest packs.
