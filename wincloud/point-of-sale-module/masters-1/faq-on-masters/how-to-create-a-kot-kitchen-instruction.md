# How to create a KOT Kitchen Instruction?

To create a KOT Kitchen Instruction, which is used to allocate instructions specifically for the kitchen, follow these steps:

1. **Navigate to the Menu:** Go to **Master1 > Kot > Kot Kitchen instruction.**
2. **Start a New Entry:** Click on the New button.
3. **Enter Details:** Input the specific Instruction and the Group Name into the required fields.
4. **Save:** Click the Save button to finalize the creation.
