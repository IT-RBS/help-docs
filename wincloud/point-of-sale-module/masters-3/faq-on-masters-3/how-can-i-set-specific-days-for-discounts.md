# How can I set specific days for discounts?

Yes, you can set specific days for discounts within the system's master settings.To configure this, you must use the Discount Type setup menu:

1. Navigate to **Master3 > Outlet - Discount Type.**
2. Click the New button to create a new entry.
3. In the configuration screen, you can enter the Discount type, a Narration, and specifically define the Applicable days for that discount.
4. Click the Save button to finalize the settings.

This allows you to control which days of the week a particular discount category can be used during a transaction.
