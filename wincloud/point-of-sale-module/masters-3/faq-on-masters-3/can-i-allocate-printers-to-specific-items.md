# Can I allocate printers to specific items?

Yes, you can allocate printers to specific items. While the standard setup often involves allocating printers to entire product groups, the system provides two specialized methods for item-level precision:

**1. Outlet-Item Printer Allocation**

This method allows you to assign specific printers to individual items within a selected outlet.

* **Navigate to: Master3 > Outlet-Item Printer Allocation.**
* **Steps:**
  1. Click the Open button.
  2. Select the desired Outlet.
  3. Click the Add button to select the specific printer name for those items.
  4. Click Save to finalize the configuration.

**2. Outlet-Item System KOT Printer Allocation**

This is a more granular configuration that allows you to allocate items to a KOT printer based on both the outlet and the specific computer system (terminal) being used to place the order.

* **Navigate to: Master3 > Outlet - Item System Kot Printer Allocation.**
* **Steps:**
  1. Click the New button.
  2. Select the relevant Outlet name and System.
  3. Click the Add button and choose the specific items to be allocated.
  4. Click Save to update the settings.

These options provide significantly more control than the standard KOT Printer Allocation, which is typically used to manage printers by product group **(via Master1 > Kot > Kot printer Allocation)**
