# Analysis- Ledger Report

**Analysis- Ledger Report**

This report is based on Analysis Levels. Analysis Level are created to bifurcate a Ledger Amount into Cost Centers. Here, the report will reflect transactions mainly under a cost centre with the division of ledger.

You can select the specific **Analysis level** you want to see. We usually keep level 1 for Cost centres.

And you can search for specific or multiple Cost Centers.

Based on the selection the report will be generated for all cost centres or the selected ones.
