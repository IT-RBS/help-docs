# Day Book

The **Day Book Report** displays all accounting transactions that occurred within a selected date or date range. It provides a chronological view of vouchers and accounting entries, helping users review daily financial activities and track transactions efficiently.

## Steps to Generate the Day Book Report

Step 1: Navigate to the **General Ledger** module.

1. Click **Reports** from the menu.
2. Select **Day Book** option.

* The day book screen will open.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-09 14-48-20.png" alt=""><figcaption></figcaption></figure>

Step 2: Locate the **Options**.

1. Select the required report format from the available options.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-09 14-49-19.png" alt=""><figcaption></figcaption></figure>

Step 3: Click the **Voucher Type** drop-down.

1. Select the required voucher type from the available list.

* If required, users can generate the report for a specific voucher type.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-09 14-50-01.png" alt=""><figcaption></figcaption></figure>

Step 4: Click the **Advance Search** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-09 14-53-48.png>)

1. Select the required filter criteria.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-09 14-51-01.png" alt=""><figcaption></figcaption></figure>

Step 5: Click the **Options** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-09 14-54-17.png>)

1. Select the required filtering criteria.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-09 14-51-33.png" alt=""><figcaption></figcaption></figure>

Step 6: After selecting all required filters, click the **Display** button.

* The system will generate and display the Day Book Report based on the selected criteria.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-09 14-52-30.png" alt=""><figcaption></figcaption></figure>

Step 7: After generating the report :

* Click the **Print** button ![](<../../../.gitbook/assets/Screenshot From 2026-06-08 16-37-58 (2).png>) to generate the report in a printable document format.
* Click the **Excel** button ![](<../../../.gitbook/assets/Screenshot From 2026-06-08 16-37-08 (2).png>) to export the report to Microsoft Excel format for further analysis and reporting.
