# Revenue Group-Analysis Code Link

The **Revenue Group – Analysis Code Link** module is used to define and manage the relationship between a revenue group and its corresponding analysis codes.

This linkage enables structured classification of revenue transactions, ensuring accurate financial reporting and detailed analysis across different dimensions such as department, project, cost center, or business activity.

## Steps to Configure Revenue Group – Analysis Code Link

Step 1: Navigate to the **General Ledger** module.

1. Click **Masters 2** from the menu.
2. Select the **Revenue Group-Analysis Code Link** option.

* The Revenue Group-Analysis Code Link screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 17-01-58.png" alt=""><figcaption></figcaption></figure>

Step 2: Choose the required **Revenue Main Group** from the list.

* The selected revenue group will be displayed for mapping.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 17-03-36.png" alt=""><figcaption></figcaption></figure>

Step 3: After selecting the revenue group, the available **Analysis Codes** will be displayed.

* Select the required analysis code(s) that need to be linked with the revenue group.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 17-04-27.png" alt=""><figcaption></figcaption></figure>

Step 4: Review the selected revenue group and linked analysis codes.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 17-05-30.png" alt=""><figcaption></figcaption></figure>

1. Click the **Save** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-10 14-29-42.png>)

* The system will save the linkage between the revenue group and the analysis code.
