# Excel Import Voucher Approval

**Excel Import Voucher Approval** is a process that allows users to upload voucher approval data into the system through an Excel file. After the file is imported, the voucher information is reviewed and authorised to ensure accuracy, completeness, and compliance with organisational accounting policies before posting or payment processing.

## Steps for Excel Import Voucher Approval

Step 1: Navigate to the **General Ledger** module.

1. Click **Transaction** from the menu.
2. Select **Excel Import Voucher Approval.**

* The voucher approval import screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-08 15-55-34.png" alt=""><figcaption></figcaption></figure>

Step 2: Click the **E** button (Excel Import option).![](<../../../.gitbook/assets/Screenshot From 2026-06-08 15-57-45.png>)

* A file selection window opens, allowing you to browse and select the required Excel file.

Step 3: Locate the Excel file containing the voucher approval details.

1. Select the file.
2. Click **Open** to upload the file.

* The system imports the voucher approval data from the selected Excel file.

Step 4: Review Imported Data

1. After the file is uploaded, review the imported voucher records.

Step 5: After verifying the imported information, click the **Save** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-08 15-58-46.png>)

* The voucher approval records are successfully saved in the system.
