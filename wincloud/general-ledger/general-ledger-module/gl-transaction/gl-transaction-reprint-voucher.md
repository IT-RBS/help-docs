# Reprint Voucher

**Reprint Voucher** is a feature that allows users to print a copy of an existing voucher that has already been generated and saved in the system. This option can be used to obtain duplicate copies of vouchers for reference, record-keeping, auditing, verification, or customer requirements.

## Steps for Reprinting a Voucher

Step 1: Navigate to the **General Ledger** module.

1. Click Transaction from the menu.
2. Select **Reprint Voucher** option.

* The Reprint Voucher screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-08 12-32-42.png" alt=""><figcaption></figcaption></figure>

Step 2: Locate the **Voucher Type** field.

1. Select the required voucher type from the available list.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-08 12-33-31.png" alt=""><figcaption></figcaption></figure>

Step 3: Use the available search filters to locate the required voucher.

1. Enter the **From Date** and **To Date** to specify the period during which the voucher was generated.

Step 4: Select the required voucher from the list.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-08 12-34-22.png" alt=""><figcaption></figcaption></figure>

Step 5: Click the **Print** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-08 12-35-16.png>)

* The system generates a printable version of the selected voucher.
