# How to create a new fiscal year?

To create a new fiscal year before closing the current one, use the Next Fiscal Year Creation feature:

1. Go to Next Fiscal Year Creation.
2. Select the Date range for the new fiscal year.
3. Enable the New Fiscal Year button.
4. Click Processed to start the new fiscal year.

After creating the new fiscal year, you can proceed with closing the current fiscal year and transferring ledgers and balances over to the new year.
