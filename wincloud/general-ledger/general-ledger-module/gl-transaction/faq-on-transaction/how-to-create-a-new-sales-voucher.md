# How to create a new Sales Voucher ?

To create an accounting voucher (such as a sales voucher or receipt transaction), you can follow the general process flow under GL Transaction:Steps to Create a Voucher:

1. Navigate to General Ledger > Transaction > GL Transaction.
2. Click on the New icon to begin a new transaction.
3. Select the required Transaction Type and Transaction Date.
4. Click and select the Customer, Party, or Account from the Chart of Accounts.
5. Enter the Amount and configure reference details (such as Ref. Type, Bill No., Bill Date, and Due Date) by selecting the bill option.
6. Add new rows to enter the appropriate CR / DR side details.
7. Save the entry. A Voucher No. will be automatically generated for that transaction type, which can be printed or referenced later.

***

Configuring a Sales Voucher Type (If Not Already Created):If you need to set up a specific Sales Voucher classification in the system first:

1. Go to Voucher Type.
2. Click the Add button.
3. Enter the Voucher Name, Voucher No Type, and discount details.
4. Click Save to create the new voucher type.
