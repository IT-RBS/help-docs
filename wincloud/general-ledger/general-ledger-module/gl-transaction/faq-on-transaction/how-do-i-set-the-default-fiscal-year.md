# How do I set the Default Fiscal Year?

To set the Default Fiscal Year in the system, follow these steps:

1. Go to Settings > Default Fiscal Year.
2. Select the Fiscal Year you want to open.
3. _(Optional)_ Select the checkbox if you want this change to reflect for all users across the system.
4. Click Save.

_(Setting a Default Fiscal Year allows you to view reports or make transactions in multiple open fiscal years_
