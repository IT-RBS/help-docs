# GL Cheque Reprint

**GL Cheque Reprint** is the process of reprinting a cheque that has been recorded in the General Ledger (GL). This feature is used when the original cheque is lost, damaged, misprinted, or requires correction.

The cheque reprint process ensures that the reissued cheque is properly authorised, tracked, and accurately reflected in the accounting records while maintaining audit and transaction integrity.

## Steps for GL Cheque Reprint

Step 1: Navigate to the **General Ledger** module.

1. Click **Transaction** from the menu.
2. Select **GL Cheque Reprint** option.

* The GL Cheque Reprint screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-08 12-48-55.png" alt=""><figcaption></figcaption></figure>

Step 2: Locate the **Voucher Type** field.

1. Select the required voucher type from the available list.

<figure><img src="../../../.gitbook/assets/image (1381).png" alt=""><figcaption></figcaption></figure>

2. Locate the **Bank** field.
3. Select the bank associated with the cheque that needs to be reprinted.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-08 12-51-42.png" alt=""><figcaption></figcaption></figure>

Step 3: After selecting the voucher type and bank, click the **Display** button.

* The system displays the list of available cheque transactions that match the selected criteria.

Step 4: Select the required cheque from the list.

Step 5: Verify the cheque details before printing.

1. Click the **Print** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-08 12-35-16.png>)

* The system generates a printable version of the selected cheque.
