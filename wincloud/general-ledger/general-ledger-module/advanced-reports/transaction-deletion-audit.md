# Transaction Deletion Audit

The **Transaction Deletion Audit Report** provides a detailed record of transactions that have been deleted or amended within a specified date range. This report helps organisations track changes made to accounting transactions, identify the users responsible for modifications, and maintain a complete audit trail for compliance and internal control purposes.

## Steps to Generate the Transaction Deletion Audit Report

Step 1: Navigate to the **General Ledger** module.

1. Click **Advanced** **Reports** from the menu.
2. Select **Transaction** **Deletion Audit** option.

* The transaction deletion audit will open.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 09-29-01.png" alt=""><figcaption></figcaption></figure>

Step 2: Locate the **Trn. Type** field.

1. Select the required transaction type from the available list.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 09-30-08.png" alt=""><figcaption></figcaption></figure>

Step 3: Click the **User Filter** option.

1.  Select one of the following:

    * All Users
    * A Specific User
    * Multiple Users

    <figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 09-31-18.png" alt=""><figcaption></figcaption></figure>

Step 4: By default, the report displays **deleted transactions only**.

1. To View Amendments and Modifications, enable the option to display **Amended/Modified Transactions**.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 09-32-44.png" alt=""><figcaption></figcaption></figure>

Step 5: After selecting the required filters, click the **Display** button.

* The system will generate and display the Transaction Deletion Audit Report based on the selected parameters.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 09-33-27.png" alt=""><figcaption></figcaption></figure>

Step 6: After generating the report :

* Click the **Print** button![](<../../../.gitbook/assets/Screenshot From 2026-06-10 09-36-01.png>)to generate the report in a printable document format.
* Click the **Excel** button![](<../../../.gitbook/assets/Screenshot From 2026-06-10 09-36-45.png>)to export the report to Microsoft Excel format for further analysis and reporting.
