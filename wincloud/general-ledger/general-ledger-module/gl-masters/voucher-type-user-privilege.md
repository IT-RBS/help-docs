# Voucher Type User Privilege

**Voucher Type User Privilege** is used to define and manage user access rights for specific voucher types within the accounting system. These privileges determine which users are authorised to create, view, edit, approve, or delete accounting vouchers.

## Steps to Configure Voucher Type User Privileges

Step 1: Navigate to the **General Ledger** module.

1. Click **Masters 1** from the menu.
2. Select **Voucher Type User Privilege** from the list.

* The Voucher Type User Privilege screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 15-44-39.png" alt=""><figcaption></figcaption></figure>

Step 2: Click the **Open** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-10 15-04-39 (2).png>)

1. Select the required user from the list.

* Once the user is selected, the privilege configuration screen will appear.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 15-45-29.png" alt=""><figcaption></figcaption></figure>

Step 3: The system will display the available voucher types and corresponding access permissions for the selected user.

* Enable the required privileges based on the user's role and responsibilities.
* Disable any privileges that should not be granted.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 15-46-50.png" alt=""><figcaption></figcaption></figure>

Step 4: After assigning the required privileges, click the **Save** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-10 14-29-42 (5).png>)

* The system will save the privilege settings for the selected user.
