# Voucher Type

A **Voucher Type** is a classification used in the accounting system to record different kinds of financial transactions. Each voucher type helps organise, track, and report transactions in a structured and systematic manner.

## Steps to Create a Voucher Type

Step 1: Navigate to the **General Ledger** module.

1. Click **Masters 1** from the menu.
2. Select **Voucher Type** from the list.

* The Voucher Type screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 14-26-57.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **Add** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-10 14-27-56.png>)

* A new entry form will appear.

Step 3: Fill in the required voucher details, such as **Voucher Name, Voucher Number Type, Discount Type** and other configuration fields as required by the system.

* Ensure all required details are entered correctly.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 14-28-49.png" alt=""><figcaption></figcaption></figure>

Step 4: Click the **Save** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-10 14-29-42.png>)

* The new Voucher Type will be created and added to the system.
