# Analysis Code

An **Analysis Code** is a predefined classification used in an accounting or financial system to categorise transactions for detailed tracking, reporting, and analysis beyond the standard general ledger structure.It allows organisations to analyse financial data based on specific business dimensions such as department, project, cost center, location, activity and Business Unit.

## Steps to Create an Analysis Code

Step 1: Navigate to the **General Ledger** module.

1. Click **Masters 1** from the menu.
2. Select **Analysis Code** from the list.

* The Analysis Code screen will be displayed.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 15-23-41.png" alt=""><figcaption></figcaption></figure>

Step 2: Click the **Open** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-10 15-04-39.png>)

* The system will display the list of analysis codes.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 15-29-36.png" alt=""><figcaption></figcaption></figure>

Step 3: Click the **Add** button ![](<../../../.gitbook/assets/Screenshot From 2026-06-10 15-32-05.png>)available on the screen.

Provide the required information:

1. **Code -** Enter a unique code that will identify the analysis category.
2. **Description -** Enter a meaningful description that clearly defines the purpose of the analysis code.

<figure><img src="../../../.gitbook/assets/Screenshot From 2026-06-10 15-30-57.png" alt=""><figcaption></figcaption></figure>

Step 4: Verify that the code and description are correct.

1. Click the **Save** button.![](<../../../.gitbook/assets/Screenshot From 2026-06-10 14-29-42.png>)

* The Analysis Code will be created and made available for use within the system.
