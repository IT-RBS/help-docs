# Purchase Request Template

**Purchase Request Template**

What is **Purchase Request Template,**

Using this option we can create the template based request in that template we can load default items while doing purchase request if you select any created template the item all will load automatically with Qty.

Steps to create **Purchase Request Template,**

1. Go to **Master** > **Purchase Request Template,**
2. Once you opened this menu user has to enter the template name, screen shown below.

![](<../../../.gitbook/assets/0 (129).png>)

1. Next user has to select the unit, purchase type and request category, then user has to select the items, using item search option.

![](<../../../.gitbook/assets/1 (47).png>)

1. Once user selected the items after that you have to enter Qty, screen shown below,

![](<../../../.gitbook/assets/2 (63).png>)

1. By clicking Add button user can add more rows,
2. Once user entered all item then Click Save button to create Template

![](<../../../.gitbook/assets/4 (81).png>)
