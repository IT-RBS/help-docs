# PO Type User

The **PO Type User** feature is used to assign applicable Purchase Order (PO) Types to users based on their department. It also allows users to perform bulk PO updates when bulk selection is enabled.

## Steps to View and Configure PO Type User

Step 1: Navigate to the **Purchase** main menu from the dashboard.

1. In the **Purchase** menu, click on **Masters**.
2. Select **PO Type User** from the sub-menu.

* The PO Type User screen will appear.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-29 16-33-05.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **Open** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-29 15-39-32.png>)

Step 3: Select the required **User** from the available list.

1. Select the appropriate **Department**.

* These settings define the department-wise Purchase Order access for the selected user.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-29 16-35-13.png" alt=""><figcaption></figcaption></figure>

Step 4: Enable the **Bulk Selection** option.

* This allows users to update multiple Purchase Orders in bulk.

Step 5: Select the required **Applicable PO Type** from the available options.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-29 16-36-29.png" alt=""><figcaption></figcaption></figure>

Step 6: Click on the **Save** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-29 15-39-16.png>)

* The PO Type User configuration will be saved successfully.
