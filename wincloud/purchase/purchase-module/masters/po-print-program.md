# PO Print Program

The **PO Print Program** feature is used to configure and maintain the print format or print program for Purchase Order documents based on the selected document type.

## Steps to Create a PO Print Program

Step 1: Navigate to the **Purchase** main menu from the dashboard.

1. In the **Purchase** menu, click on **Masters**.
2. Select **PO Print Program** from the sub-menu.

* The PO Print Program screen will appear.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-29 15-33-34.png" alt=""><figcaption></figcaption></figure>

Step 2: Click on the **Open** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-29 15-39-32.png>)

Step 3: Locate the **Document Type** field.

1. Select the required document type from the available list.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-29 15-33-56.png" alt=""><figcaption></figcaption></figure>

Step 4: Click on the **Add** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-29 15-38-55.png>)

1. Enter or paste the required **Print Program** based on your requirements.

<figure><img src="../../../.gitbook/assets/Screenshot from 2026-05-29 15-37-59.png" alt=""><figcaption></figcaption></figure>

Step 5: Click on the **Save** button.![](<../../../.gitbook/assets/Screenshot from 2026-05-29 15-22-46.png>)

* The PO Print Program will be saved successfully.
