# Purchase Requisition Amendment

**Purchase Requisition Amendment**

This option is used to amend the purchase requisition.

**Steps to purchase requisition amendment**

1. Go to Transactions main menu.
2. Click on Transaction >Purchase Requisition.
3. Click on open button you able see the below screen.
4. Select the status type first then select the requisition no. as shown below.

![](<../../../.gitbook/assets/1 (144).png>)

1. Select the Requisition. No. which you need to amend.
