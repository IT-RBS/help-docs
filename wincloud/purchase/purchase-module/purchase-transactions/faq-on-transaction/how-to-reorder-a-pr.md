# How to reorder a PR?

PR Reorder refers to the process of creating a new Purchase Requisition (PR) for items that need to be reordered, typically based on stock levels or previous requisitions.To reorder a PR in the system, follow these steps:

1. Go to the Purchase main menu.
2. Click on **Transaction > PR Reorder.**
3. Click the PR Reorder Add button.
4. Select the desired item by clicking the search icon next to the product name.
5. Click the Save button to finalize the reorder.
