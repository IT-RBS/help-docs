# DASHBOARD

### A New Dashboard Analytics

The Analytics Dashboard in Wincloud enables users to create, customize, and save personalized dashboards tailored to their specific business needs. Leveraging flexible templates and a wide variety of configurable widgets, users can easily design dashboards that surface the most relevant metrics and key performance indicators (KPIs). This empowers businesses to monitor performance, track trends, and gain actionable insights in real time.

Key Features:&#x20;

* **Customizable Layouts:** Build dashboards from scratch or modify existing templates to fit unique reporting requirements.&#x20;
* **Wide Range of Widgets:** Choose from charts, tables, gauges, and other visualization tools to display data effectively.&#x20;
* **Saved Configurations:** Save dashboard setups for quick access and consistent reporting over time.&#x20;
* **User Personalization:** Tailor each dashboard based on user roles, preferences, and frequently monitored metrics.

The Analytics Dashboard provides a powerful, intuitive interface for data visualization, enabling proactive decision-making and enhanced business performance monitoring.

### How to Configure Your Dashboard:

With the Template Master, you have the flexibility to create as many templates as you need. On the right side, you’ll find the Widget List—just drag and drop or double-click your chosen widgets onto the template screen to build a layout that’s perfectly tailored to you. It’s fast, intuitive, and puts you in complete control of your dashboard design.

1.  **Creating Dashboard templates in the template master**&#x20;

    To customize your dashboard, **go to Template Master**:&#x20;

    **Settings > >Privileges >>Dashboard Template >> Role-Based Template**&#x20;

<figure><img src=".gitbook/assets/image (874).png" alt=""><figcaption></figcaption></figure>

* Click on the plus button <img src=".gitbook/assets/image (875).png" alt="" data-size="line"> to create a new dashboard template.
* Enter the name of the template and add a sequence Number.

<figure><img src=".gitbook/assets/image (876).png" alt=""><figcaption></figcaption></figure>

* Drag and drop from the widget list or double-click on the specific widget to drop the relevant widgets onto the template according to the dashboard plan.
* To increase the size of a widget, simply drag to extend its box, and the widget will automatically resize to fit.&#x20;

<figure><img src=".gitbook/assets/image (877).png" alt=""><figcaption></figcaption></figure>

* Repeat the process to add more widgets and complete the Dashboard.

<figure><img src=".gitbook/assets/image (878).png" alt=""><figcaption></figcaption></figure>

* To recreate the dashboard, click the reset button.

### User Specific Privileges for Dashboard

**Who should view the Dashboards?**

Dashboard access permissions can be restricted to designated key users within Wincloud, ensuring secure and controlled visibility of critical data. &#x20;

To create the **user-specific privileges**, navigate to **Settings >> Company >> User**.&#x20;

<figure><img src=".gitbook/assets/image (882).png" alt=""><figcaption></figcaption></figure>

* Click on the Plus icon (+) on the User Master menu bar.&#x20;
* Once the plus icon is clicked, the User ID toggle is turned ON.&#x20;

<figure><img src=".gitbook/assets/image (883).png" alt=""><figcaption></figcaption></figure>

* Select the User ID from the list of available users. Once selected, the system automatically populates critical user information into the corresponding fields.

<figure><img src=".gitbook/assets/image (884).png" alt=""><figcaption></figcaption></figure>

* Once the user is selected, close the list and fill in the mandatory user information.&#x20;
*   Click the magnifier icon in the Template field to select the templates for which dashboard access permissions need to be configured.&#x20;

    <figure><img src=".gitbook/assets/image (885).png" alt=""><figcaption></figcaption></figure>


* Select the templates you want to grant access to by checking the corresponding boxes, and then click the OK button to confirm.&#x20;
* Save.&#x20;
